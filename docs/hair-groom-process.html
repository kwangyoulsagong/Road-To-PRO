헤어 스타일 시안 절차

specs/088 FR-20 · 2026-11-22 · 그루밍 v2(가닥 시안) → 게임 헤어 굽기

왜 이 절차인가

숫자만 바꿔 만든 헤어는 헬멧·뾰족·탈모처럼 보였다. 스타일마다 참고 사진 옆에 시안을 붙여 놓고 맞춘 뒤에야 승인이 났다(포마드·가일컷·시스루·가르마, 2026-11-22). 게임에 들어가는 모든 헤어는 이 절차를 거친다.

네 단계

1
참고 사진 — 스타일 유형 모양을 보여 주는 사진을 레포 밖 폴더에 둔다. 얼굴 닮음은 목표가 아니며, 사진은 생성 입력·레포·증거 어디에도 넣지 않는다(01-legal, 062 FR-50 개정).
2
시안 렌더 비교 — player/groom/styles.py에 스타일(바탕장 F·H·L + 가이드 가닥 + 위치별 높이 상한)을 정의하고 Blender --background --python player/groom/compare.py -- <출력> <스타일>로 정면·3/4·옆을 찍어 사진 옆에 붙인다. 한 번에 한 스타일씩, 사진과 같아질 때까지 고친다.
3
승인 — 사진 비교를 보고 승인한다. 승인되면 스타일 표의 approved=True. (088에서는 사용자가 위임해 Claude가 3시점 렌더를 직접 열어 판정하고, 사용자가 마지막 E2E에서 일괄 확인한다.)
4
굽기 + 충실도 지표 — 생성기가 가닥을 머리 중심 구면 봉투 셸 + 돌출·앞머리 가닥 카드 + 공유 결 아틀라스로 굽고(player/groom/bake.py), 시안 대비 지표를 잰다. 지표를 못 넘으면 기준을 낮추지 않고 시안 또는 굽기를 고친다.

셸은 불투명이라 시스루 앞머리 틈·디더 밀도를 마스크가 못 담는다. 그래서 처음 제안한 클로즈업 0.90은 0.82로 고쳤다(T10 측정: 승인 4종 LOD0 0.864~0.904 → 헤어라인을 피부 쪽으로 가늘게 해 톱니를 없앤 뒤 중간 계열 0.833~0.846). 늘어진 다발을 카드로 근사하는 장발·묶음·브레이드는 0.65. 장발은 게임 길이 상한(눈 − 1.62 d)에서 자른다.

예산

헤어 몫: LOD0 ≤ 1,900 tris(셸 ≤ 1,300 + 카드), LOD1 ≤ 450, LOD2 ≤ 150. 몸 포함 LOD0 ≤ 11k, 클로즈업 머리 ≤ 6k. 결 텍스처는 스타일별로 두지 않고 공유 아틀라스(parts.png) 하나를 쓴다.
