# /tasks — 태스크 분해

1. `plan.md`가 `상태: 승인됨`인지 확인.
2. `specs/_templates/tasks.md`를 복사해 채운다.
   - 한 태스크 = 한 커밋 크기 (파일 1~3개, 30분~2시간).
   - 각 태스크에 파일과 검증 방법(테스트 이름).
   - 테스트를 구현보다 먼저. asmdef·폴더 준비 같은 기반 작업이 맨 앞.
   - 마지막 태스크는 전체 AC 테스트 통과 확인.
3. 의존 관계가 순서로 표현되는지 확인. 요약을 보여주고 승인을 기다린다.
