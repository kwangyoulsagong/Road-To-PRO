# 시나리오 정의 추가

1. `docs/scenarios.html`에서 해당 패턴의 카탈로그 ID·카테고리·참여 역할·트리거 조건·변주 축을 찾는다. 카탈로그에 없으면 먼저 사용자에게 카탈로그에 추가할지 묻는다.
2. 스키마가 아직 코드로 정해지지 않았다면 임의로 확정하지 말고, 기존 `Data/scenarios/` 파일 형식을 따른다. 기존 파일이 없으면 스키마 초안을 사용자에게 먼저 보여준다.
3. 원칙: 공 주변 3~5명만 시나리오가 조종. 나머지는 팀 형태 레이어. 각 단계에 실패 조건과 폴백(Utility 규칙)으로 넘어가는 지점을 명시.
4. 변주는 파일 복제가 아니라 변주 축(측면, 템포, 참여 인원 등)으로 표현한다.
5. 실존 선수 이름이나 "누구 스타일" 같은 실명 참조 금지. 역할 이름(메짤라, 트레콸르티스타 등)으로 쓴다.
