# 프레젠테이션 · UI

## 하이라이트 3D
- 하이라이트만 재생한다. 풀경기 시청 기능을 만들지 않는다. 재생은 `MatchEngine` 이벤트 로그를 읽기만 하고, 결과를 바꾸지 않는다.
- 속도 1x / 1.5x(기본) / 2x / 3x, 리플레이 0.5x.
- 오디오: 해설 없음. 관중·휘슬·킥·그물 등 현장음만.
- 성능 예산: **내장 GPU 60fps**. 실시간 그림자 1개(태양), 포스트프로세스 최소, 선수 LOD, 드로우콜·머티리얼 수 의식. 메뉴로 나가면 3D 씬 언로드.
- URP 에셋은 `Mobile_RPAsset`을 저사양 기준으로 본다.

## UI (UI Toolkit)
- 스타일: 모바일 금융 앱. 회색 바탕 + 흰 카드, 큰 숫자, **포인트 컬러는 블루 하나**. 선택지는 바텀시트.
- 색·간격·폰트 크기는 USS 변수(토큰)로만. 하드코딩한 색 금지.
- UI는 도메인 상태를 읽고 명령을 보낸다. UI 코드에 게임 규칙 계산을 넣지 않는다.
- 텍스트는 처음부터 로컬라이즈 키로 (한국어 기본).
