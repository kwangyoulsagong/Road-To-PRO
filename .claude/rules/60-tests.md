# 테스트

- EditMode 테스트(NUnit) 위주. PlayMode는 프레젠테이션 검증이 꼭 필요할 때만.
- 테스트 이름: `메서드_상황_기대결과` (영어). 설명 주석은 한국어 가능.
- 시드 RNG는 테스트마다 고정 시드. 랜덤 시드로 통과/실패가 갈리는 테스트 금지.
- 결정론 테스트: 같은 시드로 2회 시뮬 → 이벤트 로그 해시 비교.
- 헤드리스 대량 시뮬(수천 경기)로 통계 검증: 득점·슈팅·점유율 분포가 기획서 목표 범위 안인지. 오래 걸리는 테스트는 `[Category("Slow")]`.
- 실행 방법은 `/unity-test` 스킬.
