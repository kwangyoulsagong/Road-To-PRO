# 052 — UI 사운드 · 메뉴 음악 · 오디오 설정

상태: 승인됨
브랜치: feat/052-ui-sound-music
기획 출처: docs/index.html § 기획서 4.9(UI 방향: 부드러운 마이크로 인터랙션 — 버튼 눌림 0.97, 시트 슬라이드, 성공 시 가벼운 햅틱, 카운트업), § 4.4(해설 없음 확정, 현장 사운드만), § 5.5.1(배터리 정책: 매니지먼트·메뉴는 UI만, 메뉴 30fps) / § 아키텍처 8(렌더링·배터리 정책) / 리서치 07 § 4(오디오), § 5(UI/UX) / 관련 스펙: 037(모션 토큰·햅틱 호출 지점), 038(설정 화면), 046(경기장 소리 — UI 효과음·메뉴 음악을 범위에서 뺌), 047(컷신 사운드트랙), 048(메뉴 렌더 정책)

## 배경
매니지먼트 게임은 대부분의 시간을 메뉴에서 보낸다. 버튼을 누를 때, 바텀시트가 올라올 때, 연봉이 카운트업될 때 소리가 작고 일관되게 따라오면 "앱처럼 깔끔한" 느낌이 산다(기획서 4.9). 그런데 경기장 소리(046)는 UI 효과음·메뉴 음악을 범위에서 뺐고, 037은 햅틱 호출 지점만 정의했다. 이 스펙은 **경기장 밖의 소리 전부**(UI 효과음, 메뉴 배경음)와 **전체 오디오 설정**(음량 분류, 음소거, 경기장 소리와의 전환)을 맡는다. 해설은 없다는 확정 결정은 메뉴에서도 같다 — 음성 내레이션을 넣지 않는다.

## 범위
- 포함:
  - UI 효과음 분류와 트리거: 버튼 눌림, 탭 전환, 바텀시트 열림·닫힘, 선택 확정, 카운트업(틱·완료), 증가/감소 결과, 토스트, 오류, 성공(계약 서명 등 037 FR-42 지점), 받은편지함 새 메시지, 키 모먼트 시트 등장
  - 햅틱 대응표: 같은 지점의 햅틱 강도 분류(가벼움/중간/강함) — 실제 진동 구현은 모바일 포팅 시점 (037과 동일)
  - 메뉴 배경음: 화면 그룹별 재생 규칙(메인·매니지먼트·시즌 종료·은퇴), 반복·크로스페이드, 무음 구간
  - 오디오 설정: 마스터 / 음악 / UI 효과음 / 경기장(046 소관 하위 분류 묶음) 음량, 전체 음소거, 백그라운드(창 비활성) 시 음소거
  - 화면 전환 오디오 규칙: 메뉴 → 하이라이트 → 메뉴 전환 시 메뉴 음악 페이드, 경기장 소리(046)와 겹침 금지, 컷신(047)과의 덕킹
  - 배터리·성능: 메뉴 대기 중 오디오 처리 부하, 무음일 때 오디오 처리 정지
  - 오디오 검증 증거 (046 방식: 큐 로그 + 녹음 레벨 분석)
- 제외:
  - 경기장 현장 소리, 관중 강도, 리플레이 덕킹 → 046
  - 컷신 대사 음성·사운드트랙 → 047 (이 스펙은 메뉴 음악과의 전환만)
  - UI 모션 자체(시간·이징) → 037 (이 스펙은 모션 이벤트에 소리를 붙임)
  - 설정 화면 레이아웃 → 038 FR-100 (이 스펙은 항목과 동작을 제공)
  - 사운드 소스 제작·라이선스 확보 방법 → 플랜 [미정] (CC0/상업 이용 가능만, 01-legal)
  - 오디오 미들웨어 선택 → [미정] (046과 같은 결정)

## 사용자 시나리오
1. 홈에서 "훈련" 카드를 누르면 짧고 부드러운 클릭이 나고, 바텀시트가 올라오며 가벼운 "스윽" 소리가 난다. 선택하면 확정음이 난다.
2. 재계약 서명 후 연봉 숫자가 카운트업되는 동안 아주 작은 틱이 이어지다가, 끝에서 상승 완료음이 난다.
3. 하이라이트로 들어가면 메뉴 음악이 1초 안에 사라지고 경기장 웅성임이 올라온다. 하이라이트가 끝나 매니지먼트로 돌아오면 경기장 소리가 사라지고 메뉴 음악이 다시 페이드인된다.
4. 설정에서 음악을 0으로 내리고 UI 효과음만 남긴다. 다른 창으로 전환하면 소리가 자동으로 꺼진다.

## 요구사항

### UI 효과음
- FR-01: UI 효과음 분류 [제안]: `tap`, `tab`, `sheet_open`, `sheet_close`, `confirm`, `cancel`, `countup_tick`, `countup_done_up`, `countup_done_down`, `toast`, `error`, `success`, `inbox_new`, `keymoment_open`. 분류 목록은 데이터로 관리한다.
- FR-02: 트리거는 037 컴포넌트 이벤트에 붙는다 (버튼 눌림, 시트 열림, 카운트업 시작·완료 등). 화면(038·039)이 개별로 소리를 부르지 않는다 — 컴포넌트가 자동으로 낸다 [제안]. 예외(성공·오류)는 화면이 의미 이벤트를 보낸다.
- FR-03: 카운트업 틱: 값 변화 간격마다가 아니라 [제안] 최대 초당 12회로 제한, 카운트업 길이와 무관하게 과밀하지 않다. 완료음은 증가/감소에 따라 다르다 (037 증감 의미색과 같은 의미).
- FR-04: 같은 효과음이 [제안 50 ms] 안에 반복 요청되면 하나만 낸다 (연타·목록 스크롤 중 소리 폭주 방지). 동시 UI 효과음 최대 [제안 4]개.
- FR-05: 037 "모션 줄이기"가 켜져 있으면 카운트업 틱은 내지 않고 완료음만 낸다 (037 FR-41: 즉시 최종 값).
- FR-06: 비활성 버튼을 누르면 `error`가 아니라 [제안] 소리 없음 (오류음 남용 금지). 실제 실패(저장 실패, 금칙어 이름 등)만 `error`.
- FR-07: 효과음 길이 [제안 ≤ 300 ms], 피크 레벨은 메뉴 음악보다 [제안 −6 dB] 이하로 낮게 들리지 않을 만큼, 날카로운 고음 금지 [제안 기준: 주 에너지 4 kHz 이하].

### 햅틱 대응
- FR-10: 각 UI 효과음 분류에 햅틱 강도(없음/가벼움/중간/강함)를 대응시키는 표를 데이터로 둔다 (037 FR-42의 "성공 시 가벼운 햅틱" 포함). 데스크톱에서는 표만 있고 동작 없음.
- FR-11: 햅틱 설정 끄기 항목을 설정에 둔다 (모바일 빌드에서만 표시 [제안]).

### 메뉴 배경음
- FR-20: 화면 그룹별 음악 상태 [제안]: `main`(타이틀·불러오기), `management`(주간 루프 전체), `season_end`(시즌 결산·시상식), `retirement`(은퇴·레거시 036). 그룹이 바뀔 때만 곡이 바뀌고, 같은 그룹 안 화면 이동에서는 끊기지 않는다.
- FR-21: 곡 전환은 크로스페이드 [제안 1.5초]. 반복 재생 시 이음매에서 클릭·팝 없음.
- FR-22: 같은 곡 반복 피로를 줄이기 위해 그룹당 곡 [제안 2~4]개, 재생 순서는 시드가 아니라 단순 순환 [제안] (오디오는 결정론 대상이 아님 — 단 큐 로그 검증용 고정 모드 제공, 비기능 참고).
- FR-23: 매니지먼트 중 [제안 3분] 이상 입력이 없으면 음악 음량을 [제안 −10 dB] 낮추고, 입력이 생기면 복귀 [제안].
- FR-24: 메뉴 음악에 가사·내레이션·해설 음성 없음 (확정 결정 "해설 없음"과 같은 정신, 현지화 부담 제거).

### 설정 · 전환
- FR-30: 음량 분류: 마스터 / 음악 / UI 효과음 / 경기장. 경기장은 046의 하위 분류 **관중·피치 2개**(046 FR-25 — 장내 PA 분류 없음, 046 Q2)를 묶는 상위 값이다 — 046 슬라이더와 곱으로 적용 [제안]. 설정 화면 배치는 038.
- FR-31: 전체 음소거 토글. 음소거 상태에서 음량 슬라이더 값은 유지된다.
- FR-32: 창 비활성(포커스 잃음)·최소화 시 음소거 [제안 기본 켬, 설정으로 끄기 가능]. 복귀 시 [제안 0.3초] 페이드인.
- FR-33: 설정은 세이브가 아니라 사용자 설정에 저장 (037 비기능과 동일). 변경 즉시 적용, 재시작 후 유지.
- FR-34: 하이라이트 진입: 메뉴 음악 [제안 1.0초] 페이드아웃 완료 후 경기장 소리(046)가 시작한다 (겹침 구간 [제안 ≤ 0.3초]). 하이라이트 중 UI 효과음은 HUD 버튼(039 배속 등)에만, 음량 [제안 −6 dB].
- FR-35: 하이라이트 종료 → 메뉴: 046 FR-41로 경기장 소리가 정리된 뒤 메뉴 음악 페이드인 (046 AC-10과 같은 기준: 전환 후 1초 시점 경기장 소리 −60 dBFS 이하).
- FR-36: 컷신(047) 재생 중 메뉴 음악은 컷신 사운드트랙에 대해 덕킹 [제안 −12 dB] 또는 일시정지(컷신 데이터가 지정). 컷신 종료 후 복귀.
- FR-37: 키 모먼트 바텀시트(019·039)가 열리면 `keymoment_open` 효과음, 경기장 소리 덕킹은 046 범위.

### 배터리 · 성능
- FR-40: 모든 음량이 0이거나 음소거면 오디오 믹서 처리를 멈춘다 [제안] (메뉴 대기 전력 절약, 048 배터리 정책과 같은 목적).
- FR-41: 메뉴에서는 경기장 오디오 리소스를 메모리에 두지 않는다 (046 FR-41과 동일 원칙). 메뉴 음악은 스트리밍 [제안], UI 효과음은 메모리 상주.
- FR-42: 오디오 처리는 메뉴의 렌더 빈도 저하(048 FR-10)와 무관하게 끊기지 않는다 (렌더 간격이 늘어도 음악·효과음 정상).

### 경계 · 예외 상황
- 출력 장치 없음(배치모드·헤드리스) → 예외·에러 로그 0, 큐 로그는 정상 기록 (046 AC-13과 동일).
- 출력 장치 변경(헤드폰 연결·해제) 중 → 재생 끊김 후 [제안 1초] 안에 복구, 예외 0.
- 카운트업 도중 값이 또 바뀜(037 경계) → 틱은 이어지고 완료음은 최종 완료 시 1번만.
- 시트 대기열(037: 동시에 두 시트 불가) → 열림음은 실제로 열릴 때마다 1번.
- 화면 그룹 전환이 빠르게 연속(0.5초 안에 2번) → 마지막 그룹 곡으로 수렴, 곡 2개 이상 동시 재생 없음.
- 음량 0 → 해당 분류 큐는 로그에 남되 재생 처리는 생략 [제안].
- 창 비활성 상태에서 하이라이트 진입(자동 진행) → 음소거 유지, 복귀 시 현재 상태 소리로 페이드인.
- 앱 시작 직후 첫 효과음 지연(디코딩) → 시작 시 UI 효과음 미리 로드, 첫 탭 지연 [제안 ≤ 50 ms].
- 사운드 파일 누락 → 해당 큐는 무음 처리 + 개발 빌드에서만 경고 1회 (출시 빌드 경고 로그 0 기준은 000 FR-60 — 누락 자체를 빌드 검사로 막는다).

## 비기능 요구사항
- 결정론: 오디오는 시뮬 결과를 바꾸지 않는다. 검증용 "고정 모드"(곡 순서·변형 고정)에서 같은 E2E 시나리오 → 같은 큐 로그(분류, 화면 시각, 목표 음량).
- 라이선스: 모든 사운드·음악은 CC0 또는 상업 이용 가능 라이선스, `Art/LICENSES.csv` 기록 (01-legal).
- 접근성: 소리로만 전달되는 정보 없음 — 모든 효과음 의미는 화면에도 표시된다 (청각 장애 고려).

## 수용 기준
- AC-01 [로직]: 037 기본 컴포넌트 이벤트(버튼 눌림, 시트 열림·닫힘, 카운트업 시작·완료, 토스트)마다 정해진 분류의 큐가 정확히 1개 기록된다. 비활성 버튼 눌림은 큐 0개.
- AC-02 [로직]: 같은 효과음을 10 ms 간격으로 20회 요청하면 큐는 50 ms 창마다 최대 1개, 동시 UI 효과음 최대 4개를 넘지 않는다.
- AC-03 [로직]: 3초 카운트업의 틱 큐가 초당 12개 이하이고 완료음은 1개. 모션 줄이기 켜면 틱 0개, 완료음 1개.
- AC-04 [로직]: 같은 그룹 안 화면 10개 이동 동안 음악 곡 변경 0회, 그룹이 바뀌면 크로스페이드 1회. 0.5초 안 그룹 2회 전환 시 동시 재생 곡 ≤ 2(페이드 구간), 최종 1곡.
- AC-05 [로직]: 음소거·음량 설정이 사용자 설정에 저장되고 재시작 후 유지, 세이브 파일에는 없다.
- AC-06 [로직]: 출력 장치 없는 배치모드에서 메뉴 E2E 전체를 돌려도 예외·에러 로그 0, 큐 로그 정상.
- AC-07 [결정론]: 고정 모드에서 `e2e/052-ui-sounds` 2회 실행 → 큐 로그(분류·화면 시각·목표 음량) 해시 동일.
