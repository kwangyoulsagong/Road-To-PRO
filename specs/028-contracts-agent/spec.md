# 028 — 계약 · 연봉 · 에이전트

## 배경
계약은 "돈이냐 출전이냐"를 고르는 순간이다. 연봉·기간·출전 약속·바이아웃·보너스 같은 조항이 실제 경기 기용(025)·이적(029)·라이프 예산(032)으로 이어진다. 협상은 숫자가 오가는 미니게임이며, 에이전트의 능력과 성향이 정보와 결과를 바꾼다. 돈 계산은 하나만 틀려도 플레이어가 바로 알아챈다 — 반올림, 통화, 주급·연봉 변환, 보너스 지급 시점이 정확해야 한다.

## 범위
- 포함:
  - 계약 데이터: 주급(연봉 표시), 기간(시작·종료일), 서명 보너스, 출전·골 수당, 팀 성과 보너스, 출전 시간 약속 등급, 바이아웃(국내/해외), 셀온, 연봉 인상 조건, 클럽 연장 옵션, 강등 시 삭감 (리서치 05 § 2.2)
  - 계약 생애주기: 제안 → 협상 → 서명 → 유효 → (연장 옵션 발동 / 재계약 / 만료 / 해지 / 이적으로 종료)
  - 협상 모델 (BATNA·레버리지·라운드별 요구액·클럽 인내심·결렬)
  - 클럽 연봉 예산과 연봉 구조 상한
  - 에이전트: 능력치(Skill, Network, Greed, Honesty), 수수료, 등급, 교체
  - 급여·보너스 지급과 내 선수 수입 기록 (032 라이프 예산으로 전달)
  - 계약 만료 임박 알림, 자유계약(FA) 상태
  - 사기 입력 항 "연봉만족" 제공 (024 FR-45)
  - 구단 규율 벌금 규정 (032 FR-32 경기 전날 유흥 적발 등이 호출)
  - 계약 화면·협상 바텀시트 흐름 (한 화면에 계약만)
- 제외:
  - 이적료 협상·클럽 간 입찰 (029). 이 스펙은 선수 개인 계약(개인 조건)만
  - 임대 계약의 클럽 간 조건(임대료·연봉 분담 — 029), 임대 중 개인 계약 유지 규칙만 여기
  - 출전 약속 이행 체크 (025가 이 스펙의 조항을 읽음)
  - 세금 문제 이벤트 (031/032)
  - 이벤트 문구 (031)

## 사용자 시나리오
1. "에이전트가 새 제안을 가져왔어요" → 계약 화면: 주급 큰 숫자, 기간, 출전 약속 "Regular", 바이아웃, 보너스 목록.
2. "조건 바꾸기" 바텀시트 → 주급 +15%, 출전 약속 Key 요구 → 클럽 응답 (라운드 2/3) → 일부 수용.
3. 다른 클럽 오퍼가 하나 더 있어서 레버리지가 높다. 에이전트가 "버텨 보죠"라고 조언한다.
4. 클럽 인내심이 0이 되어 결렬. 그 클럽과의 관계가 나빠졌다는 한 줄.
5. Greed 높은 에이전트가 자꾸 이적을 부추긴다. 에이전트 교체를 고른다 (위약금 [미정]).
6. 계약 만료 6개월 전 알림. 재계약하지 않으면 자유계약으로 나갈 수 있다.

## 요구사항

### 계약 데이터와 돈
- FR-01: 금액은 032 FR-14 통화 규칙(최소 단위 64비트 정수, 반올림 규칙 하나)을 따른다. 실수 누적 금지. 표시 반올림은 표시 단계에서만. 이 스펙의 원문 앵커(EUR/년, FR-22)는 게임 통화로 1:1 환산한 밸런싱 기준값이다 [제안].
- FR-02: 기본 급여 단위는 주급. 연봉 표시 = 주급 × 52 [제안]. 화면은 플레이어 설정에 따라 주급/연봉 표시.
- FR-03: 조항 (리서치 05 § 2.2): 서명 보너스(일시), 출전 수당(경기당), 골 수당(골당), 팀 성과 보너스(우승·잔류·대륙대회 진출 조건), 출전 시간 약속(Rotation / Regular / Key / Star), 바이아웃(금액, 국내/해외 구분), 셀온(%), 연봉 인상(연 % · 1군 데뷔 · 국가대표 발탁 시 자동), 클럽 연장 옵션(+1년, 출전 조건부), 강등 시 삭감(−20~50%).
- FR-04: 셀온 기본 10~20% [U]. 바이아웃 V×1.5~5 (리서치 05 § 1.4), V = 029 시장가치(계약 승수 C 적용 전, 029 FR-03). 바이아웃 의무 여부는 리그 규칙 (스페인형 리그 의무) — 월드(020) 리그 속성으로 읽는다.
- FR-05: 계약 기간 [미정: 최소·최대 — 제안 6개월 ~ 5년, 18세 미만 최대 3년]. 시작·종료일은 날짜(024 시간 규칙).

### 지급
- FR-10: 주급은 매주 주 마감(024)에 지급. 출전·골 수당은 경기 후, 팀 성과 보너스는 조건 확정 시점(시즌 말 등), 서명 보너스는 서명일.
- FR-11: 에이전트 수수료 5~10% [U] (Greed 연동)는 [미정: 서명 시 일시 / 급여 비율] 방식으로 뺀다.
- FR-12: 모든 지급은 수입 기록(날짜·항목·금액)으로 남고, 내 선수 자산(032)에 더해진다. 시즌 수입 합계는 기록 합과 정확히 같다.
- FR-13: 연봉 인상 조건(1군 데뷔, 국가대표 발탁)은 해당 사건 알림(024, 035)을 받으면 즉시 적용, 다음 주 지급부터 반영.
- FR-14: 강등 시 삭감은 강등 확정 다음 시즌 시작부터.
- FR-15: 연봉만족 항(0~100, 024 FR-45 입력) [제안] = 50 + 50 · clamp(log2(현재 주급 / 기대 주급), −1, 1). 기대 주급 = 같은 리그 티어·포지션·능력 구간 선수의 주급 중앙값(월드 계약 분포). 표본 < [제안] 10명이면 리그 티어 전체 중앙값. 주급 0(유스 무계약) → 50.
- FR-16: 구단 규율 벌금: 규율 위반(경기 전날 유흥 적발(032), 훈련 불참, 공개 비판 등 030 시스템 요청) 시 [제안] 주급의 1~2주분, 같은 시즌 누적 상한 주급 8주분. 벌금은 032 장부 출금으로 기록하고 025 Indiscipline 항에 알린다.

### 클럽 측 제약
- FR-20: 클럽 연봉 예산 WageBudget = Revenue × r, r = 0.50~0.70 (재정 규정 리그는 0.70 상한) (리서치 05 § 2.1). Revenue는 020 제공.
- FR-21: 클럽 상한: `ClubMax = min(WageBudgetRoom, ValueToClub × 0.15/yr)` [U], `WageStructureCap` = 클럽 최고 연봉의 1.0~1.2배 (리서치 05 § 2.3). 클럽 제안 주급 ≤ min(ClubMax, WageStructureCap).
- FR-22: 티어별 1군 연봉 범위 (밸런싱 앵커 [U]): T1 엘리트 3M~25M+, T1 일반 0.8M~4M, T2 150k~1.2M, T3 30k~300k, T4 5k~40k (EUR/년). 월드 전체 계약 분포가 이 범위를 크게 벗어나지 않아야 한다 (AC-09).

### 협상
- FR-30: 선수 측 유보가치 = max(현재 대안 오퍼 중 최대 효용, 현 계약 유지 효용) (리서치 05 § 2.3). 효용 = f(주급, 기간, 출전 약속, 클럽 수준, 보너스) [미정: f].
- FR-31: 레버리지 `L = 0.4·norm(대안오퍼수·질) + 0.3·(1 − contractLeft/60) + 0.2·norm(Ability − squadAvg) + 0.1·AgentSkill` (contractLeft 단위 개월) (리서치 05 § 2.3). L ∈ [0,1]로 자른다.
- FR-32: 라운드별 요구액 `Demand_t = Reservation + (Aspiration − Reservation)·(1 − t/T)^(1/(1+L))` (리서치 05 § 2.3). 레버리지가 높을수록 천천히 양보. T = 최대 라운드 [미정: 제안 3, 029 이적 협상과 맞춤].
- FR-33: 내 선수 협상: 플레이어가 조건(주급, 기간, 약속 등급, 바이아웃, 보너스)을 바꿔 제안 → 클럽 응답(수용 / 역제안 / 거절). AI 선수끼리는 같은 모델로 자동 협상.
- FR-34: 클럽 인내심 P: 라운드마다 감소, 요구가 ClubMax에서 멀수록 크게 감소 [미정: 감소식]. P = 0 → 결렬, 해당 클럽과 관계 −10 (리서치 05 § 2.3).
- FR-35: 출전 약속 요구가 높을수록 클럽 효용이 줄어든다 (약속은 감독(025) 판단을 구속하지 않고 체크만 된다).

### 에이전트
- FR-40: 에이전트 능력치 Skill, Network, Greed, Honesty (0~1), 수수료 5~10% [U] (리서치 05 § 2.3). 등급(기획서 § 4.5 "등급별 협상력과 수수료") = Skill·Network 구간 [미정: 등급 수·이름].
- FR-41: Skill → 레버리지 항, Network → 비공개 관심 구단 발견 확률 (029 오퍼 정보 공개), Greed → 수수료·이적 부추김 이벤트 계기 (030), Honesty → 에이전트가 전하는 정보의 정확도 [미정: 효과 정의].
- FR-42: 에이전트 교체: 언제든 요청 가능, [미정] 위약금·쿨다운. 등급 높은 에이전트는 선수 명성·가치가 일정 이상이어야 계약해 준다 [제안].

### 생애주기
- FR-50: 상태: 제안 → 협상 중 → 서명 → 유효 → 만료 / 재계약 / 해지 / 이적 종료. 한 선수에게 동시에 유효한 1군 계약은 정확히 1개 (임대 중에도 원소속 계약 유지, 임대 조건은 029).
- FR-51: 만료 임박 알림: 잔여 12개월·6개월 [제안]. 잔여 6개월 이하부터 다른 클럽과 사전 협상 가능 [미정: 규칙 — 현실 보스만 판례형 규칙을 쓸지].
- FR-52: 만료일이 지나면 자유계약(FA) 상태. FA 이적은 이적료 0 (029, 계약 승수 0 — 리서치 05 § 1.2). 만료일이 시즌 경계일이면 024 FR-32 순서(임대 종료 → 계약 만료)로 처리, 시즌 중 만료일이면 그날 주 마감에 처리.
- FR-53: 클럽 연장 옵션: 조건(출전 수 [미정]) 충족 시 클럽이 일방 발동 → 종료일 +1년.
- FR-54: 재계약 거부(내 선수가 재계약 제안 거절) 사실은 025 선발 Penalty에 전달된다.

### 화면
- FR-60: 계약 화면: 주급(또는 연봉) 최대 크기 숫자, 기간, 출전 약속, 바이아웃, 보너스 목록, 에이전트 한 줄 조언. 계약 화면에는 계약만 (기획서 § 4.9).
- FR-61: 협상 바텀시트: 조건 슬라이더·선택, 현재 라운드 n/T, 클럽 인내심 표시(대략 3단계 [제안]), 제출. 클럽 응답은 다음 시트로.
- FR-62: 복수 오퍼 비교 화면: 오퍼 2~4개 카드를 나란히(좁은 화면에서는 세로) — 주급, 기간, 약속, 클럽 수준 (리서치 05 § 8 시사점 3).
- FR-63: 금액 표시: 천 단위 구분, 큰 금액 축약(1.2M) 규칙, ko/en 표기 차이 [제안: ko "120만", en "1.2M"].

## 경계 · 예외 상황
- 금액 오버플로: 25M+/년 엘리트 × 5년 × 보너스 합 — 64비트 정수 범위 안 확인. 음수 금액 금지.
- 주급 × 52 와 실제 시즌 주 수(52/53주) 차이 — 연봉 표시와 실제 지급 합의 차이를 기록으로 설명 가능해야 한다.
- 시즌 중 이적 시 주급 일할 계산 [제안: 주 단위로 끊고 이적일이 속한 주는 새 클럽 지급].
- contractLeft = 0, 60개월 초과 계약에서 레버리지 항 (1 − contractLeft/60) 음수 → 클램프.
- 대안 오퍼 0개일 때 norm 분모 0.
- T 라운드 마지막 (t = T)에서 Demand = Reservation (지수 경계), L = 0·1 극단.
- 바이아웃 금액 = 0 또는 없음 / 국내만 / 해외만.
- 계약 종료일 = 시즌 경계일 (024 시즌 경계 처리 순서와 맞춤).
- 협상 중 이적 창구 마감 → 협상 자동 종료 규칙 [제안].
- 18세 미만 선수 계약 제한 (기간 상한).
- 에이전트 교체 직후 진행 중 협상 → [제안] 협상 취소.
- 강등 삭감 + 연봉 인상이 같은 시즌에 겹침 → 적용 순서 [제안: 삭감 후 인상].
- 부상·질병 결장 중 계약 만료 → 그대로 FA가 되고 건강 상태는 유지(027). 결장 중 재계약 제안은 클럽 효용에 결장 잔여 기간 반영 [제안].
- 은퇴 확정(036) 시 진행 중 협상은 취소, 유효 계약은 은퇴 처리일에 해지(위약금 없음 [제안]).
- 벌금 누적이 잔액을 음수로 만듦 → 032 FR-12 음수 하한 규칙이 적용된다 (벌금은 거부되지 않고 기록 [제안]).
- 2월 29일이 계약 종료일 → 평년에는 2월 28일로 [제안] (024 FR-02 달력 규칙).

## 비기능 요구사항
- 결정론: 같은 입력·시드 → 협상 라운드별 요구·응답·결과 동일. AI 자동 협상 처리 순서 고정 (선수 id 순).
- 세이브 호환: 계약 전체 조항, 수입 기록, 에이전트, 협상 진행 상태 저장. 협상 중 저장 → 로드 후 같은 라운드부터.

## 수용 기준
- AC-01 [결정론]: 같은 픽스처·시드로 협상 시뮬 2회 → 라운드별 요구·응답·최종 조건 동일.
- AC-02 [로직]: 레버리지·라운드 요구액 공식이 FR-31·FR-32와 같다 (고정 입력 표 10행). L ∈ [0,1], t = T 에서 Demand = Reservation, 대안 오퍼 0개에서 예외 없음.
- AC-03 [로직]: L이 높은 협상의 라운드별 양보 폭이 L이 낮은 협상보다 작다 (같은 Reservation·Aspiration).
- AC-04 [로직]: 클럽 제안 주급이 항상 ≤ min(ClubMax, WageStructureCap) (무작위 협상 10,000건).
- AC-05 [로직]: 인내심 0 → 결렬, 관계 −10이 정확히 1회 적용.
- AC-06 [로직]: 1시즌 지급 기록 합 = 주급 지급 합 + 수당 + 보너스 − 수수료, 자산 증가분과 정확히 일치 (정수 오차 0).
- AC-07 [로직]: 연봉 인상(1군 데뷔·국가대표), 강등 삭감, 연장 옵션 발동이 각각 기대한 날짜·금액으로 적용된다 (경계: 같은 시즌 삭감+인상).
- AC-08 [로직]: 계약 생애주기: 만료일 다음 날 FA, 한 선수 동시 유효 1군 계약 1개 (월드 헤드리스 3시즌에서 위반 0).
- AC-09 [로직]: 월드 생성 직후·3시즌 후 티어별 연봉 분포의 중앙값이 FR-22 범위 안.
- AC-10 [로직]: 금액 경계: 25M/년 × 5년 계약의 총액·보너스 합 계산에 오버플로 없음, 음수 금액 0.
- AC-11 [E2E]: `e2e/028-contract-screen` — 계약 화면: 주급 큰 숫자·조항·에이전트 조언 캡처 (ko/en 금액 표기 확인). 프로필: 전체.
- AC-12 [E2E]: `e2e/028-negotiation` — 협상 바텀시트 → 클럽 역제안 → 수용까지 각 단계 캡처, 라운드 n/T와 인내심 표시. 프로필: 전체.
- AC-13 [E2E]: `e2e/028-offer-compare` — 오퍼 3개 비교 화면이 넓은 화면 가로·좁은 화면 세로로 겹침·잘림 없이 보인다. 프로필: 전체.
- AC-14 [E2E]: `e2e/028-breakdown` — 결렬 시 관계 하락 한 줄 캡처. 프로필: smoke.
- AC-15 [성능]: 성능 예산 표 항목이 기준 프로필에서 예산 안.
- AC-16 [로직]: 연봉만족 항(FR-15): 주급 = 기대 → 50, 2배 → 100, 절반 → 0, 4배 → 100(클램프), 주급 0 → 50. 벌금(FR-16) 누적이 상한에서 멈추고 032 장부·025 Indiscipline에 각각 1회 기록된다.
- AC-17 [로직]: 협상 2라운드 진행 중 저장 → 로드 → 남은 라운드 결과가 저장 없이 진행한 결과와 같다. 계약 만료일 = 시즌 경계일 픽스처에서 024 FR-32 순서대로 FA 처리된다.
