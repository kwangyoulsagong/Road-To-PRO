# 019 — 키 모먼트 · 재시뮬

상태: 초안
브랜치: feat/019-key-moments
기획 출처: docs/index.html § 기획서 1.2(핵심 컨셉 2), § 4.4(경기 참여 방식), § 4.2.1(지시 준수율), § 4.9(선택지는 바텀시트), § 5.4(피치 컨트롤 활용처: 키 모먼트 선택지 생성), § 7(M3 완료 기준), § 아키텍처 4(선택이 결과를 바꾸면 같은 시드로 재계산), research[7] 07 § 2.3(시드 + 입력 로그 재시뮬, 10초 체크포인트)

## 배경
"경기는 시뮬레이션이지만 내 선수는 개입한다"가 이 게임의 핵심 컨셉이다(기획서 1.2). 내 선수에게 결정적인 순간이 오면 경기가 멈추고 선택지가 뜬다. 예: "수비 뒷공간이 열렸다 → ① 침투 요구 ② 내려와서 받기 ③ 포지션 유지". 선택은 결과를 실제로 바꿔야 하고(M3 완료 기준: "선택 결과가 시뮬에 반영됨"), 그러면서도 결정론이 깨지면 안 된다. 그래서 경기는 먼저 끝까지 계산하고, 선택이 결과를 바꾸면 **그 시점의 상태에서 같은 시드로 남은 경기를 다시 계산**한다(아키텍처 4). 이 스펙은 키 모먼트 감지, 선택지 생성, 성공 확률, 선택 적용과 재시뮬을 정한다. 선택지 화면(바텀시트)은 037·039, 하이라이트 끼워 넣기는 018이 맡는다.

## 범위
- 포함:
  - 키 모먼트 감지 규칙 (내 선수 관련 상황, 빈도 상한)
  - 상황별 선택지 생성 (2~4개) 과 각 선택지의 성공 확률·예상 결과 힌트
  - 성공 확률 = 내 능력치 + 상황(피치 컨트롤) + 상대 능력치
  - 선택 적용: 선택을 시뮬 입력으로 기록하고, 그 시점 상태 체크포인트에서 같은 시드로 남은 경기 재시뮬
  - 선택 결과의 커리어 반영 신호 (지시 무시·감독 신뢰 등은 신호만 내보내고 처리는 025)
  - 키 모먼트 기록 (경기 후 리뷰·세이브용)
  - 시간 제한·자동 선택(무응답) 규칙
- 제외:
  - 바텀시트·선택지 UI 구현 (037 컴포넌트, 039 경기 HUD) — 이 스펙은 UI에 넘길 데이터와 화면 흐름만 정한다
  - 하이라이트 선정 (018), 3D 재생 (041)
  - 피치 컨트롤 계산 (007), 액션 성공 판정 모델 (008), 시나리오 실행 (013)
  - 감독 신뢰도 변화량 계산 (025)

## 사용자 시나리오
1. 하이라이트를 보다가 내 선수가 하프스페이스에서 공을 받는 순간 화면이 멈추고, 아래에서 시트가 올라온다: "수비 뒷공간이 열렸어요" — ① 침투 요구 (성공 높음 · 위험 낮음) ② 내려와서 받기 ③ 포지션 유지.
2. ①을 고르면 그 장면이 이어서 재생되고, 침투 → 스루패스 → 슈팅이 나온다. 결과가 원래 계산과 다르면 이후 경기 결과(스코어·평점)도 바뀐다.
3. 감독이 "크로스 그만 올려라" 지시를 내린 상태에서 크로스를 고르면, 지시 무시로 기록된다. 골이 나면 오히려 신뢰가 오른다(025가 처리).
4. 시트를 띄워 두고 오래 고민해도 게임은 멈춰 있다. 자동 진행 옵션을 켰다면 제한 시간 뒤 선수 성향대로 자동 선택된다.
5. 경기 후 리포트에서 "키 모먼트 3회 · 성공 2회"와 각 선택을 볼 수 있다.

## 요구사항

### 감지
- FR-01: 키 모먼트 후보는 **내 선수가 주체가 되는 의사결정 순간**이다. 후보 종류 [제안]: 공 소유 시 결정(침투 패스/드리블/슈팅/홀드), 오프더볼 움직임(침투 요구/내려와 받기/위치 유지), 수비 결정(압박/지연/커버), 세트피스 키커 선택(직접 슈팅/크로스/짧게), 페널티 키커 방향. 각 종류는 데이터로 정의한다.
- FR-02: 후보 점수 = 그 순간의 결정 가치 차이(선택지 간 기대 xT/xG 차이가 큰 순간일수록 높음, 007·008 제공) × 경기 상황 가중(막판·접전). 점수가 임계값 [미정] 이상일 때만 키 모먼트.
- FR-03: 빈도 상한: 경기당 [제안] 2~5회, 연속 키 모먼트 간 최소 간격 [제안] 시뮬 시간 5분. 내 선수 출전 시간에 비례해 상한을 줄인다 (15분 출전 → 최대 [제안] 2회).
- FR-04: 내 선수가 출전하지 않으면 키 모먼트 없음. 퇴장·교체·부상 아웃 이후에도 없음.
- FR-05: 감지는 **1차 계산(풀 시뮬) 중**에 일어난다. 키 모먼트 지점마다 상태 체크포인트를 남기고, 1차 계산에서 시뮬이 실제로 고른 행동(= "선택하지 않았다면 일어났을 일")을 기본 선택으로 기록한다.

### 선택지
- FR-10: 선택지 2~4개. 각 선택지: 짧은 대화체 문장(기획서 4.9 문체), 성공 확률 표시 등급, 위험 표시, 성향·역할 궁합 표시(003), 감독 지시 위반 여부 표시.
- FR-11: 성공 확률 = f(내 선수 관련 능력치, 상황(피치 컨트롤 · 압박 · 공간), 상대 관련 능력치) (기획서 4.4). 확률 계산 자체는 008·007 모델을 그대로 쓴다. 키 모먼트 전용 확률 공식을 따로 만들지 않는다 (같은 상황이면 시뮬 판정과 표시 확률이 일치해야 함).
- FR-12: 화면 표시는 정확한 %가 아니라 등급(예: 높음/보통/낮음 — 구간 [미정])으로 보여준다. 내부 확률값은 기록한다.
- FR-13: 판단력·시야 능력치가 낮으면 표시 등급에 오차가 섞일 수 있다 [제안] (기획서 5.2 "판단력·시야 낮으면 노이즈" 원칙과 같은 방향). 오차는 시드 RNG로 결정론적.
- FR-14: 감독 지시와 충돌하는 선택지는 "지시와 다름" 표시를 단다. 지시 준수율(기획서 4.2.1)은 AI 자동 선택에만 적용하고, 플레이어 선택은 항상 따른다.

### 선택 적용과 재시뮬
- FR-20: 플레이어가 기본 선택(1차 계산이 고른 것)과 같은 선택을 하면 재시뮬하지 않는다. 1차 결과를 그대로 쓴다.
- FR-21: 다른 선택을 하면: 키 모먼트 체크포인트 상태를 복원 → 선택을 그 틱의 입력으로 주입 → 같은 시드 스트림으로 경기 끝까지 재시뮬 → 새 SimEvent 스트림으로 이후 결과 교체.
- FR-22: "같은 시드"의 의미: 체크포인트에 RNG 상태를 포함해 저장하고, 복원 후 이어서 쓴다. 선택 주입으로 RNG 소비 순서가 달라지는 것은 허용(결과가 달라지는 게 목적). 단, **같은 선택을 다시 하면 항상 같은 결과**여야 한다.
- FR-23: 재시뮬은 선택 시점 이후 키 모먼트를 다시 감지한다. 이전에 예정됐던 이후 키 모먼트는 폐기하고 새 결과 기준으로 다시 정한다.
- FR-24: 재시뮬은 백그라운드에서 돌고, 그동안 선택 직후 장면(해당 클립 나머지)을 재생할 수 있어야 한다. 재시뮬은 앞에서부터 순서대로 결과를 내므로, **다음 하이라이트 장면 구간까지 계산되면** 경기 끝까지 기다리지 않고 그 장면을 재생한다 (점진 재생). 다음 장면 구간이 아직 계산되지 않았으면 대기 표시를 띄운다.
- FR-25: 선택 결과(성공/실패, 이후 득점 변화)를 키 모먼트 기록에 남긴다. 커리어 반영 신호(지시 위반, 성공, 실패, 결정적 결과)를 025·030에 이벤트로 넘긴다.
- FR-26: 입력 로그: 경기의 모든 키 모먼트 선택을 (틱, 키 모먼트 id, 선택 id) 목록으로 남긴다. 시드 + 라인업 + 전술 + 입력 로그만으로 최종 결과를 재현할 수 있어야 한다 (research[7] § 2.3 방식 B).

### 진행 흐름
- FR-30: 하이라이트 재생 중 키 모먼트 지점에서 재생을 멈추고 선택지를 띄운다. 선택 전에는 경기 시간이 흐르지 않는다.
- FR-31: 기본은 시간 제한 없음. 설정에서 자동 진행을 켜면 제한 시간 [제안] 10초 후 선수 성향 기반 자동 선택 (지시 준수율 적용).
- FR-32: "모두 건너뛰기"(041 FR-21)를 눌러도 **내 선수 키 모먼트는 건너뛰지 않는다** (확정 (2026-11-02 사용자 결정)). 건너뛴 구간의 키 모먼트는 3D 없이 텍스트 + 미니맵(039)으로 상황을 보여주고 같은 선택지를 바텀시트로 낸다. 선택 결과 반영(재시뮬)은 같은 규칙을 따른다.
- FR-33: 선택 후 결과 요약 한 줄 ("침투 성공! 슈팅까지 이어졌어요")을 039가 띄울 수 있게 결과 데이터를 넘긴다.
- FR-34: 건너뛰기 키 모먼트 화면 검증 (FR-32): 텍스트 + 미니맵 키 모먼트도 3D 키 모먼트와 같은 선택지·등급·지시 위반 표시를 쓴다.

## 경계 · 예외 상황
- 키 모먼트 직후 경기가 바로 끝나는 경우(추가시간 마지막 틱): 재시뮬 구간이 0~수 틱이어도 정상 처리.
- 같은 틱에 내 선수 키 모먼트가 두 종류(예: 공 소유 + 세트피스): 우선순위 [제안] 공 소유 결정 > 세트피스 > 오프더볼 > 수비, 하나만 띄운다.
- 선택 후 재시뮬 결과로 내 선수가 퇴장·부상: 이후 키 모먼트 0, 018 재선정.
- 재시뮬 결과 경기 결과(승/무/패)가 바뀜: 최종 스코어·평점·스탯(015)은 재시뮬 결과로 완전히 교체. 1차 결과가 어디에도 남지 않는다 (디버그 기록 제외).
- 키 모먼트 선택 중 앱 종료: **경기 중 저장은 없다** (확정 (2026-11-02 사용자 결정)). 재시작하면 경기 시작 직전 상태로 돌아가 경기를 처음부터 다시 진행한다. 같은 시드라 같은 흐름이 나오고, 이전 세션의 선택은 남지 않는다. 체크포인트·입력 로그는 메모리에만 있다.
- 선택지 중 확률이 0 또는 1인 선택지: 표시는 하되 등급은 경계값, 내부 확률은 [0,1]로 클램프. NaN이면 그 선택지를 빼고 경고 로그.
- 선택지가 1개 이하로 남는 상황: 키 모먼트로 띄우지 않는다.
- 연속 재시뮬 (키 모먼트 3회 모두 기본과 다른 선택): 재시뮬이 체인으로 3회 일어나도 최종 결과는 입력 로그 하나로 재현 가능.
- 시뮬 버전이 바뀐 세이브에서 입력 로그 재생: 결과가 달라질 수 있으므로 세이브에 시뮬 버전을 기록하고, 다르면 저장된 최종 결과를 신뢰(재생하지 않음) (022와 연계).

## 비기능 요구사항
- 결정론: (시드, 라인업, 전술, 입력 로그) → 최종 결과 비트 단위 동일. 체크포인트 복원 후 재시뮬 = 처음부터 같은 입력 로그로 시뮬한 결과 (이 동치가 핵심 불변식).
- 순수 C#, UnityEngine 비참조. 재시뮬은 프레젠테이션 프레임을 막지 않도록 메인 스레드 밖에서 돌 수 있어야 한다 (경기 하나는 단일 스레드 원칙 유지 — 재시뮬 하나는 하나의 스레드에서).
- 체크포인트 크기: 경기 전체 상태 + RNG 상태. 006 체크포인트 형식과 같다 (≤ 16 KB, 006 성능 예산).
- 세이브 호환: 입력 로그 형식에 버전 필드.

## 수용 기준
- AC-01 [결정론]: 고정 시드 경기에서 70분 키 모먼트에 선택 B를 했을 때, (a) 체크포인트 복원 후 재시뮬 결과와 (b) 처음부터 입력 로그 [70분: B]로 전체 시뮬한 결과의 SimEvent 해시가 같다.
- AC-02 [결정론]: 같은 키 모먼트에서 같은 선택을 10회 반복하면 10회 모두 같은 결과 해시가 나온다.
- AC-03 [로직]: 기본 선택과 같은 선택을 하면 재시뮬이 일어나지 않고 1차 결과 해시가 그대로다.
- AC-04 [로직]: 1,000경기 샘플(내 선수 풀타임 출전)에서 경기당 키 모먼트가 2~5회 범위 밖인 경기 비율이 [제안] 5% 이하이고, 연속 키 모먼트 간격이 5분 미만인 경우가 0건이다.
- AC-05 [로직]: 내 선수 미출전·퇴장 이후·교체 아웃 이후 키 모먼트가 0건이다 (1,000경기 전수).
- AC-06 [로직]: 키 모먼트 선택지의 내부 성공 확률이, 같은 상황에서 008 판정 모델이 쓰는 확률과 일치한다 (오차 0, 픽스처 20개).
- AC-07 [로직]: 다른 선택을 고른 1,000회 샘플에서 결과(성공/실패) 분포가 표시 확률과 통계적으로 일치한다 ([제안] 등급별 실제 성공률이 등급 구간 안).
- AC-08 [로직]: 키 모먼트 3회 모두 기본과 다른 선택을 한 경기의 최종 결과가 입력 로그 3개로 처음부터 재현된다.
- AC-09 [로직]: 감독 지시와 충돌하는 선택을 하면 "지시 위반" 신호 이벤트가 정확히 1개 나온다.
- AC-10 [로직]: 추가시간 마지막 틱 키 모먼트, 동시 두 종류 키 모먼트, 선택지 NaN 픽스처에서 예외가 없고 FR 규칙대로 처리된다.
- AC-11 [성능]: 재시뮬 시간이 성능 예산 표 안에 든다. 1,000경기 샘플에서 "다음 장면 구간이 아직 계산 안 돼 대기"가 생긴 키 모먼트 비율이 5% 이하다 (low-igpu-1080p 흉내).
- AC-12 [E2E]: `e2e/019-key-moment-choice` — 고정 세이브·시드 경기 하이라이트에서 키 모먼트 지점에 재생이 멈추고 바텀시트에 선택지 3개(문장·등급·위험·지시 위반 표시)가 뜬다. 선택 전·후, 결과 요약 한 줄까지 단계별 스크린샷이 기준 이미지와 일치한다. 프로필: 전체 (ko/en, light/dark 포함 — 긴 문장 잘림 검사).
- AC-13 [E2E]: `e2e/019-key-moment-resim` — 같은 경기에서 다른 선택을 하면 최종 스코어 화면이 기본 선택 경로와 달라지고(픽스처로 결과가 달라지도록 고른 경기), 재시뮬 중에도 하이라이트 재생 프레임이 목표 fps를 유지한다. 프로필: smoke.
- AC-14 [E2E]: FR-34: `e2e/019-skip-key-moment` — 고정 세이브·시드 경기에서 "모두 건너뛰기"를 누르면 3D 재생 없이 키 모먼트 지점에서 미니맵 + 텍스트 + 바텀시트 선택지가 뜨고, 선택 후 결과가 3D로 본 경우와 같다(같은 선택 → 같은 결과 해시). 프로필: smoke.
- AC-15 [로직]: 앱을 키 모먼트 선택 화면에서 강제 종료하고 다시 시작하면 경기 시작 직전 상태로 복구되고, 같은 선택을 다시 하면 처음 실행과 결과 해시가 같다.
