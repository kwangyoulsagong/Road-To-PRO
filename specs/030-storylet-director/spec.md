# 030 — 스토리렛 엔진 · 스토리 디렉터

상태: 초안
브랜치: feat/030-storylet-director
기획 출처: docs/index.html § 기획서 4.6.2(이벤트 카탈로그), 4.10(라이프: 지연 결과·디렉터 리듬) / § 리서치 05 §7(내러티브와 이벤트: 스토리렛·디렉터·관계·사기·인터뷰 인용 시드), §8(벤치마크 시사점: 쿨다운·리듬·콜백·지연 결정) / § 리서치 07 §3.4(스토리 모먼트: 트리거+템플릿+결과 변수) / § 아키텍처 6(주간 커리어 루프: 라이프 → 스토리 디렉터 → 다음 주)

## 배경
선수의 커리어는 경기 결과만으로는 이야기가 되지 않는다. 감독 면담, 에이전트 연락, 연애, 스캔들 같은 사건이 적절한 때에, 적절한 빈도로, 앞선 선택을 기억하며 일어나야 한다. 이 스펙은 사건 하나를 "전제조건 + 선택지 + 결과"로 정의하는 **스토리렛** 형식과, 그중 무엇을 언제 띄울지 정하는 **스토리 디렉터**(압박 → 숨 돌릴 틈 → 재압박 리듬)를 정한다. 개별 이벤트 콘텐츠는 031이 채운다.

## 범위
- 포함:
  - 스토리렛 정의 형식 (전제조건, 적합도, 쿨다운, 반복 여부, 태그, 카테고리, 선택지, 선택지 노출 조건, 결과)
  - 결과 종류: 수치 변화(사기·신뢰·평판·돈·관계·피로 등 다른 스펙의 상태), 플래그, 인용 시드 저장, 지연 결과 예약, 후속 스토리렛 예약, 다른 시스템으로의 요청(예: 이적 요청 → 029)
  - 디렉터: 긴장도(Tension) 게이지, 주간 선택 수 상한, 태그 가중치, 신선도(최근 사용 감점), 우선순위·강제 이벤트
  - 지연 결과 큐 (n일/n주/n경기 뒤, 또는 조건 충족 시 발동)
  - 인용 시드와 콜백 (예: 자신감 발언 후 3경기 무득점 → 조롱 기사)
  - 사기 입력 항 "최근사건" 제공 (사기 합성식·효과는 024 FR-45·46 소유)
  - 콘텐츠 데이터 로딩·검증 (스키마 오류, 존재하지 않는 참조, 순환 후속 예약 감지)
  - 이벤트가 화면에 전달되는 형태(제목·본문 키·선택지 키·연출 힌트)의 계약
- 제외:
  - 개별 이벤트 300+개 작성과 콘텐츠 린트 → 031
  - 화면(받은편지함, 바텀시트) 구현 → 038, 디자인 토큰 → 037
  - 컷신·대화 연출 재생 → 047 (이 스펙은 연출 힌트 id만 넘긴다)
  - 관계·미디어·라이프 각 시스템의 수치 모델 → 032, 033, 034 (이 스펙은 그 상태를 읽고 쓰는 통로만)
  - 커리어 주간 진행 순서 → 024 (이 스펙은 024가 정한 시점에 호출됨)

## 사용자 시나리오
1. 경기 후 라이프 시간이 끝나면 "에이전트가 새 제안을 가져왔어요" 카드가 받은편지함에 뜬다. 열면 선택지 2~3개가 바텀시트로 올라온다.
2. 인터뷰에서 "이번 시즌 20골 넣겠다"고 자신 있게 답했다. 그 뒤 3경기 연속 무득점이 되자 조롱 기사가 뜬다. 앞선 선택이 기억되고 있다.
3. 부상·스캔들이 몰아친 다음 몇 주는 조용히 지나가고, 가벼운 생활 이벤트만 뜬다. 숨 돌릴 틈이 있다.
4. 같은 "파티 초대" 이벤트가 매주 반복되지 않는다.

## 요구사항

### 스토리렛 정의
- FR-01: 스토리렛 필드: id(전역 유일, 영문 snake_case), 카테고리(031의 12 카테고리 중 하나), 태그(복수), 전제조건, 적합도(0 이상 실수), 쿨다운(일), 반복 가능 여부, 최대 발생 횟수(커리어 전체), 우선순위(일반/높음/강제), 유효 기간(조건이 맞은 뒤 며칠 안에 띄워야 하는지), 제목·본문 텍스트 키, 선택지 목록, 연출 힌트 id(선택), 등급 표시(전체/주의).
- FR-02: 전제조건은 상태 질의의 조합(그리고/또는/아님)으로 쓴다. 질의 대상: 나이, 날짜·시즌 구간(프리시즌·시즌 중·이적시장·시즌 종료), 경기 결과·최근 n경기 스탯, 신뢰·사기·평판·돈·관계 수치, 플래그, 이전 스토리렛 발생 여부와 선택 결과, 부상·질병 상태, 계약 상태, 소속 팀 상황. 데이터로만 쓰고 코드 수정 없이 추가 가능해야 한다 (기획서 5.1.1과 같은 원칙).
- FR-03: 선택지 필드: 텍스트 키, 노출 조건(없으면 항상), 비용(돈·시간 슬롯 — 032와 연동), 결과 목록, 성공 판정(선택: 확률 또는 능력치 판정, 실패 시 다른 결과 목록). 선택지는 1~4개. 선택지가 1개면 "확인" 이벤트.
- FR-04: 노출 조건을 만족하는 선택지가 하나도 없으면 그 스토리렛은 후보에서 빠진다 (빈 바텀시트 금지).
- FR-05: 결과 종류: 수치 증감(대상·양·상한/하한), 플래그 설정/해제, 인용 시드 저장, 지연 결과 예약(n일/n주/n경기 뒤, 또는 조건), 후속 스토리렛 예약(지정 지연 + 유효 기간), 시스템 요청(이적 요청·면담 요청·벌금·결장 처리 등, 수신 스펙이 처리), 긴장도 증감.

### 디렉터
- FR-10: 디렉터는 024가 정한 시점(주간 루프의 "스토리 디렉터" 단계, 경기 직후, 특정 날짜 이벤트)에 호출된다. 한 번 호출에서 후보를 모으고 띄울 스토리렛을 0개 이상 고른다.
- FR-11: 후보 = 전제조건 참 ∧ 쿨다운 지남 ∧ 최대 횟수 미달 ∧ 노출 가능한 선택지 ≥ 1. 선택 가중치 = `적합도 × 태그 가중치(긴장도) × 신선도` (리서치 05 §7.2).
- FR-12: 긴장도 0~1. 사건(위기 태그 스토리렛, 부상, 스캔들, 패배 연속 등) 발생 시 상승, 평온한 주마다 감쇠. 긴장도가 높을수록 위기 태그 가중치↓·휴식 태그 가중치↑, 낮을수록 반대 ("압박 → 숨 돌릴 틈 → 재압박", 리서치 05 §7.1). 상승·감쇠량은 [제안] 위기 이벤트 +0.2, 주당 감쇠 ×0.7 — 튜닝 값으로 데이터에 둔다.
- FR-13: 주당 띄우는 일반 스토리렛 상한 [제안] 3개 (강제·높음 우선순위는 상한과 별도로 처리하되 강제도 주당 [제안] 2개 넘으면 다음 주로 미룸). 같은 카테고리는 주당 [제안] 1개.
- FR-14: 신선도: 최근 [제안] 8주 안에 같은 태그를 쓴 횟수에 따라 가중치를 낮춘다. 반복 가능 스토리렛도 같은 id 연속 발생은 쿨다운으로 막는다.
- FR-15: 강제 우선순위(예: 데뷔전, 계약 만료 통보, 커리어 위협 질병)는 전제조건이 맞으면 유효 기간 안에 반드시 뜬다. 유효 기간을 넘기면 "놓침" 결과(정의된 경우)를 적용한다.
- FR-16: 시즌 경계(시즌 종료 → 다음 시즌)·이적·감독 교체 시 해당 스토리렛 후보와 예약 큐를 정리하는 규칙을 둔다 (예: 이전 클럽 동료 관련 예약은 이적 후 무효 또는 변형).

### 지연 결과 · 인용 시드
- FR-20: 지연 결과 큐: 예약 시점, 발동 조건(시간 또는 조건식), 만료 시점, 발동 시 적용할 결과. 시간 진행 때마다 검사. 만료되면 버리고 로그를 남긴다.
- FR-21: 인용 시드: 발언 종류(겸손/자신감/도발/회피, 리서치 05 §7.3), 대상(감독·팀·상대·팬), 내용 키, 시점. 다른 스토리렛 전제조건이 인용 시드를 질의할 수 있다 (콜백). 시드는 [제안] 1시즌 뒤 만료.
- FR-22: 같은 플레이 기록에서 같은 시드면 디렉터의 선택·지연 결과 발동이 항상 같다 (결정론).

### 사기 입력 "최근사건" 항
- FR-30: 최근사건 항(0~100) = 50 + 최근 [제안] 6주 스토리렛 결과의 사기 증감 합을 지수 감쇠([제안] 주당 ×0.7)한 값, [0,100]으로 자름. 스토리렛 결과의 "사기 ±n"은 사기를 직접 바꾸지 않고 이 항에 들어간다. 사기 합성식과 효과(±5%)는 024 FR-45·46이 정의한다.
- FR-31: (삭제 — 024 FR-46으로 이동)

### 콘텐츠 로딩 · 검증
- FR-40: 스토리렛 데이터(`Data/`)를 읽을 때 검증: 스키마 위반, 중복 id, 없는 텍스트 키, 없는 후속 스토리렛 참조, 알 수 없는 상태 질의, 선택지 0개 또는 5개 이상, 후속 예약의 무한 순환(지연 0으로 서로 예약). 오류 하나라도 있으면 로딩 실패와 함께 전체 오류 목록을 낸다 (첫 오류에서 멈추지 않음).
- FR-41: 모드 스토리렛도 같은 검증을 거친다. 모드 오류는 해당 모드만 빼고 기본 콘텐츠는 계속 로딩.
- FR-42: 디버그용 질의: 지금 상태에서 후보 목록·각 가중치·탈락 사유(전제조건 X, 쿨다운 남음 n일 등)를 볼 수 있다 (밸런스·버그 조사용, 출시 빌드에서는 꺼짐).

### 화면 계약
- FR-50: 디렉터가 고른 스토리렛은 "표시 요청"으로 UI에 전달된다: 카테고리, 제목 키, 본문 키와 치환 변수(이름·숫자), 선택지 키와 비용 표시, 연출 힌트 id. UI는 결과 계산을 하지 않고 선택한 선택지 번호만 돌려준다 (rules 30).
- FR-51: 텍스트 치환 변수가 비어 있으면 표시 요청을 만들지 않고 오류로 기록 (빈 이름 "님이 ..." 같은 화면 금지).

## 경계 · 예외 상황
- 후보 0개인 주 → 아무것도 띄우지 않는다 (오류 아님). 연속 [제안] 3주 0개면 디버그 경고.
- 같은 주에 강제 스토리렛이 상한보다 많음 → 우선순위·유효 기간 짧은 순으로 처리, 나머지 다음 주로. 유효 기간이 지나기 전에 반드시 처리되는지 확인.
- 선택지 비용을 감당 못 함(돈 부족·시간 슬롯 없음) → 그 선택지는 비활성 표시 + 사유. 모든 선택지가 불가능하면 기본 선택지("넘긴다")가 정의돼 있어야 하며 없으면 로딩 오류.
- 수치 결과가 범위를 넘음 → 각 수치 스펙의 범위로 clamp. 돈은 음수 허용 여부를 032가 정함.
- 지연 결과 발동 시점에 대상이 사라짐(동료 이적, 파트너와 이별, 은퇴) → 발동하지 않고 로그. 예외 없이 처리.
- 시즌 종료일·이적시장 마감일 당일 예약 발동 순서 → 날짜 내 발동 순서를 고정 규칙으로 (예약 시점 순).
- 게임 저장·불러오기 사이에 예약 큐·쿨다운·인용 시드·긴장도가 정확히 보존 (022 세이브 왕복).
- 커리어 수십 시즌 플레이 시 스토리렛 기록 누적 → 오래된 기록 요약·압축으로 메모리·세이브 크기 상한 유지.
- 선수 사망·실제 비극 묘사 없음, 15세 등급. **모든 스토리렛(기본·모드)은 031 콘텐츠 린트(실명·금지어·등급·연령 하한)를 통과한 것만 로딩**한다. 연애·유흥 카테고리 스토리렛은 031 FR-05 연령 하한 전제조건이 없으면 로딩 오류.
- 같은 날 강제 스토리렛·지연 결과·시스템 요청(예: 이적 확정 + 결혼식)이 겹침 → 날짜 내 처리 순서 고정: 지연 결과 → 강제 → 높음 → 일반 [제안].

## 비기능 요구사항
- 결정론: 같은 세이브·같은 시드·같은 선택 순서 → 디렉터 선택·결과 완전히 동일. 해시 비교 가능하게 디렉터 결정 로그를 남긴다.
- 세이브 호환: 스토리렛 id가 콘텐츠 업데이트로 삭제돼도 세이브가 열려야 한다 (없는 id 기록은 무시하고 경고).
- 순수 C#, UnityEngine 비참조 (Career 모듈 규칙, rules 20).

## 수용 기준
- AC-01 [로직]: 전제조건이 거짓·쿨다운 남음·최대 횟수 도달·노출 가능 선택지 0개인 스토리렛은 후보에서 빠지고, 디버그 질의에 각각의 탈락 사유가 나온다.
- AC-02 [로직]: 긴장도 0.9에서 1,000회 선택 시 휴식 태그 비율이 긴장도 0.1일 때보다 높다 (가중치 표에 따른 기대 비율 ±5%p 안).
- AC-03 [로직]: 주당 일반 스토리렛 상한·카테고리당 1개 규칙이 52주 시뮬 동안 한 번도 깨지지 않는다.
- AC-04 [로직]: 강제 스토리렛은 전제조건이 맞은 뒤 유효 기간 안에 100% 발생하고, 일부러 상한을 막으면 유효 기간 만료 시 "놓침" 결과가 적용된다.
- AC-05 [로직]: 지연 결과 "3경기 뒤"는 정확히 3번째 경기 처리 직후 발동하고, 그 사이 대상 동료가 이적하면 발동하지 않고 로그가 남는다.
- AC-06 [로직]: 자신감 인용 시드 저장 후 3경기 무득점이면 콜백 스토리렛이 후보가 되고, 2경기 무득점이나 득점 발생 시에는 후보가 아니다.
- AC-07 [로직]: 최근사건 항: 결과 없음 → 50, 사기 +10 결과 1회 직후 → 60, 1주 뒤 → 57(×0.7 감쇠), 범위 밖 누적은 [0,100]으로 잘린다. 스토리렛 결과가 024 사기 값을 직접 바꾸는 경로가 없다.
- AC-08 [로직]: 일부러 오류 7종(중복 id, 없는 텍스트 키, 없는 후속 참조, 알 수 없는 질의, 선택지 0개, 선택지 5개, 지연 0 순환)을 넣은 데이터를 로딩하면 7개 오류가 모두 한 번에 보고된다.
- AC-09 [로직]: 오류 있는 모드를 넣어도 기본 콘텐츠는 로딩되고 해당 모드만 빠진다.
- AC-10 [로직]: 저장 → 불러오기 후 예약 큐·쿨다운·인용 시드·긴장도·발생 횟수가 저장 전과 같고, 이어서 10주 진행한 결과가 저장 없이 진행한 결과와 같다.
- AC-11 [결정론]: 같은 시드·같은 선택 순서로 5시즌 헤드리스 커리어를 2회 돌린 디렉터 결정 로그 해시가 같다.
- AC-12 [E2E]: 고정 세이브 픽스처에서 주를 진행하면 받은편지함에 스토리렛 카드가 뜨고, 열면 바텀시트에 선택지 3개(1개는 비용 부족으로 비활성+사유 표시)가 보인다. 선택 후 결과 요약(예: 사기 +3)이 보인다. 프로필: smoke. 치환 변수 빈칸·잘린 텍스트 없음 (ko/en).
- AC-13 [성능]: 성능 예산 표의 모든 항목이 예산 안.
