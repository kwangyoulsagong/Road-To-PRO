상태: 초안

## 배경
게임의 심장 박동이다. 플레이어는 매주 "훈련 고르기 → 컨디션 확인 → 출전/벤치 → 평점 반영 → 라이프 시간 → 이벤트"를 반복하고, 이 주가 모여 시즌이, 시즌이 모여 15세 유스부터 은퇴까지의 커리어가 된다. 여러 시스템(성장·부상·신뢰·계약·이적·라이프·스토리)이 **언제, 어떤 순서로** 돌아가는지를 이 스펙이 정한다. 순서가 흔들리면 같은 세이브에서 다른 결과가 나오고, 시즌 경계에서 날짜·계약·나이 계산이 틀리면 커리어 전체가 꼬인다.

## 범위
- 포함:
  - 게임 시간 단위(일·주·시즌)와 시간 진행 ("다음으로" 한 번 = 다음 결정 지점까지)
  - 주간 루프 단계 순서와 각 단계가 호출하는 시스템 (아키텍처 6)
  - 시즌 루프: 프리시즌 → 리그/컵 → 이적시장(여름/겨울) → 시즌 시상식 → 계약 갱신/이적 → 다음 시즌 (기획서 § 3)
  - 커리어 경로 상태: 아카데미(U16~U18) → U21/B팀 → 1군 데뷔 / 임대 / 방출 → … → 은퇴 (리서치 05 § 5.2)
  - 시즌 경계 처리: 나이 증가, 시즌 통계 마감, 다음 시즌 일정 요청, 계약 잔여 기간 감소
  - 이적 창구 열림/닫힘 시점과 마감 직전 구간 표시
  - 그 주 일정 정보(경기 수·원정·소집·재활)를 032에 넘겨 시간 슬롯을 받는 호출 (슬롯 수·규칙은 032 소유)
  - **사기(Morale) 합성식·집계·효과 범위 — 이 스펙이 소유** (입력 항은 각 스펙이 제공)
  - 헤드리스 커리어 실행 모드와 축소 월드 픽스처 (장기 시뮬 AC용)
  - 임대 성공 판정
  - 시즌 경계에서 은퇴 판정 호출(036)과 은퇴 확정 시 루프 정지
  - 내 선수가 없는 경기의 처리 호출 (016)
  - 자동 진행(여러 주 건너뛰기)과 중단 조건
- 제외:
  - 경기 전 명단 부족 처리, 경기 간 징계 누적·출전정지, 심판 배정, AI 감독 경기 중 전술 변경, 감독 경질 판단 → 050 (이 스펙은 050을 주간 루프 순서에 맞춰 호출만)
  - 일정 데이터·생성 알고리즘 (021)
  - 선발 판단과 신뢰 업데이트 공식 (025)
  - 성장·훈련 효과 (026), 부상·질병 판정 (027)
  - 계약 협상 (028), 이적 입찰·가치 (029)
  - 이벤트 선택과 디렉터 (030), 이벤트 내용 (031)
  - 라이프 행동·시간 슬롯 수 (032), 관계 (033), 미디어 (034), 국가대표 소집 (035), 은퇴 판정 공식·은퇴 처리·레거시 (036)
  - 경기 시뮬과 하이라이트 (006, 018, 041)
  - 화면 (038이 제공. 이 스펙은 루프 진행에 필요한 화면 흐름 AC만 둔다)

## 사용자 시나리오
1. 월요일 아침, "이번 주 훈련을 골라주세요" 카드가 뜬다. 훈련을 고르고 라이프 슬롯 2개를 쓴 뒤 "다음으로"를 누르면 토요일 경기 화면으로 넘어간다.
2. 감독이 나를 벤치에 앉혔다. 경기는 하이라이트 없이 결과만 보이고, 사기가 조금 떨어졌다는 알림이 뜬다.
3. 8월 말, 이적시장 마감 7일 전 배지가 일정 화면에 보인다. 에이전트 연락 이벤트가 뜬다.
4. 시즌 마지막 경기 후 시즌 시상식 → 시즌 요약(출전·골·평점·가치 변화) → 재계약/이적 단계 → 프리시즌으로 넘어간다. 나이가 한 살 올랐다.
5. 임대 간 시즌이 끝나자 "임대 성공" 판정과 원소속팀 복귀 이벤트가 뜬다.
6. 35세 시즌 말, 은퇴 고민 이벤트가 뜨고 은퇴를 고르면 커리어가 끝나 레거시 화면(036)으로 간다.

## 요구사항

### 시간
- FR-01: 게임 시간의 최소 단위는 **일**. 한 주 = 월~일 7일. 시즌 = 시즌 시작일 ~ 다음 시즌 시작일 전날. 시즌 시작일·종료일·이적 창구는 일정(021)이 제공하는 캘린더에서 읽는다.
- FR-02: 날짜는 달력 날짜(연·월·일)로 다룬다. 윤년(2월 29일) 포함. 경과일 계산은 달력 기준.
- FR-03: 시간 진행은 "다음 결정 지점까지" 단위다. 결정 지점: 주 시작(훈련 선택), 라이프 시간, 경기일, 이벤트 선택 대기, 이적 창구 열림/마감 D-7/마감, 시즌 시상식, 계약 만료 임박, 시즌 시작.
- FR-04: 자동 진행: N주 건너뛰기를 고를 수 있다. 중단 조건(내 경기 출전, 선택이 필요한 이벤트, 부상, 오퍼 도착, 창구 마감 D-7)이 생기면 즉시 멈춘다. 자동 진행 중 훈련은 마지막 선택 유지, 라이프 슬롯은 "휴식"으로 채운다 [제안].

### 주간 루프 (아키텍처 6 순서 그대로)
- FR-10: 주간 단계 순서는 고정이다:
  1. 주 시작 — 지난 주 지연 효과 적용(예: 과음 → 이번 경기 컨디션, 리서치 기획서 § 4.10 "결과는 지연해서 나타난다")
  2. 훈련 선택 (026에 전달)
  3. 컨디션·피로·부상·질병 판정 (027)
  4. 감독 선발 판단 (025)
  5. 경기 (출전 → 경기·하이라이트 / 벤치·제외 → 결과만 + 사기 하락) — 주중·주말 경기가 여러 개면 날짜 순서대로 3~5를 반복
  6. 평점 반영 → 신뢰·가치·명성 (025, 029, 034)
  7. 라이프 시간 (032)
  8. 스토리 디렉터 이벤트 (030)
  9. 주 마감 — 사기 집계, 계약 잔여일 갱신, 주간 기록 저장
- FR-11: 각 단계는 같은 입력이면 같은 순서·같은 결과를 낸다. 단계마다 그 단계 전용 RNG 스트림을 쓴다 (001 제공) — 한 단계에서 난수를 더 쓰거나 덜 써도 다른 단계 결과가 바뀌지 않는다.
- FR-12: 한 주에 내 경기가 0개(A매치 휴식 주)·1개·2개 이상인 경우를 모두 처리한다. 2경기 주는 경기 사이 회복 시간(72~96시간 원칙, 리서치 05 § 3.1)을 027에 넘긴다.
- FR-13: 내 선수가 뛰지 않는 경기(같은 리그 다른 경기, 다른 리그)는 저정밀 시뮬(016)로 같은 주 안에 계산해 순위표가 항상 최신이다.

### 주간 시간 예산
- FR-20: 주간 시간 슬롯 수와 소비·이월 규칙은 **032 FR-01~03이 정의**한다. 이 스펙은 주 시작(FR-10 단계 1)에 그 주 일정 정보(내 경기 수, 원정 여부, 국가대표 소집(035), 부상 재활(027))를 032에 넘기고, 라이프 단계(FR-10 단계 7)에서 032가 확정한 슬롯을 쓴다.
- FR-21: (삭제 — 032 FR-03으로 이동)

### 시즌 루프
- FR-30: 시즌 단계: 프리시즌 → 리그·컵 진행(이적시장 여름/겨울 포함) → 시즌 시상식 → 계약 갱신·이적 → 다음 시즌 프리시즌 (기획서 § 3).
- FR-31: 이적 창구: 하계 약 9주, 동계 약 4주 (리서치 05 § 1.3, [U]). 실제 날짜는 캘린더(021)가 제공. 마감 직전 7일은 "마감 임박" 상태로 표시하고 029에 알린다 (Urgency 급상승 구간).
- FR-32: 시즌 경계(시즌 마지막 날 → 다음 시즌 첫날)에서 이 순서로 처리한다: 시즌 통계 마감 → 시상식 → 은퇴 판정(FR-50) → 임대 종료 판정(FR-42) → 계약 만료 처리(028) → 다음 시즌 캘린더 요청(021: 첫 시즌만 실제, 2시즌부터 생성) → 승강 반영(020/021) → 시즌 카운터 +1.
- FR-33: 나이는 생일에 오른다 (시즌 경계가 아님). 나이 의존 공식(성장 g(age), 부상 M_age, 가치 f_age, 은퇴)은 계산 시점의 만 나이를 쓴다.
- FR-34: 시즌 요약: 출전·선발·분·골·어시스트·평균 평점·시장가치 변화·신뢰 변화. 시즌 통계는 시즌 단위로 영구 보관(커리어 기록).

### 커리어 경로
- FR-40: 커리어 상태: `아카데미` → `U21/B팀` → `1군` / `임대(하위 티어)` / `방출 → 하부 리그·해외` → `은퇴` (리서치 05 § 5.2). 상태 전이는 이 스펙이 관리하고, 전이 계기(계약·이적·임대 성사, 방출)는 028/029/030이 알린다.
- FR-41: 1군 데뷔 시점(첫 1군 공식 경기 출전)을 기록하고 데뷔 이벤트를 디렉터(030)에 알린다.
- FR-42: 임대 성공 판정 = 출전 비율 ≥ 50% 그리고 평균 평점 ≥ 평점 기대치 (리서치 05 § 5.2). 평점 기대치는 025 FR-21이 정의한 값을 그대로 쓴다. 성공: 원소속팀 Trust +15(025에 전달), 시장가치 상승(029). 실패: 2차 임대·방출 확률 상승.
- FR-43: 출전 비율은 025 FR-41의 정의(출전 분 / 출전 가능했던 경기 총 분, 부상·질병·징계·소집 기간 제외)를 그대로 쓴다. 출전 가능 경기 0이면 임대 판정은 "판정 불가 → 실패 아님, 복귀만" [제안].

### 사기 (Morale) — 이 스펙이 소유
- FR-45: 주 마감에 사기를 다시 계산한다: `Morale = 0.3·출전만족 + 0.2·팀성적 + 0.15·관계평균 + 0.15·연봉만족 + 0.1·생활 + 0.1·최근사건` (리서치 05 § 7.3). 결과는 0~100으로 자른다. 각 항(0~100)의 제공 스펙:

  | 항 | 제공 | 정의 위치 |
  |---|---|---|
  | 출전만족 | 025 | 025 FR-43 |
  | 팀성적 | 024 (이 스펙) | FR-47 |
  | 관계평균 | 033 | 033 FR-04 |
  | 연봉만족 | 028 | 028 FR-15 |
  | 생활 | 032 | 032 FR-50 |
  | 최근사건 | 030 | 030 FR-30 |

  다른 스펙은 사기를 따로 계산하지 않는다. 사기를 직접 바꾸는 이벤트 결과(030 FR-05)는 최근사건 항을 통해서만 들어온다.
- FR-46: 사기 효과: 훈련 성장률(026)과 경기 평점(015)에 ±5% (리서치 05 § 7.3). 사기 50 = 보정 0, 0 = −5%, 100 = +5%, 선형 [제안]. 효과 적용은 026·015가 이 스펙의 사기 값을 읽어서 한다.
- FR-47: 팀성적 항 [제안] = 50 + 50·clamp((기대 순위 − 현재 리그 순위) / (팀 수/2), −1, 1). 기대 순위 = 시즌 시작 시 클럽 명성 순위(020). 시즌 첫 3경기 전에는 50.

### 은퇴 (호출만 — 판정·처리는 036 소유)
- FR-50: 시즌 경계 처리(FR-32)의 "은퇴 판정" 단계에서 036 FR-01~05의 판정을 월드 전체에 호출한다. 확률식·임계값·내 선수 비강제 원칙은 036이 정의한다.
- FR-51: 027의 커리어 위협 경로(시즌 중 발생 가능)는 036 FR-03으로 바로 간다. 이 스펙은 은퇴 확정 알림만 받는다.
- FR-52: 은퇴 확정 → 커리어 상태 `은퇴` → 036으로 넘긴다. 이후 주간 루프는 돌지 않는다.

### 헤드리스 커리어 실행 모드
- FR-55: 화면 없이 커리어를 끝까지 돌리는 모드. 선택은 정책 함수(무작위·탐욕·고정 스크립트)로 대신한다. 장기 시뮬 AC(024 AC-12, 030~036의 다시즌 결정론·분포 AC, 031 도달 가능성)는 이 모드를 쓴다.
- FR-56: 축소 월드 픽스처 [제안]: 1개국·리그 2개(18팀·20팀)·선수 약 1,700명. 이 모드에서는 내 경기도 저정밀(016)로 계산할 수 있다(옵션). 기본 세계와 같은 규칙을 쓰고 규모만 줄인다.

### 저장과 복구
- FR-60: 주 마감마다, 그리고 내 경기 시작 직전에 자동 저장 지점을 만든다 (022 FR-35). 진행 중 앱이 꺼지면 마지막 저장 지점으로 돌아온다. 경기 중 저장은 없다 (022 FR-36, 확정 (2026-11-02 사용자 결정)).
- FR-61: 루프 상태(현재 날짜, 현재 단계, 대기 중인 선택, RNG 스트림 위치)는 전부 세이브에 들어간다. 로드 후 진행 결과는 저장 전 계속 진행한 결과와 같다.

### 화면 흐름 (루프 진행에 필요한 것만)
- FR-70: 홈 화면에 현재 날짜, 이번 주 단계 진행 표시, 다음 경기, "다음으로" 버튼. 다음 결정 지점 이름이 버튼에 보인다 ("훈련 고르기", "경기 보기").
- FR-71: 시즌 요약 화면: FR-34 항목을 큰 숫자 카드로.
- FR-72: 자동 진행 바텀시트: 1주 / 2주 / 다음 경기까지 / 창구 마감까지. 중단되면 이유 한 줄.

- 2월 29일 생일: 평년에는 [제안] 3월 1일에 나이 증가.
- 시즌 시작일이 주 중간(수요일 등)인 실제 일정 — 첫 주는 짧은 주로 처리.
- 같은 날 경기 2개(이론상 불가)·연속일 경기 — 일정 데이터 검증에서 거부하거나 순서대로 처리.
- 이적 창구 마감일 = 경기일인 경우, 마감 처리와 경기 처리의 순서 고정 [제안: 경기 먼저, 마감은 그날 끝].
- 커리어 도중 시작(실제 일정과 안 맞음) → 021의 자동 생성 대체 경로.
- 시즌 경계에 계약 만료·임대 종료·감독 경질·은퇴 고민이 동시에 생김 — FR-32 순서로만 처리, 이벤트는 디렉터 큐에 순서대로.
- 부상으로 시즌 전체 결장 (출전 0분) → 출전 비율 0, 평균 평점 정의 없음(평균 계산에서 0으로 나누기 금지).
- 임대 중 원소속팀 감독 경질 → 복귀 시 신뢰는 025 규칙.
- 자동 진행 52주 이상 요청 → 시즌 경계에서 반드시 한 번 멈춤 (시상식은 건너뛰지 않음) [제안].
- 은퇴 후 로드한 세이브에서 "다음으로"를 눌러도 루프가 돌지 않는다.
- 40세 이상까지 은퇴를 계속 거절 → 036 FR-04(무소속 장기화 → 은퇴 권유) 경로. 이 스펙은 루프만 계속 돈다.
- 사기 입력 항 중 일부가 아직 없음(예: 파트너 없음, 시즌 첫 경기 전) → 각 제공 스펙의 기본값(033 FR-04 정규화, FR-47 기본 50)으로 계산. 0으로 나누기 금지.
- 생일이 시즌 경계일과 같음 → 나이 증가가 먼저, 시즌 경계 처리가 나중 [제안] (FR-33 만 나이 기준).
- 이적 창구 마감일 = 시즌 경계일 → 마감 처리 후 시즌 경계 처리.
- 연도 표기 4자리 초과(커리어 25년 이상) 문제 없음.

## 비기능 요구사항

## 수용 기준
- AC-01 [결정론]: 같은 세이브에서 같은 선택으로 10주 진행을 2회 하면 상태 해시가 같다. 10주 자동 진행과 1주씩 10번 진행도 같다.
- AC-02 [결정론]: 한 단계(예: 라이프)에서 난수를 1회 더 쓰게 바꿔도 다른 단계(부상 판정, 선발) 결과가 같다.
- AC-03 [로직]: 주간 단계 실행 순서 기록이 FR-10 순서와 같다. 경기 2개 주에서는 경기 순서대로 3~5가 반복된다. 경기 0개 주에서는 4~6이 생략된다.
- AC-04 [로직]: 시즌 경계 처리 순서가 FR-32와 같다 (계약 만료·임대 종료·은퇴 고민이 동시에 있는 픽스처).
- AC-05 [로직]: 2월 29일생 선수의 나이가 평년·윤년에 기대한 날 오른다. 시즌 경계는 나이를 바꾸지 않는다.
- AC-06 [로직]: 이적 창구 상태가 캘린더 픽스처의 열림·D-7·마감 날짜에 정확히 바뀐다.
- AC-07 [로직]: 임대 성공 판정 경계: 출전 비율 49.9%/50.0%, 평점 기대치 −0.01/정확히 — 표의 모든 행이 기대 결과. 출전 0분 시즌에서 예외 없이 실패 판정.
- AC-08 [로직]: 사기 공식이 FR-45와 같고, 각 항 0/50/100 경계값 조합에서 결과 ∈ [0,100]이다. 사기 0/50/100의 성장·평점 보정이 −5%/0/+5%다 (FR-46). 팀성적 항이 FR-47 경계(1위·꼴찌·기대 순위와 같음·시즌 첫 3경기 전)에서 100/0/50/50 근처 기대값이다.
- AC-09 [로직]: 시즌 경계 처리에서 036 은퇴 판정이 FR-32 순서대로 정확히 1회 호출되고, 은퇴 확정 알림을 받으면 그 뒤 "다음으로"가 루프를 돌리지 않는다.
- AC-10 [로직]: 자동 진행이 중단 조건(출전 경기, 오퍼, 부상, 창구 D-7, 선택 이벤트) 각각에서 멈춘다.
- AC-11 [로직]: 저장 → 로드 → 5주 진행 결과가 저장 없이 5주 진행한 결과와 같다 (중간 단계에서 저장한 경우 포함).
- AC-12 [로직]: 헤드리스 모드(FR-55)·축소 월드(FR-56)로 15세 시작 → 은퇴까지 커리어 100회를 돌려 예외·무한 루프 0, 콘솔 경고 0, 모든 커리어가 은퇴 상태로 끝난다 (은퇴 연령 분포는 036 AC-02가 검증). `[Category("Slow")]`.
- AC-13 [E2E]: `e2e/024-week-loop` — 홈 → 훈련 선택 → 라이프 → 경기 → 주 마감까지 각 단계 캡처, "다음으로" 버튼에 다음 결정 지점 이름이 보인다. 프로필: 전체.
- AC-14 [E2E]: `e2e/024-season-end` — 시즌 마지막 경기 픽스처 → 시상식 → 시즌 요약 큰 숫자 카드 → 프리시즌. 프로필: smoke.
- AC-15 [E2E]: `e2e/024-auto-advance` — 4주 자동 진행 중 오퍼 도착으로 멈추고 이유 한 줄이 보인다. 프로필: smoke.
- AC-16 [성능]: 성능 예산 표 항목이 기준 프로필에서 예산 안.
