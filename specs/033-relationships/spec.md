# 033 — 관계: 동료 케미 · 연애 · 결혼 · 가족

상태: 초안
브랜치: feat/033-relationships

## 배경
선수 한 명의 커리어는 사람들과의 관계로 만들어진다 (기획서 1.2 "커리어 = 관계와 선택"). 동료와의 케미는 경기 안에서 패스가 누구에게 가는지를 바꾸고, 연인·가족은 사기와 일관성, 이적 결정에 영향을 준다. 자녀는 은퇴 후 2세대 커리어로 이어진다. 이 스펙은 관계 수치와 그 변화·효과 규칙을 정한다.

## 범위
- 포함:
  - 관계 대상과 수치: 동료(개별), 에이전트, 가족, 파트너 — 각 `Affinity(-100~100)`, `Respect(0~100)` (리서치 05 §7.3). 감독 관계는 025 Trust 하나로, 팬·언론 관계는 034 팬 평판·언론 평판으로 표현한다 (같은 개념을 두 스펙이 따로 두지 않는다).
  - 동료 관계 변화 규칙 (같이 뛴 시간, 어시스트 주고받기, 버릇, 회식, 다툼 이벤트, 포지션 경쟁)
  - 케미스트리 → 경기 엔진 입력: 패스 대상 선택 가중치 (010이 사용)
  - 연애: 만남 경로(파티, 지인 소개, SNS, 연예인), 데이트 장소 선택, 관계도(호감·신뢰), 공개 연애, 이별
  - 결혼·가족: 프러포즈, 결혼식, 자녀, 가족의 이적 의견, 가족 병환·고향 방문 훅
  - 효과: 관계 안정 → 사기·집중력(일관성) 상승, 연애 스캔들 → 034 언론 이벤트, 가족 의견 → 029 이적 결정 입력
  - 자녀 기록 → 036 뉴게임+ 입력
  - 사기 식(024 FR-45)의 "관계평균" 항
  - 관계 화면 데이터 계약 (메신저 대화 화면 형식, 기획서 4.10)
- 제외:
  - 감독과의 관계 → 025 Trust (이 스펙에는 감독 Affinity가 없다)
  - 팬·언론 관계 → 034 팬 평판·언론 평판
  - 에이전트 등급·협상 → 028
  - 이벤트 콘텐츠 → 031, 디렉터 → 030
  - 시간 슬롯·돈 예산 → 032 (데이트·가족 활동은 032 예산을 씀)
  - 메신저 화면 구현 → 038

## 사용자 시나리오
1. 같은 측면에서 2시즌 같이 뛴 풀백과 케미가 높아져, 경기 중 내 윙어가 그 풀백에게 패스하는 비율이 눈에 띄게 늘었다.
2. 이기주의 버릇 때문에 공격수 동료와 관계가 나빠졌다. 그 동료가 나에게 패스를 덜 준다.
3. 파티에서 만난 사람과 데이트를 이어가다 공개 연애를 했다. 관계가 안정되자 사기가 올랐다. 그런데 해외 빅클럽 오퍼가 오자 파트너가 반대한다.
4. 결혼 후 자녀가 생겼다. 은퇴 화면에서 "자녀로 2세대 커리어 시작"이 열린다.

## 요구사항

### 관계 수치
- FR-01: 관계 대상마다 `Affinity`(−100~100, 0 = 무관심)와 `Respect`(0~100)를 가진다 (리서치 05 §7.3). 초기값 [제안] 동료 Affinity 0·Respect = 능력 차이 기반, 가족 Affinity 60.
- FR-02: 모든 변화는 사유(이벤트 id·경기·활동)와 함께 기록 (디버그·리포트용, 최근 [제안] 20개 유지).
- FR-03: 감쇠: 상호작용이 없으면 Affinity가 0 쪽으로 서서히 이동 [제안] 주당 1% (가족·배우자는 [제안] 0.3%).
- FR-04: 관계평균(024 FR-45 사기 식 입력, 0~100) = 가중 평균(파트너 Affinity, 가족 Affinity 평균, 친한 동료 상위 3명 Affinity 평균 — 각각 (A+100)/2로 0~100 변환, 감독은 025 Trust 값 그대로) [제안] 가중치 파트너 0.25, 가족 0.2, 동료 상위 3명 0.35, 감독(025 Trust) 0.2. 파트너 없음·동료 3명 미만 → 있는 항의 가중치로 정규화. 모든 항이 없으면 50.

### 동료 · 케미스트리
- FR-10: 동료 Affinity 변화 요인 [제안 값]: 같이 출전한 분 (90분당 +0.5), 나에게 어시스트(+2) / 내가 어시스트(+2), 같은 포지션 주전 경쟁 중(주당 −0.5), 회식(032, +2), 다툼·화해 이벤트(031), 버릇(기획서 4.2.1: 이타적 → 같이 뛴 동료 +, 이기주의 → 공격진 동료 −, 드리블 중독 → 볼 손실 시 근처 동료 −).
- FR-11: 케미스트리(쌍 단위, 0~1) = f(서로의 Affinity, 같이 뛴 누적 시간, 같은 국적·언어 [제안] 보너스). 같이 뛴 시간이 없으면 0.
- FR-12: 경기 엔진 입력: 패스 대상 후보 점수에 케미 보정 [제안] ×(1 + 0.15·chemistry) (기획서 4.5 "패스 선택 확률에 반영"). 보정은 Utility 점수 단계에서만 (010 FR-14가 이 값을 읽어 적용), 패스 성공 판정에는 영향 없음. 상한 [제안] ×1.15.
- FR-13: 경기 엔진에는 경기 시작 시 스냅샷으로 넘긴다 (경기 중 관계 변화가 같은 경기 시뮬에 피드백되지 않게 → 결정론·재시뮬(019) 일관성).
- FR-14: 모든 AI 선수 쌍의 케미를 다 계산하지 않는다. 내 선수가 속한 팀의 1군 쌍만 정밀, 그 외 팀은 팀 평균 케미 하나 [제안].

### 연애
- FR-20: 만남 경로 (기획서 4.10): 파티(032 활동), 지인 소개(동료 Affinity 높을 때), SNS(034 팔로워), 연예인(명성 높을 때). 각 경로는 031 이벤트로 시작.
- FR-21: 관계 단계: 알게 됨 → 데이트 중 → 연인(비공개) → 공개 연애 → 약혼 → 결혼, 그리고 이별(어느 단계에서든). 단계 이동은 호감·신뢰 임계 + 이벤트 선택으로.
- FR-22: 데이트: 장소 선택(비용·슬롯은 032), 결과로 호감·신뢰 변화. 같은 장소 반복 시 효과 감소 [제안].
- FR-23: 효과 (기획서 4.10): 관계 안정(연인 이상, 신뢰 ≥ [제안] 60) → 사기 보정·일관성(숨김 능력치) 보정 [제안] +2 (최대). 연애 스캔들(공개 연애·이별·파파라치) → 034 언론 이벤트 훅.
- FR-24: 동시에 여러 파트너 → 지원하지 않는다 [제안]. 새 연애 시작은 현재 파트너 없음일 때만.
- FR-25: 표현: **암시적 표현(화면 전환·텍스트)만, 노골적 성적 묘사 없음** (기획서 4.10, rules 01). 연애 단계의 연령 하한은 031 FR-05 `adultContentMinAge` 하나만 읽는다.
- FR-26: 파트너·가족·"연예인" 만남 상대는 모두 020 이름 규칙으로 만든 **가상 인물**이다. 실존 연예인·유명인 이름·이미지 연상 금지 (01-legal, 020 FR-33 필터 적용).

### 결혼 · 가족
- FR-30: 가족 구성: 부모(시작 시 생성), 배우자(결혼 시), 자녀(0명 이상). 가족 병환·고향 방문 이벤트 훅(031).
- FR-31: 가족의 이적 의견 (기획서 4.10): 해외 이적·먼 이적에 대해 배우자·가족이 찬성/반대 의견을 가진다. 의견 = f(가족 Affinity, 거리·언어 변화, 자녀 나이). 029 이적 결정 화면에 의견으로 표시되고, 반대를 무릅쓰고 이적하면 가족 Affinity 하락 + 사기 하락 [제안].
- FR-32: 자녀: 출생 이벤트로 생성. 자녀 기록(출생 시즌, 이름, 성향 시드)을 남긴다. 036 뉴게임+가 이 기록으로 2세대 선수를 만든다 (기획서 4.8).
- FR-33: 결혼 효과 (기획서 4.10): 안정감 → 일관성 보정 [제안] +1, 사기 하한 보정.

### 화면 계약
- FR-40: 관계 화면 데이터 (메신저 대화 화면 형식, 기획서 4.10): 대상 목록(이름·관계 단계·Affinity 화살표 표시), 대화 기록(최근 이벤트 텍스트 키), 동료 케미 상위 5명.
- FR-41: 수치는 정확한 숫자 대신 단계·화살표로 보여준다 [제안] (숨김 성격 유지).

## 경계 · 예외 상황
- 동료가 이적·은퇴 → 관계 기록은 보존(옛 동료로), 케미는 같은 팀이 아니면 경기 입력에서 제외. 다시 같은 팀이 되면 기록에서 이어감.
- 내가 이적 → 새 팀 동료 Affinity 초기화, 옛 팀 동료는 "옛 동료"로 보존.
- Affinity·Respect 범위 경계(−100, 100, 0, 100) → clamp. 감쇠가 0을 넘어 부호를 바꾸지 않는다.
- 파트너와 이별 직후 같은 주 새 만남 → 쿨다운 [제안] 4주.
- 결혼식·출산이 경기일과 겹침 → 이벤트는 경기 다음 날로 미루거나 결장 선택지 (024 일정과 협의, 030 날짜 내 순서 규칙).
- 연령 하한 미만: 연애·결혼 이벤트 없음, 가족(부모) 관계만. 하한 생일 당일 이후부터 만남 이벤트 후보.
- 사기 입력에 감독 항을 넣을 때 감독 교체 직후(025 FR-30 리셋) → 리셋된 Trust 그대로 사용 (별도 처리 없음).
- 결혼·출산·이별이 이적 확정과 같은 주 → 030 날짜 내 처리 순서 규칙, 가족 의견은 이적 확정 전 값으로 판정.
- 자녀 수 상한 [제안] 4. 뉴게임+ 후보 자녀 0명이면 036이 "제자" 경로로 대체.
- 케미 계산 대상 쌍 수 폭발 방지 (FR-14).

## 비기능 요구사항
- 결정론: 관계 변화·만남·의견은 시드 RNG. 경기 엔진에 넘기는 케미 스냅샷은 정렬된 순서(선수 id 순)로 만든다 (Dictionary 순회 의존 금지, rules 20).
- 세이브 호환: 관계 기록·가족·자녀 기록이 저장·불러오기 후 동일 (022). 자녀 기록은 뉴게임+ 세이브로 넘어간다.
- 순수 C#, UnityEngine 비참조.

## 수용 기준
- AC-01 [로직]: 같이 출전·어시스트·주전 경쟁·회식·버릇별 Affinity 변화가 규칙 값과 같고, 범위 경계에서 clamp, 감쇠가 부호를 바꾸지 않는다.
- AC-02 [로직]: 관계평균 계산이 파트너 있음/없음, 동료 0·1·3명, 모든 항 없음(→ 50) 경우 모두 가중치 정규화가 맞고, 감독 항이 025 Trust 값과 같다 (경계값 표).
- AC-03 [로직]: 케미 0 vs 1인 두 동료가 같은 조건에 있을 때 패스 대상 점수 비가 정확히 1 : 1.15이고, 패스 성공 판정 확률은 같다.
- AC-04 [로직]: 경기 중 관계 변화가 같은 경기의 케미 입력에 반영되지 않는다 (스냅샷 고정).
- AC-05 [로직]: 연애 단계 이동이 정의된 순서만 허용되고(건너뛰기 불가), 이별은 어느 단계에서든 가능하며, 031 FR-05 연령 하한 미만에는 연애 단계가 생기지 않는다 (하한 값을 바꾸면 결과도 따라 바뀐다). 파트너가 있으면 새 만남 이벤트가 후보가 아니다.
- AC-06 [로직]: 해외 이적 오퍼에 대해 가족 의견이 계산되어 029에 전달되고, 반대를 무릅쓴 이적 후 가족 Affinity·사기가 규칙대로 떨어진다.
- AC-07 [로직]: 자녀 출생 기록이 세이브에 남고 036이 읽을 수 있는 형태다 (필드 누락 없음).
- AC-08 [로직]: 동료 이적 → 옛 동료 보존·경기 케미 제외, 재합류 시 기록 이어짐.
- AC-09 [결정론]: 같은 시드·같은 선택으로 10시즌 헤드리스 커리어 2회 → 관계 로그·케미 스냅샷 해시 동일.
- AC-10 [로직]: 같은 시드 세트로 케미 보정 켬/끔 1,000경기씩 헤드리스 시뮬: 케미 상위 쌍(chemistry ≥ 0.8) 간 패스 비율의 상대 증가가 [제안] ≥ 5%이고, 부트스트랩 95% 신뢰구간 하한 > 0. 전체 패스 성공률 차이는 ±0.5%p 이내 (성공 판정 무영향 확인).
- AC-11 [E2E]: 고정 픽스처(파트너 있음, 자녀 1명, 동료 25명)에서 관계 화면을 열면 메신저 형식 목록·대화 기록·케미 상위 5명이 보이고, 정확한 수치 대신 단계·화살표가 보인다. 프로필: 전체 (ko/en × light/dark). 긴 이름이 잘리지 않고 말줄임 처리된다.
- AC-12 [E2E]: 이적 결정 픽스처에서 가족 반대 의견이 이적 화면에 보인다 (029 화면 위 표시 부분만). 프로필: smoke.
- AC-13 [성능]: 성능 예산 표 항목이 예산 안.
