## 배경
국가대표 발탁은 선수 커리어의 큰 이정표다. 연령별 대표에서 시작해 A대표로 올라가고, 메이저 대회에 나가고, 언젠가 대표팀에서 은퇴한다. 발탁은 시장가치·연봉·명성을 올리지만, 소집 기간에는 클럽 일정·라이프 시간이 줄고 피로가 쌓인다. 이 스펙은 대표팀 선발, 소집, 대표팀 경기, 메이저 대회, 기록을 정한다.

## 범위
- 포함:
  - 대표팀 단계: 연령별(U17 / U19 / U21 [제안]) → A대표
  - 대표팀 감독의 선발 규칙 (소집 명단 크기, 후보 풀, 점수)
  - 소집 기간: 021 캘린더의 A매치 기간 사용. 소집 중 클럽 활동·라이프 슬롯 변화(032), 피로·부상 위험(027)
  - 대표팀 경기: 친선·예선·본선. 내 선수가 뛰는 대표팀 경기는 정밀 시뮬(+ 하이라이트), 그 외는 저정밀(016)
  - 메이저 대회: 주기·예선·본선 일정 생성 (가상 대회명)
  - 대표팀 기록: 캡 수, 골, 대회 출전·성적 → 036 레거시, 034 명성, 029 시장가치, 028 연봉 인상 트리거
  - 대표팀 은퇴 (선수 선택 또는 장기 미발탁)
  - 국적·이중국적 처리 (023 선수 생성의 국적 사용)
- 제외:
  - 국가·대표팀 구성 데이터 생성 → 020 (가상 국가)
  - A매치 기간 날짜 자체 → 021
  - 경기 시뮬 → 006~019, 저정밀 → 016
  - 이벤트 텍스트(첫 발탁, 탈락 등) → 031
  - 연봉 인상 계산 → 028 (이 스펙은 발탁 사실만 알림)

## 사용자 시나리오
1. 18세에 리그에서 좋은 평점을 이어가자 U19 대표에 첫 발탁 이벤트가 뜬다.
2. 23세, 소속팀 주전으로 시즌 중반 A대표에 발탁됐다. 소집 기간 동안 라이프 시간이 줄고, 소속팀 복귀 후 피로가 남아 있다.
3. 메이저 대회 본선에서 내 선수의 경기가 하이라이트로 재생된다. 대회가 끝나면 캡·골이 기록에 쌓인다.
4. 32세, 대표팀 감독이 세대교체를 하며 탈락. 1년 뒤 "국가대표 은퇴" 선택 이벤트가 뜬다.

## 요구사항

### 대표팀 단계 · 자격
- FR-01: 대표팀 단계 [제안]: U17(만 17세 이하), U19, U21, A대표. 연령 기준일은 대회 주기 시작 연도 1월 1일 [제안].
- FR-02: 자격: 국적(023). 이중국적이면 A대표 공식 경기 출전 전까지 선택 가능, 출전 후 고정 [제안]. 선택은 031 이벤트.
- FR-03: 동시에 두 단계 소집 불가. 같은 A매치 기간에 A대표와 연령별이 겹치면 A대표 우선.

### 선발
- FR-10: 소집 명단 크기 [제안] 연령별 23명, A대표 26명. 포지션 쿼터(GK 3 이상 등).
- FR-11: 후보 풀: 그 국적의 해당 연령 선수 전체 (020 월드 + 내 선수). 대표팀 감독 점수 [제안] = 0.5·능력(포지션 기준) + 0.2·최근 폼(평점 EMA) + 0.1·리그 수준 + 0.1·대표팀 경력 + 0.1·감독 성향 보정(유스 선호 등). 025 선발 점수 구조를 대표팀 버전으로 재사용 (리서치 05 §3.2 형식).
- FR-12: 부상·질병(027)으로 결장 중인 선수는 소집 제외. 소집 후 부상 → 교체 소집.
- FR-13: 내 선수의 발탁 가능성 힌트: 대표팀 감독 관심도(낮음/보통/높음)를 화면에 표시 [제안]. 정확한 점수는 숨김.
- FR-14: 모든 국가 대표팀을 매번 정밀 선발하지 않는다. 내 선수 국적 대표팀만 정밀 선발, 나머지 국가는 대회 시뮬용 팀 강도 하나 [제안].

### 소집 기간
- FR-20: A매치 기간 횟수·날짜는 021 FR-24가 소유하고 이 스펙은 읽기만 한다. 소집 기간 동안 1·2부 클럽 경기 없음(021 FR-24 보장), 클럽 훈련 대신 대표팀 훈련. 하위 리그(021 FR-24 [미정])에서 소집과 클럽 경기가 겹치면 소집 우선, 클럽 경기는 "소집 결장"으로 처리하고 025 출전 비율 분모에서 뺀다 (025 FR-41).
- FR-21: 소집 중 라이프 슬롯 감소 (032 FR-01 "원정·소집 주"). 장거리 이동 피로 [제안] +이동 거리 비례.
- FR-22: 소집 후 클럽 복귀 시 피로·부상 상태를 027·025에 그대로 전달 (클럽 감독 선발에 반영).

### 대표팀 경기 · 대회
- FR-30: 경기 종류: 친선, 예선, 본선(조별·토너먼트). 일정은 이 스펙이 대회 형식으로 생성하고 날짜는 021 A매치 기간 안에 배치.
- FR-31: 메이저 대회 [제안]: 대륙 대회·세계 대회 각각 4년 주기, 서로 2년 엇갈림. 본선은 시즌 사이 여름. 가상 대회명·가상 국가 (rules 01).
- FR-32: 내 선수가 명단에 있는 경기는 정밀 시뮬(006~) + 하이라이트(018), 다른 경기는 저정밀(016).
- FR-33: 토너먼트 무승부 → 연장·승부차기 (012 규칙). 조별 순위 동률 규칙 [제안] 승점 → 득실 → 다득점 → 상대전적 → 추첨(시드 RNG).

### 기록 · 효과
- FR-40: 기록: 단계별 캡 수, 골, 어시스트, 대회 출전 목록·성적, 주장 여부, 첫 발탁 날짜.
- FR-41: 효과 알림 (수신 스펙이 계산): A대표 첫 발탁 → 028 연봉 자동 인상 트리거(리서치 05 §2), 029 시장가치 변수(리서치 05 §1 국가대표 여부), 034 명성 상승, 031 이벤트(첫 발탁·메이저 대회·탈락), 036 레거시 점수(대표팀 기록).
- FR-42: 대표팀 은퇴: 선수가 선택(031 이벤트) 또는 [제안] A대표 미발탁 3년 + 32세 이상이면 자동 "사실상 은퇴" 상태. 은퇴 후 선발 후보 제외.

### 화면 계약
- FR-50: 대표팀 화면: 현재 단계·관심도, 다음 A매치 기간 날짜, 최근 명단(발탁 시), 기록(캡·골 큰 숫자), 대회 일정·결과.

## 경계 · 예외 상황
- 연령 경계: 기준일 당일 생일 → 규칙 고정(기준일 기준 만 나이). 시즌 중 생일로 연령별 자격이 바뀌어도 그 대회 주기 동안 유지 [제안].
- 국적 대표팀 후보가 명단 크기보다 적음(작은 가상 국가) → 있는 인원만 + 경고 없이 진행, 포지션 쿼터 부족은 다른 포지션으로 채움.
- A매치 기간에 클럽 경기가 잡혀 있음(021 버그) → 이 스펙은 소집 거부하지 않고 오류 기록 (021 검증과 연결).
- 소집 중 이적시장 마감 → 이적 처리는 029가 하고 소집은 유지.
- 내 선수가 부상으로 대회 전체 결장 → 대회는 저정밀로 진행, 기록에는 미출전.
- 은퇴(036) 후 대표팀 소집 이벤트 금지.
- 소집 기간이 시즌 경계·이적 창구 마감과 겹침 → 소집은 유지, 시즌 경계·마감 처리는 024 순서대로 (소집 중에도 처리됨).
- 대표팀 경기 중 부상 → 027이 같은 규칙으로 판정, 결장일은 클럽 복귀 후에도 이어진다.
- 대표팀 기록 저장 → 로드 후 대회 진행 상태(조별 순위·대진)가 같다.
- 메이저 대회 본선 여름과 프리시즌 겹침 → 본선 진출 선수의 프리시즌 시작 지연 (024에 알림).

## 비기능 요구사항
- 결정론: 선발·대회 시뮬·추첨은 시드 RNG. 같은 월드·같은 시드 → 같은 명단·같은 대회 결과.
- 세이브 호환: 대표팀 기록·대회 진행 상태 저장·불러오기 동일 (022). 대회 진행 중 저장 가능.
- 순수 C#, UnityEngine 비참조.

## 수용 기준
- AC-01 [로직]: 연령 기준일 전날·당일·다음날 생일 선수의 연령별 자격이 규칙대로 갈린다.
- AC-02 [로직]: 소집 명단이 크기·포지션 쿼터를 지키고, 결장 중인 선수는 빠지며, 소집 후 부상 시 교체 소집된다.
- AC-03 [로직]: 같은 A매치 기간 A대표·연령별 동시 선발 시 A대표만 소집된다.
- AC-04 [로직]: 이중국적 선수는 A대표 공식 경기 출전 전까지 선택 가능, 출전 후 다른 국적 후보에서 빠진다.
- AC-05 [로직]: 조별 순위 동률 규칙(승점 → 득실 → 다득점 → 상대전적 → 추첨)이 경계 케이스 6개에서 맞다.
- AC-06 [로직]: 첫 A대표 발탁 시 028·029·034·031·036으로 가는 알림이 각각 1회만 발생한다.
- AC-07 [로직]: 미발탁 3년 + 32세 이상이면 사실상 은퇴 상태가 되고 이후 선발 후보에서 빠진다.
- AC-08 [로직]: 메이저 대회 주기가 4년·2년 엇갈림으로 20시즌 동안 맞게 생성되고, 모든 대표팀 경기가 021 A매치 기간 안에 있다.
- AC-09 [결정론]: 같은 월드·같은 시드로 10시즌을 2회 돌린 대표팀 명단·대회 결과·기록 해시가 같다.
- AC-10 [E2E]: 고정 픽스처(A대표 캡 24, 다음 A매치 기간 예정, 대회 진행 중)에서 대표팀 화면을 열면 단계·관심도·다음 소집 날짜·캡/골 큰 숫자·대회 일정이 보인다. 프로필: 전체 (ko/en × light/dark).
- AC-11 [E2E]: 첫 발탁 이벤트 픽스처에서 이벤트 카드 → 바텀시트 → 대표팀 화면 갱신(단계 표시 변경)까지 캡처. 프로필: smoke.
- AC-12 [성능]: 성능 예산 표 항목이 예산 안.
