# 034 — 미디어 · 팬 · 평판 · 스폰서

상태: 초안
브랜치: feat/034-media-reputation
기획 출처: docs/index.html § 기획서 4.5(팬/미디어 평판: 인터뷰 답변 선택이 이적시장 가치와 이벤트에 영향), 4.10(명성·미디어: SNS 게시, 광고 촬영, 자선, 인터뷰 / 팔로워 → 스폰서 수입, 자선 → 평판 회복 / 라이프스타일 등급 → 스폰서 제안·팬 이미지), 4.2.1(버릇: 쇼맨 → 팬 인기↑, 다이버 → 심판·언론 평판↓), 4.6.2(미디어·팬 30) / § 리서치 05 §7.3(미디어 인터뷰 톤 4종·인용 시드·콜백, 소셜미디어: 팔로워 수·성향 분포, 논란 확률 = 도발도 × 노출도), §7.1(명성·연봉을 wealth로 보고 미디어 압박 크기 결정), §8(NSS: 소비 → 라이프스타일 등급 → 스폰서) / § 리서치 07 §3.4(뉴스·SNS 템플릿, 판정 논란 기사 트리거)

## 배경
선수의 가치는 경기장 안에서만 정해지지 않는다. 인터뷰 한 마디, SNS 게시물, 자선 활동이 팬과 언론의 시선을 바꾸고, 그 시선이 스폰서 수입과 이적시장 가치로 돌아온다. 이 스펙은 평판 수치, 인터뷰·SNS·광고·자선의 규칙, 뉴스·SNS 피드 생성, 스폰서 수입을 정한다.

## 범위
- 포함:
  - 평판 수치: 명성(인지도), 팬 평판, 언론 평판 — **이 스펙이 소유**. 리서치 05 §7.3의 "팬·언론 Affinity"는 이 스펙의 팬 평판·언론 평판과 같은 것이다 (033에는 팬·언론 관계 수치가 없다).
  - 미디어 인터뷰: 톤 4종(겸손 / 자신감 / 도발 / 회피), 즉시 효과 + 인용 시드 저장 (030 FR-21 사용)
  - 소셜미디어: 팔로워 수와 성향 분포, 게시 종류, 논란 확률 = 도발도 × 노출도
  - 광고 촬영, 자선 활동 (시간 슬롯은 032)
  - 스폰서: 제안 조건(명성·팔로워·라이프스타일 등급·평판), 계약 기간·주급 형태 수입, 해지 조건(스캔들)
  - 뉴스 기사·SNS 피드 생성: 경기 데이터·사건으로 템플릿 채우기 (리서치 07 §3.4)
  - 미디어 압박 크기 = f(명성, 연봉) (리서치 05 §7.1)
  - 버릇 효과: 쇼맨 → 팬 인기↑ / 감독 신뢰 하락 위험(025 입력), 다이버 → 심판·언론 평판↓ (기획서 4.2.1)
  - 평판 → 029 시장가치 입력(반영 여부는 029 FR-06), 030 디렉터 입력
  - 사기에는 직접 쓰지 않는다 (사기 합성식 024 FR-45에 미디어 항 없음 — 인터뷰·논란의 사기 영향은 030 최근사건 항으로만)
  - 미디어 탭(뉴스·SNS 피드·스폰서) 데이터 계약
- 제외:
  - 이벤트 콘텐츠(인터뷰 질문 문장, SNS 논란, 파파라치, 악성 루머) → 031
  - 파파라치 적발 판정 → 032 (이 스펙은 기사 생성만)
  - 시장가치 공식 → 029 (평판은 입력값)
  - 감독 신뢰 → 025
  - 기자회견 컷신 연출 → 047, 화면 구현 → 038

## 사용자 시나리오
1. 해트트릭 후 인터뷰에서 "자신감" 톤을 골랐다. 팬 평판이 오르고, 다음 날 뉴스 피드에 내 발언 인용 기사가 뜬다.
2. 상대 팀을 도발하는 SNS 게시물을 올렸다. 팔로워가 많아 논란이 커지고, 언론 평판이 떨어진다. 스폰서 하나가 계약 재검토 경고를 보낸다.
3. 스캔들 뒤 자선 활동을 꾸준히 하자 평판이 천천히 회복된다.
4. 팔로워가 일정 수를 넘자 스포츠 브랜드 스폰서 제안이 온다. 주마다 스폰서 수입이 장부에 들어온다.

## 요구사항

### 평판 수치
- FR-01: 명성(0~100, 인지도), 팬 평판(−100~100), 언론 평판(−100~100). 명성은 거의 떨어지지 않고(경기 출전·기록·사건으로 상승, 장기 무활동 시 느린 감쇠), 평판은 양방향.
- FR-02: 명성 상승 요인: 출전 리그 수준, 골·어시스트·평점, 하이라이트급 장면(018 점수 상위), 국가대표(035), 큰 경기 활약, 이적료 규모. [제안] 수치는 튜닝 데이터.
- FR-03: 팬 평판 요인: 경기 활약, 인터뷰 톤, 팬과의 사진·응원가 이벤트, 쇼맨 버릇, 라이벌 팀 이적(큰 하락), 충성(장기 재직) 보너스.
- FR-04: 언론 평판 요인: 인터뷰 톤(도발·회피 감점), 스캔들, 다이버 버릇(시뮬레이션 반칙 경고 받을 때마다), 판정 논란(012 `오심` 이벤트에 연루된 경우).
- FR-05: 미디어 압박 = f(명성, 연봉) (리서치 05 §7.1). 압박이 클수록 인터뷰·논란 이벤트 빈도와 결과 크기가 커진다 (030 적합도 입력).

### 인터뷰
- FR-10: 인터뷰 시점: 경기 후(평점·결과 기준 [제안] 내 선수 관여도 높을 때), 큰 경기 전, 이적 소문 시. 질문 문장은 031 콘텐츠.
- FR-11: 톤 4종 효과 [제안]:

  | 톤 | 팬 평판 | 언론 평판 | 감독 신뢰(025) | 인용 시드 |
  |---|---|---|---|---|
  | 겸손 | +1 | +2 | +1 | 저장 안 함 |
  | 자신감 | +3 | 0 | 0 | 저장 (콜백: n경기 무득점 → 조롱 기사) |
  | 도발 | +4 (자기 팬) | −4 | −2 | 저장 (콜백: 상대전 패배 → 역풍 기사) |
  | 회피 | −1 | −2 | 0 | 저장 안 함 |

- FR-12: 인용 시드는 030 FR-21 형식으로 저장하고, 콜백 결과(조롱·역풍·찬사 기사)는 이 스펙의 기사 생성으로 나타난다.

### 소셜미디어
- FR-20: 팔로워 수(정수)와 성향 분포 [제안] 3분포: 지지 / 중립 / 비판 비율. 증가 = f(명성, 게시 빈도, 하이라이트, 연애 공개, 쇼맨). 비판 비율은 논란·스캔들로 증가.
- FR-21: 게시 종류: 훈련, 일상, 경기 소감, 자선, 광고, 도발. 슬롯 비용은 032 (게시 [제안] 0칸이지만 주당 횟수 제한).
- FR-22: 논란 확률 = 도발도 × 노출도 (리서치 05 §7.3). 도발도는 게시 종류·톤, 노출도는 팔로워 수 기반 [제안] log 스케일 0~1. 논란 발생 시 031 `media_fans` 이벤트 후보 + 언론 평판 하락.
- FR-23: 팔로워 상한 없음, 정수 오버플로 없음 (64비트). 표시 단위는 1.2만 / 120만 처럼 축약 (037 숫자 포맷).
- FR-24: SNS 서비스 이름·UI는 가상이다. 실존 SNS 서비스 이름·로고·특징적 UI를 흉내 내지 않는다 (01-legal). 가상 서비스 이름 목록은 051 후보 [미정].

### 광고 · 자선
- FR-30: 광고 촬영: 스폰서 계약 의무(시즌당 n회)이거나 단발 제안. 슬롯 비용(032), 수입, 팬 평판 소폭 변화(과다 시 [제안] 시즌 6회 초과 → 팬 평판 감점 "광고 과다").
- FR-31: 자선: 비용(돈·슬롯), 효과 → 팬·언론 평판 회복 (기획서 4.10 "자선 → 평판 회복"). 회복 효율은 평판이 낮을수록 크다 [제안] (회복 탄력), 같은 주 반복 효과 감소.

### 스폰서
- FR-40: 스폰서 제안 조건 [제안]: 명성 ≥ 단계별 임계, 팔로워 ≥ 임계, 라이프스타일 등급(032) ≥ 임계, 팬·언론 평판 ≥ 하한 (기획서 4.10 "라이프스타일 등급 → 스폰서 제안", 리서치 05 §8 NSS 구조). 단계 [제안] 지역 / 국내 / 글로벌.
- FR-41: 스폰서 계약: 종류(스포츠 브랜드, 음료, 시계 등 — 가상 브랜드명), 기간(시즌), 주당 수입(032 장부에 입금, 금액은 032 FR-14 통화 규칙), 의무(광고 촬영 횟수, 평판 하한 유지), 해지 조항(평판 하한 미달, 특정 스캔들). 도박·주류 브랜드 스폰서는 넣지 않는다 [제안] (15세 등급).
- FR-42: 동시 스폰서 수 상한 [제안] 같은 종류 1개, 전체 5개. 충돌 종류(경쟁 브랜드) 동시 계약 불가.
- FR-43: 해지 경고 → [제안] 4주 유예 → 해지. 유예 중 평판 회복 시 유지.

### 뉴스 · SNS 피드
- FR-50: 뉴스 기사·SNS 글은 템플릿 + 치환 변수(선수·팀 이름, 평점, 골, 상대, 날짜)로 만든다 (리서치 07 §3.4). 템플릿 콘텐츠는 031과 같은 린트(실명·금지어·등급)를 거친다.
- FR-51: 트리거: 경기 결과(평점 상위/하위, 해트트릭, 자책골, PK 실축), 인용 시드 콜백, 판정 논란(012의 오심 이벤트), 이적 소문(029), 스캔들(032·033), 스폰서 계약.
- FR-52: 피드 보관 [제안] 최근 60개, 오래된 것은 삭제 (세이브 크기).
- FR-53: 같은 사건에 기사 중복 생성 금지 (사건 id 기준 1회).

### 버릇 연결
- FR-60: 쇼맨(기획서 4.2.1): 개인기 시도 시 팬 평판 + / 감독 신뢰 하락 위험(025 입력), 하이라이트 장면 증가는 018이 처리.
- FR-61: 다이버: 파울 유도 성공 시 변화 없음, 시뮬레이션 반칙 경고(012)마다 언론 평판 [제안] −3, 심판 평판(경기 엔진 판정에 쓰지는 않음 [제안]) 기록.

### 화면 계약
- FR-70: 미디어 탭: 명성·팔로워(큰 숫자, 축약 표기), 팬·언론 평판 화살표, 뉴스 피드 카드, SNS 피드 카드, 스폰서 카드(주당 수입 큰 숫자·남은 기간·의무 진행).

## 경계 · 예외 상황
- 평판 −100·100 경계 → clamp. 명성 0 (데뷔 전 유스) → 인터뷰·스폰서 없음.
- 팔로워 0 → 노출도 0 → 논란 확률 0 (log(0) 처리 주의).
- 스폰서 계약 중 이적·은퇴 → 계약은 선수 개인 계약이라 이적에도 유지, 은퇴 시 [제안] 시즌 말 종료.
- 해지 유예 중 다시 스캔들 → 유예 즉시 종료·해지.
- 같은 주 인터뷰 여러 번(경기 2번) → 각각 처리, 인용 시드 여러 개 공존.
- 치환 변수 비어 있음 → 기사 생성 안 하고 오류 기록 (030 FR-51과 같은 원칙).
- 다른 언어(en)에서 축약 표기 규칙 (1.2만 ↔ 12K) → 037 숫자 포맷.
- 판정 논란 기사가 실존 심판을 연상시키지 않게 심판도 가상 이름 (020 이름 규칙, 목록 소유는 051 후보).
- 기사·SNS 템플릿은 031 린트(실명·금지어·등급)를 통과한 것만 쓴다. 치환 변수로 들어가는 이름(선수·클럽·브랜드)도 가상 데이터에서만 온다 — 모드로 실명 데이터가 들어온 경우의 처리는 049·실명 정책(결정 대기).
- 같은 주에 스캔들 + 스폰서 해지 + 이적 → 해지 판정은 주 마감 1회, 순서 고정 [제안].
- 스폰서 계약 기간이 시즌 경계를 넘음 → 024 FR-32 시즌 경계 이후 남은 기간 그대로, 은퇴 시 시즌 말 종료.

## 비기능 요구사항
- 결정론: 팔로워 증가·논란 판정·스폰서 제안은 시드 RNG. 같은 시드·같은 선택 → 같은 피드·같은 장부 입금.
- 세이브 호환: 평판·팔로워·스폰서 계약·피드·인용 시드 저장·불러오기 동일 (022).
- 순수 C#, UnityEngine 비참조.

## 수용 기준
- AC-01 [로직]: 인터뷰 톤 4종 각각의 즉시 효과가 표와 같고, 자신감·도발만 인용 시드가 저장된다.
- AC-02 [로직]: 자신감 인용 후 n경기 무득점 → 조롱 기사 1건 생성(중복 없음), 그 사이 득점하면 생성 안 됨.
- AC-03 [로직]: 논란 확률 = 도발도 × 노출도가 경계값(팔로워 0, 도발도 0, 둘 다 최대)에서 0 / 0 / 최대값이고, 10,000회 판정 빈도가 확률 ±1.5%p.
- AC-04 [로직]: 스폰서 제안 조건 임계 바로 아래/위에서 제안 없음/있음. 경쟁 브랜드 동시 계약 불가. 주당 수입이 032 장부에 매주 정확히 입금된다.
- AC-05 [로직]: 평판 하한 미달 → 해지 경고 → 4주 유예 → 해지. 유예 중 회복 시 유지, 유예 중 재스캔들 시 즉시 해지.
- AC-06 [로직]: 자선의 평판 회복이 평판 낮을 때 더 크고, 같은 주 반복 시 감소한다.
- AC-07 [로직]: 다이버 버릇 선수가 시뮬레이션 반칙 경고를 받을 때마다 언론 평판이 규칙대로 떨어진다. 쇼맨 개인기 시도가 팬 평판을 올린다.
- AC-08 [로직]: 같은 사건 id로 기사가 두 번 생성되지 않는다. 치환 변수 빈 템플릿은 기사 없이 오류 기록.
- AC-09 [로직]: 팔로워가 64비트 범위에서 오버플로 없고, 축약 표기가 ko(만·억)/en(K·M) 경계값(9,999 / 10,000 / 999,999 / 1,000,000)에서 맞다.
- AC-10 [결정론]: 같은 시드·같은 선택으로 10시즌 헤드리스 커리어 2회 → 평판·팔로워·스폰서·피드 로그 해시 동일.
- AC-11 [E2E]: 고정 픽스처(스폰서 3개, 피드 60개, 팔로워 123만)에서 미디어 탭을 열면 명성·팔로워 큰 숫자(축약), 평판 화살표, 뉴스·SNS 카드, 스폰서 카드(주당 수입·남은 기간)가 보인다. 프로필: 전체 (ko/en × light/dark). 큰 숫자·긴 기사 제목 잘림 없음.
- AC-12 [E2E]: 경기 후 인터뷰 픽스처에서 톤 4개 선택지 바텀시트가 보이고, "자신감" 선택 후 다음 화면 피드에 인용 기사가 나타난다. 프로필: smoke.
- AC-13 [성능]: 성능 예산 표 항목이 예산 안.
