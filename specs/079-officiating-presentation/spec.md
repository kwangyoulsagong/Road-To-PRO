# 079 — 판정 연출 (심판 신호 · VAR 리뷰 · 부심 깃발 · 선수 반응 · 항의 · 실랑이)

상태: 승인됨
브랜치: feat/079-officiating-presentation
기획 출처: docs/index.html § 리서치 07 § 1.1(IFAB 규칙 구현 범위 · VAR 4대 사안 · OFR), § 1.2(경기당 오프사이드 3.5~4.0 · 파울 20~24 · 경고), § 1.5(심판 위치 선정 · 4심은 프레젠테이션 전용 애니메이션), § 2.1(골 후 순서 · 데드볼 클로즈업 컷) / 기획서 4.8(콘텐츠 등급 15세) / specs/012 FR-01~06·26·72·90(판정·VAR·항의 경고는 시뮬이 정한다) / specs/018 FR-01·22·30(VAR 번복 장면) / specs/058 T15a(VAR 번복 장면 선정) / specs/060 FR-96(골 취소 시 세리머니 끊기) / IFAB 경기 규칙 Law 5·6 심판·부심 신호(공개 규정)

## 배경
2026-11-11 사용자 요구: "VAR이면 심판이 VAR 확인하는 모션, 판정 애니메이션, VAR로 취소되면 아쉬워하는 것, 오프사이드면 가끔 '옵사 아니다' 화내는 모션, 선수 심판 항의, 가끔 싸우는 모션". 지금 심판 클립은 휘슬·카드·어드밴티지 3개뿐이고, 판정 뒤 선수 반응은 060의 "골 취소 시 실망" 한 줄뿐이다. 012가 판정을 시뮬 안에서 정하지만 화면에는 결과가 바로 나와서, 축구 중계에서 가장 극적인 장면인 판정 순간이 비어 있다.
이 스펙은 **판정을 바꾸지 않고** 판정 이벤트를 받아 심판·부심·선수가 그 판정을 몸으로 보여 주게 한다. 판정 결과·카드·정지 시간은 012가, 장면 선정은 018(058 1단계)이, 카메라는 042가 정한다.

## 범위
- 포함:
  - 심판 신호 동작(IFAB Law 5): 직접 프리킥(팔 방향), 간접 프리킥(팔 들기 유지), 페널티(지점 가리키기), 어드밴티지(두 팔 앞으로), 골 인정(센터 가리키기), 골 취소·반칙(휘슬 + 손 X 또는 반칙 지점), 경고·퇴장(카드 들기, 기존 클립 재사용), 골킥·코너 방향 지시, 드롭볼
  - VAR 리뷰 연출: 심판 귀에 손(교신) → 체크 대기, 온필드 리뷰(OFR) 시 TV 사각형 그리기 → 모니터로 이동 → 모니터 시청 → 복귀 → 최종 판정 신호. 선수들이 결과를 기다리는 대기 동작
  - 부심 깃발 신호(IFAB Law 6): 오프사이드(깃발 들기 → 위치 지시 높이 3단계), 스로인 방향, 골킥·코너, 교체, 늦은 깃발(012 늦은 깃발 판정과 같은 시각)
  - 판정 뒤 선수 반응: VAR 취소된 골의 득점 팀 아쉬움(머리 감싸기·손 허리·주저앉기)과 상대 팀 안도, 오프사이드 선언에 "아니다" 항의(가끔 화냄), 파울·카드·PK에 대한 심판 항의(손 벌리기·따라가며 항의·주장 대표 항의), 반칙당한 쪽 호소
  - 가끔 실랑이: 거친 반칙·논란 판정 뒤 양 팀 선수가 몰려 밀치기·이마 맞대기 직전, 동료·심판이 떼어 놓기. 등급 15세: 주먹·발길질 같은 폭력 묘사 없음(기획서 4.8)
  - 반응 강도와 빈도를 선수 성격·성향(003)·경기 상황(점수·시간·판정 중요도)·심판 성향(012)에서 정하는 규칙. 항의가 지나치면 012가 내는 항의 경고와 같은 사건으로 이어진다(판정은 012, 이 스펙은 동작)
  - 하이라이트 장면에 판정 연출 구간 포함(058·018 장면 구간과 042 데드볼 컷 연결): VAR 번복·오프사이드 골 취소·PK·레드카드 장면은 판정 연출까지 보여 준다
- 제외:
  - 판정 규칙·오심·VAR 개입 여부·카드 결정 → 012 (이 스펙은 결과를 바꾸지 않는다)
  - VAR 화면 UI(라인 오버레이, "VAR CHECK" 표시, 판정 결과 자막) → 039·042
  - 관중 야유·탄식 소리 → 075, 관중 동작 → 045
  - 골 세리머니 동작 → 060 (VAR 취소로 끊기는 순간 이후 반응만 이 스펙)
  - 판정 논란의 언론·감독·평판 반영 → 030·034
  - 감독·벤치 항의 동작 → 050 (FR-37 감독 퇴장과 함께)

## 사용자 시나리오
1. 내 선수가 골을 넣고 세리머니를 하는데 심판이 귀에 손을 댄다. 선수들이 멈춰 기다리고, 심판이 TV 사각형을 그리고 모니터로 간다. 돌아온 심판이 손을 X로 긋고 프리킥 방향을 가리킨다. 내 선수는 머리를 감싸 쥐고 주저앉고, 상대 수비는 주먹을 쥔다.
2. 침투한 동료가 슈팅하는 순간 부심 깃발이 올라간다. 동료는 부심 쪽으로 두 팔을 벌리며 "아니다"라고 항의하고, 리플레이가 발끝 차이를 보여 준다.
3. 박스 근처에서 상대가 거칠게 넘어뜨리자 심판이 휘슬을 불고 지점을 가리킨 뒤 경고를 든다. 내 팀 동료 둘이 다가가 따지고, 상대 선수와 이마를 맞대기 직전 동료가 떼어 놓는다.
4. PK 선언에 수비수들이 심판을 둘러싸고 항의하고, 주장이 대표로 말한다. 한 명은 항의를 멈추지 않다가 경고를 받는다(012가 정한 사건).

## 요구사항

### 판정 신호 (심판 · 부심)
- FR-01: 012의 판정 이벤트(반칙·프리킥 종류·페널티·어드밴티지·골 인정·골 취소·오프사이드·카드·재시작)마다 IFAB Law 5·6의 공식 신호 하나를 심판 또는 부심이 낸다. 신호 종류 ↔ 판정 이벤트 매핑은 데이터 한 곳에서 관리한다(043 매핑 표 방식).
- FR-02: 신호 시작은 판정 이벤트 시각 기준 [제안] 0.2~0.6 s 뒤(사람 반응 지연), 휘슬이 먼저다. 늦은 깃발(012)은 012가 준 깃발 시각에 든다.
- FR-03: 방향이 있는 신호(직접 프리킥·스로인·골킥·코너·오프사이드 위치)는 판정 데이터의 공격 방향·지점과 일치한다. 오프사이드 위치 지시는 반칙 지점이 먼 쪽·중앙·가까운 쪽 터치라인 기준 3단계 깃발 높이(Law 6).
- FR-04: 신호 중 심판·부심은 정해진 위치 선정(012 FR 위치, 리서치 07 § 1.5)을 벗어나지 않는다. 신호 동작이 이동을 막지 않게 상체 레이어로 겹친다.
- FR-05: 카드 신호는 기존 카드 클립을 쓰고, 받는 선수 쪽을 향한다. 퇴장은 받은 선수가 058 FR-65대로 걸어 나간다.

### VAR 리뷰 연출
- FR-10: VAR 체크(012 VarCheck)가 시작되면 심판은 귀에 손을 대는 교신 동작으로 대기하고, 다른 손으로 선수들을 막는 손짓을 한다. 체크 중 경기는 데드볼이다(012).
- FR-11: 온필드 리뷰(012 OFR)면 심판이 두 손으로 TV 사각형을 그린 뒤 리뷰 지역(터치라인 하프라인 근처 모니터, 044 경기장 배치)으로 걸어가 모니터를 본다. 걷기·보기 시간은 012 VAR 정지 시간(FR-90) 안에 들어간다.
- FR-12: 리뷰가 끝나면 다시 TV 사각형을 그린 뒤 최종 판정 신호를 낸다(번복: 골 취소 X·PK 지점·카드, 유지: 원래 판정 신호 반복).
- FR-13: VAR 체크·리뷰 동안 선수들은 대기 동작(손 허리·서성임·심판 근처로 모이기 [제안] 최대 3~5명, 기도 손)을 한다. 득점 팀과 상대 팀은 다른 대기 동작 풀을 쓴다.
- FR-14: 012의 리그 VAR 플래그가 꺼진 대회에서는 VAR 연출이 없다.

### 판정 뒤 선수 반응
- FR-20: 판정 뒤 반응 대상 선수와 동작은 판정 종류별 규칙으로 정한다.

  | 판정 | 손해 본 쪽 | 이득 본 쪽 |
  |---|---|---|
  | VAR 골 취소 | 득점자·동료: 머리 감싸기·손 허리·주저앉기·하늘 보기 | 안도·주먹 쥐기·GK 박수 |
  | 오프사이드 선언 | 해당 선수: 두 팔 벌림·부심 향해 "아니다"(가끔 화냄) | 수비 라인: 손 들어 어필 확인 |
  | 반칙·카드 | 반칙 선수: 손 벌림·"공 쳤다" 동작·심판 따라가며 항의 | 피해 선수: 호소·통증 |
  | 페널티 선언 | 수비진: 심판 둘러싸기·주장 대표 항의 | 공격진: 환호 |
  | 오심성 미판정(012 진짜 판정 ≠ 내린 판정) | 피해 쪽: 강한 항의 | — |

- FR-21: 반응 강도(가벼움·보통·강함)는 선수 성격·성향(003, 예: 다혈질·리더십), 경기 상황(점수 차·남은 시간·판정 중요도), 판정이 오심인지(012 텔레메트리)로 정한다. 같은 상황이면 장면 id·선수 id에서 유도한 시드로 고르는 결정론 선택이다.
- FR-22: "가끔 화냄"(오프사이드 강함)과 강한 항의 빈도는 [제안] 판정 대비 10~20%로 시작해 측정 뒤 조정한다.
- FR-23: 반응은 058 데드볼 이동과 함께 돈다: 반응 동작은 상체·제자리 레이어이고, 재시작 배치 이동이 시작되면 [제안] 2 s 안에 이동 동작으로 섞여 끝난다. 반응 때문에 재시작이 늦어지지 않는다(정지 시간은 012).
- FR-24: 항의가 012의 항의 경고(FR-26) 조건을 넘으면 그 선수는 012가 경고 사건을 낸다 — 이 스펙은 항의 강도를 012에 입력으로 넘기고, 경고 결정은 012가 한다. 항의 입력은 시뮬 RNG를 쓰지 않는 결정론 값이다.

### 실랑이 (몰려들기 · 밀치기 · 떼어 놓기)
- FR-30: 거친 반칙(012 심각한 반칙·퇴장성 반칙), 보복성 반칙, 논란 판정 뒤에 [제안] 판정 대비 3~8% 빈도로 실랑이가 생긴다. 성격(다혈질)·경기 열기(더비·점수·시간)가 빈도를 올린다.
- FR-31: 실랑이는 2~6명이 몰려들어 밀치기·가슴 맞대기·이마 맞대기 직전까지 가고, 동료·심판이 떼어 놓는 순서로 [제안] 3~6 s 안에 끝난다. 주먹·발길질·넘어뜨리기 같은 폭력 묘사는 없다(등급 15세, 기획서 4.8).
- FR-32: 실랑이 결과(경고·퇴장)는 012가 정한다. 이 스펙은 실랑이 발생 여부와 관여 선수를 012에 입력으로 넘긴다(폭력 행위 판정은 012).
- FR-33: 실랑이 중 선수 몸은 서로 겹치지 않는다(054·005 분리 규칙, 몸 캡슐).

### 하이라이트 · 카메라 연결
- FR-40: VAR 번복·오프사이드 골 취소·PK 선언·레드카드 장면은 판정 연출(체크 대기 → 리뷰 → 최종 신호 → 반응)까지 장면 구간에 넣는다. 긴 VAR 대기는 [제안] 대기 구간을 최대 4 s로 줄여(시간 건너뛰기 컷) 보여 준다. 장면 구간 규칙은 018(058 1단계)과 맞춘다.
- FR-41: 판정 연출 구간은 데드볼이라 042 데드볼 컷 규칙으로 심판 클로즈업·반응 클로즈업을 쓸 수 있다. 042 컷 최소 길이 2.5 s를 지킨다.
- FR-42: 리플레이(오프사이드 발끝·반칙 접촉)는 042 리플레이 앵글로 나오고, 반응 동작은 리플레이 뒤 라이브 구간에 나온다.

### 경계 · 예외 상황
- FR-60: 판정 연출 도중 하프·경기 종료(058 FR-60)가 오면 최종 신호까지만 보여 주고 반응은 종료 장면으로 넘긴다.
- FR-61: VAR 리뷰 중 심판 이동 경로에 선수가 있으면 피해 간다(005 분리). 모니터 위치가 경기장 배치에 없으면 하프라인 터치라인 [제안] 1 m 밖 기본 지점을 쓰고 진단을 남긴다.
- FR-62: 같은 데드볼에 판정이 겹치면(반칙 → 카드 → 실랑이) 신호 → 카드 → 실랑이 순서로 이어 붙이고, 데드볼 정지 시간(012) 안에 들어가지 않는 반응은 생략한다.
- FR-63: 반응 대상 선수가 이미 걸어 나가는 중(058 퇴장·교체)이면 반응을 고르지 않는다. 퇴장당한 선수의 항의는 걸어 나가며 하는 상체 동작만 허용한다.
- FR-64: 내 선수가 반응 대상이면 하이라이트에서 내 선수 반응을 우선 클로즈업한다(042 내 선수 모드 규칙 안에서).

### 동작 자산
- FR-50: 신호·VAR·반응·실랑이 동작은 043·055 모션 파이프라인(bpy 자체 제작, Unity Humanoid)으로 만든다. 상용 게임 동작 복제 없음(01-legal).
- FR-51: 최소 동작 세트 [제안]: 심판 신호 12종, 부심 깃발 6종, VAR 4종(교신·사각형·모니터 보기·대기 손짓), 선수 반응 18종(실망 5·항의 6·안도 3·호소 2·대기 2), 실랑이 6종(밀치기 2·맞대기 1·떼어 놓기 2·물러서기 1). 같은 동작 반복이 눈에 띄지 않게 종류별 변형 2개 이상.

## 비기능 요구사항
- 결정론: 판정 결과는 시뮬(012)이 정한다. 반응·실랑이 발생과 관여 선수가 012 입력이 되는 부분(FR-24·32)은 시뮬 결정론 규칙(고정 순서, 시뮬 RNG 스트림만)을 따른다. 순수 표현 선택(동작 변형)은 장면 id·선수 id 시드만 쓴다. 같은 시드면 같은 반응·같은 실랑이.
- 시뮬 불변(표현 부분): 동작 재생은 판정·위치·정지 시간을 바꾸지 않는다.
- 세이브 호환: 저장은 경기 전·후만(확정). 새 세이브 필드 없음.
- 콘텐츠 등급: 15세. 폭력 묘사 없음, 욕설 제스처 없음.

## 수용 기준
- AC-01 [로직]: 012 판정 이벤트 종류 전부에 신호 매핑이 있고(누락 0), 신호 시작이 판정 시각 + 0.2~0.6 s 안이며 방향 신호가 판정 데이터의 방향·지점과 일치한다.
- AC-02 [로직]: 오프사이드 깃발 높이 3단계가 반칙 지점의 먼 쪽·중앙·가까운 쪽 구간과 일치하고, 늦은 깃발은 012 깃발 시각에 든다.
- AC-03 [로직]: VAR 체크 → OFR → 최종 신호 순서가 012 VAR 이벤트 순서와 같고, 심판이 리뷰 지역까지 걸어서 이동하며(순간이동 0, 058 AC-01 감사기) 이동·시청이 VAR 정지 시간 안에 끝난다. VAR 플래그 꺼진 대회는 VAR 동작 0.
- AC-04 [로직]: 판정 종류별 반응 대상·동작 풀이 FR-20 표대로 고르고, 같은 시드 2회 결과가 같다. 강한 반응 빈도가 고정 시드 대량 판정에서 [제안] 10~20% 안.
- AC-05 [로직]: 실랑이 빈도가 고정 시드 대량 판정에서 [제안] 3~8% 안, 관여 2~6명, 3~6 s 안에 끝나고, 몸 겹침 0, 폭력 동작 클립이 목록에 없다.
- AC-06 [로직]: 반응·실랑이가 재시작을 늦추지 않는다(058 재시작 준비 시각 동일, 반응 끝 2 s 안 이동 섞임).
- AC-07 [로직]: 항의 강도·실랑이 관여가 012 입력으로 넘어가고, 012가 낸 경고·퇴장 사건과 같은 선수·같은 시각이다(012 연결 전에는 대체 심판 스크립트로 검증).
- AC-08 [결정론]: 같은 시드 2회 시뮬에서 판정·반응·실랑이 이벤트 로그 해시가 같고, 동작 선택 해시가 같다.
- AC-09 [E2E]: `e2e/079-var-review` — 고정 경기(주입 VAR 골 취소)에서 교신 대기, TV 사각형, 모니터 시청, 최종 X 신호, 득점자 실망 반응을 캡처. 심판·대상 선수가 화면 안. 육안 승인.
- AC-10 [E2E]: `e2e/079-calls-reactions` — 오프사이드 깃발 + "아니다" 항의, 직접 프리킥 신호 + 반칙 선수 항의, PK 신호 + 수비진 둘러싸기, 실랑이(밀치기 → 떼어 놓기)를 캡처. 육안 승인.
- AC-11 [로직]: 하이라이트 선정에서 VAR 번복·오프사이드 골 취소·PK·레드카드 장면 구간이 판정 연출 끝(최종 신호 + 반응)까지 들어가고, VAR 대기가 4 s를 넘으면 건너뛰기 컷이 들어간다.

## 미정 / 질문
- 정리됨 (2026-11-11 사용자 결정 '베스트 케이스'): 아래 [제안] 값은 추천안으로 채택하고 측정 뒤 조정한다 — 신호 지연 0.2~0.6 s, VAR 대기 모이기 3~5명, 강한 반응 10~20%, 실랑이 3~8%·2~6명·3~6 s, 반응 → 이동 섞임 2 s, 하이라이트 VAR 대기 압축 4 s, 동작 세트 수(심판 12·부심 6·VAR 4·반응 18·실랑이 6), 선택 2 ms, 클립 4 MB.
- 정리됨 (같은 결정): 실랑이 표현 상한은 밀치기·가슴/이마 맞대기 직전·떼어 놓기까지(15세). 주먹·발길질·넘어뜨리기·욕설 제스처는 넣지 않는다.
- 정리됨 (같은 결정): 항의·실랑이는 표현이 아니라 012 판정 입력이 된다(항의 경고·폭력 행위 판정은 012). 그래서 발생 여부·관여 선수는 시뮬 쪽 결정론 값으로 정하고, 동작 변형만 표현 시드로 고른다.
- 정리됨 (같은 결정): VAR 화면 UI·라인 오버레이는 039·042, 관중 반응 소리는 075로 둔다.
