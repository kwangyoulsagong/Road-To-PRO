## 배경
지금 경기장은 044 생성기의 인자 몇 개(수용 등급 4단계·층수·지붕 3종·조명 2종·좌석 2색)로만 달라져서, 클럽이 바뀌어도 거의 같은 사각 그릇처럼 보인다. 선수 한 명의 커리어를 하부 리그 작은 구장에서 시작해 9만 석 대형 경기장까지 올라가는 것이 이 게임의 큰 그림인데, 경기장이 그 성장을 눈으로 보여 주지 못한다. 또 044의 수용 등급(8천~6만)이 020 월드 생성의 경기장 수용 범위(2,000~90,000)와 맞지 않아 작은 클럽과 최대 클럽의 경기장을 만들 수 없다. 이 스펙은 경기장의 **형태·규모·유형·개성**과 그것을 미리 만들어 배포하는 **경기장 카탈로그**를 정한다. 어느 클럽에 어떤 경기장을 주는지(클럽 연결·이름·증축·이전)는 077이 맡고, 재질 값 기준·조명·후처리는 061이 맡는다. 표면 디테일 2차(관중석 좌석·계단 통로·광고판 등)는 2026-11-11 061 Q1 (a)로 이 스펙이 맡는다.

  - 규모: 수용 인원 2,000~90,000 연속 값 + 규모 구간 6개 (044 4단계 대체, 2026-11-11 결정)
  - 경기장 유형(아키타입) 7종의 형태 규칙과 유형 × 규모 호환표
  - 개성 요소: 좌석 색 무늬(글자 없음), 외장 재질, 지붕 구조 형태, 조명탑 형태, 코너 처리, 스코어보드 위치, 주변 배경(원경 세트), 면별 비대칭
  - 061 FR-20 중 **지붕 하부 구조·조명탑·피치 주변 트랙·경기장 외곽 실루엣의 '형태'** (2026-11-11 결정 — FR-28)

  - 경기장 카탈로그: 오프라인으로 미리 생성·베이크한 경기장 항목 모음, 수용 범위 커버리지, 실행 중 변주(좌석 색·원경)
  - 접점 데이터: 042 카메라 거치 범위·금지 영역, 045 좌석·구역 데이터, 046 잔향용 음향 속성, 064 날씨용 지붕 덮임 정보
  - 예산: 044 예산을 모든 유형·최대 규모에서 유지, 생성 시간·카탈로그 용량·로딩
  - 생성 결정론과 인자 검증 (044 FR-11·12 확장)
- 제외:
  - 클럽에 경기장 배정, 같은 리그 구분, 경기장 이름, 국가 대표 경기장 선택, 증축·이전 → 077
  - 재질 값 기준표(061 FR-07)·조명·하늘·후처리·AA·근거리 잔디·기준 장면 정의(061 FR-01·02) → 061 (표면 디테일은 이 스펙 FR-40~46, 2026-11-11 061 Q1 (a) 이관)
  - 피치·골대·라인 규격, 잔디 셰이더 → 044 (변경 없음)
  - 관중 렌더링·수용률 산식 → 045 / 020·024·050
  - 잔향 값·사운드 믹스 → 046 (이 스펙은 음향 속성 데이터만 낸다)
  - 날씨 효과(비·눈·젖음) → 064
  - 실행 중 경기장 모듈 조립 (경기장별 라이트맵 베이크 확정 048 FR-04와 충돌 — 채택 안 함)
  - 스코어보드·대형 화면에 표시하는 내용(점수·영상) — 후속 후보 [미정]
  - 실존 경기장 형태·이름·로고·좌석 무늬 글자 복제 (금지)

## 사용자 시나리오
1. 하부 리그 클럽에서 데뷔한 선수의 첫 하이라이트가 열리면, 한쪽에만 지붕 덮인 1층 스탠드가 있고 나머지는 낮은 난간과 둔덕뿐인 2~3천 석 구장이 보인다. 조명은 낮은 기둥 여러 개다.
2. 1부 클럽 홈 경기는 코너가 막힌 2층 볼형 경기장에 골대 뒤 한쪽이 가파른 대형 홈 응원석이다. 좌석은 클럽 두 색의 사선 블록 무늬이고 글자는 없다.
3. 육상 트랙 겸용 경기장에서는 관중석이 멀고 메인 중계 화면에 트랙 레인이 보인다.
4. 전체 지붕·외장 패널로 둘러싸인 9만 석 경기장은 같은 카메라 규칙인데도 관중석이 화면을 가득 채워 규모 차이가 확연하다. 프레임은 끊기지 않는다.
5. 같은 카탈로그 경기장을 두 클럽이 (다른 리그에서) 쓰더라도 좌석 색은 각 클럽 색, 주변 배경은 각 연고 도시에 맞게 다르다.

## 요구사항

### 규모
- FR-01: 경기장 수용 인원 범위는 **2,000~90,000석 연속 값**이다(020 FR-22와 같은 범위, 2026-11-11 결정으로 044의 4단계 대체). 044의 4값(8천·2만·4만·6만)은 이 범위 안의 유효한 값으로 계속 생성된다(회귀).
- FR-02: 규모 구간 [채택] 6개 — 형태 규칙(층수·스탠드 면 수·허용 유형)을 고르는 단위다:

  | 구간 | 수용 인원 | 층수 | 비고 |
  |---|---|---|---|
  | R1 | 2,000~4,999 | 1 | 스탠드 1~4면, 일부 면은 난간·둔덕·입석 테라스 |
  | R2 | 5,000~11,999 | 1~2 | 044 8천 포함 |
  | R3 | 12,000~24,999 | 1~2 | 044 2만 포함 |
  | R4 | 25,000~44,999 | 2~3 | 044 4만 포함 |
  | R5 | 45,000~64,999 | 2~3 | 044 6만 포함 |
  | R6 | 65,000~90,000 | 3 | 최대 규모 |

- FR-03: 생성된 경기장의 실제 좌석 수가 그 경기장의 **공식 수용 인원**이다(게임 안 표시·045 관중 수·020 리포트가 모두 이 값을 쓴다, 배정은 077). 요청 수용 인원과 실제 좌석 수 차이는 ±[채택] 1% 이내.
- FR-04: 규모는 화면에서 구분된다: 같은 카메라 규칙(042 메인 중계 와이드)에서 관중석·지붕 구조가 차지하는 화면 비율이 규모 구간이 올라갈수록 커진다(단조 증가). 피치 네 모서리는 모든 규모에서 보인다(044 FR-62).

### 경기장 유형 (아키타입)
- FR-10: 유형 7종과 형태 규칙 [채택]. 각 유형은 생성 요약의 **형태 기술값**(FR-12)으로 판정할 수 있어야 한다. 실존 경기장의 특징적 형태를 그대로 따라 하지 않는다(044 FR-50).

  | id | 유형 | 형태 규칙 | 허용 규모 |
  |---|---|---|---|
  | T1 | 소규모 1층 구장 | 1층, 스탠드 1~4면(최소 1면은 좌석 스탠드), 나머지는 난간·둔덕·입석 테라스. 지붕 없음 또는 메인 스탠드만 부분 지붕. 조명은 낮은 기둥 다수 | R1~R2 |
  | T2 | 사각 스탠드 분리형 | 4면 독립 스탠드, 코너 4개 모두 열림, 면마다 높이·지붕이 같거나 다름. 조명탑은 코너 | R2~R5 |
  | T3 | 연속 볼형 | 스탠드가 둘레를 끊김 없이 감싼다(코너 막힘 4개), 위에서 보면 둥근 사각 또는 타원 | R3~R6 |
  | T4 | 육상 트랙 겸용 | 피치 둘레 육상 트랙 레인 6~8개, 트랙 바깥 타원 스탠드, 골대 뒤 관중석이 피치에서 멀다. 지붕은 메인 스탠드 위주 | R3~R6 |
  | T5 | 현대식 전체 지붕·외장 파사드 | 지붕 덮개 비율 ≥ 90%, 외곽이 연속 외장 패널로 감싸여 바깥에서 스탠드 구조가 보이지 않는다. 조명은 지붕 라인 | R4~R6 |
  | T6 | 한쪽 대형 스탠드(홈 응원석) | 골대 뒤 한 면이 단일 경사의 큰 스탠드로, 높이가 나머지 면 평균의 1.4배 이상. 홈 응원 구역(045)이 이 면에 놓인다 | R2~R5 |
  | T7 | 비대칭(증축 이력형) | 네 면 중 3면 이상이 층수·높이·지붕 형태 중 하나 이상에서 서로 다르다 | R2~R5 |

- FR-11: 유형 × 규모 호환표(FR-10 "허용 규모")에 없는 조합은 생성하지 않고 오류를 낸다(FR-71). 카탈로그 항목과 077 배정은 호환표 안에서만 나온다.
- FR-12: 생성 요약에 형태 기술값을 기록한다: 유형 id, 규모 구간, 실제 좌석 수, 면별(4면) 층수·최고 높이(m)·지붕 유무·지붕 깊이, 코너별 막힘 여부, 지붕 덮개 비율(관중석 면적 대비), 트랙 유무·레인 수, 외장 파사드 유무, 지붕 구조 형태, 조명 형태, 스코어보드 위치, 좌석 무늬 종류, 외장 재질, 피치 중심에서 가장 가까운 관중석까지 거리(면별). 카탈로그 구분(FR-34)·077 리그 구분·접점 데이터(FR-50~53)가 이 값을 쓴다.

### 개성 요소 (유형 위에 얹는 변주)
- FR-20: 좌석 색 무늬 [채택] 6종: 단색, 줄(가로), 층별 교대, 블록 격자, 사선 블록, 흩뿌림(무작위 점). 무늬는 경기장 항목에 고정되고, 색은 **실행 중 홈 클럽 색 2개(020 클럽 색) + 중립색 1개(회색 계열)** 로 칠해진다(FR-33). **글자·숫자·엠블럼·연도·그림 모양은 넣지 않는다**(044 FR-51, 01-legal).
- FR-21: 외장 재질 [채택] 5종: 노출 콘크리트, 벽돌, 금속 패널, 유리·반투명 패널, 칠한 철골. 재질 값(밝기·거칠기)은 061 FR-07 범위를 따른다.
- FR-22: 지붕 구조 형태 [채택] 4종: 기둥 지지(앞쪽 기둥 있음), 캔틸레버(기둥 없음), 상부 트러스, 케이블·마스트 지지. 앞쪽 기둥은 메인 카메라 거치 위치에서 피치를 가리지 않는다(044 FR-62).
- FR-23: 조명 형태 [채택] 4종: 코너 격자 타워 4기, 코너 단일 기둥 타워 4기, 낮은 기둥 다수(6~8기, T1과 R1~R2의 T2 전용), 지붕 라인 조명. 빛 표현은 발광 머티리얼만(044 FR-42). 전체 지붕 + 타워 조합은 지붕 라인으로 자동 전환(044 FR-61).

### 결정론 · 인자 검증
- FR-70: 같은 생성기 버전·같은 Blender 버전(044 FR-65)·같은 명세 → 같은 glb 해시, 같은 좌석 데이터·카메라 데이터·음향 속성 해시, 같은 미리보기 이미지(044 AC-03 확장). 명세 시드만 바꾸면 개성 요소가 바뀌고 규격 검사는 통과한다. 카탈로그 전체를 2회 생성하면 항목별 해시가 같다.

- FR-72: 경기장 형태·변주는 시뮬 결과에 영향을 주지 않는다(읽기 전용 프레젠테이션 입력). 공식 수용 인원(FR-03)은 생성 결과로 고정되며 생성기 버전이 올라가도 같은 명세의 좌석 수는 바뀌지 않는다(바뀌면 회귀 실패).

### 경계 · 예외 상황
- 수용 2,000(최소)·T1·스탠드 1면: 나머지 세 면은 난간·둔덕. 045 관중은 그 1면 좌석에만 앉는다. 스탠드 1면이 메인 쪽이 아니면 메인 쪽에 독립 카메라 단(042 FR-01 높이 범위)을 둬 042 거치 범위를 보장한다.
- 수용 90,000(최대)·3층: 예산 안(FR-60), 좌석 수 그대로. 상층 끝 관중 시야 검사는 하지 않고 044 FR-62 카메라 가시성만 판정한다.
- 구간 경계값(4,999/5,000 등): FR-02 표의 포함 범위 그대로, 구간이 겹치지 않는다.
- 044 기존 4값과 044 인자 세트(최소·기본·최대): 계속 생성되고 044 AC 전부 통과(회귀). 044 "최소 인자"의 수용 8천은 이제 최소가 아니다 — 최소 회귀 세트에 2천을 추가한다.
- 클럽 색 2개가 비슷하거나(ΔE < 20, 045 FR-06 선례) 중립색과 비슷함: 무늬가 사라져 보이지 않게 중립색을 반대 명도의 회색으로 바꾼다 [채택].
- 원경 세트와 경기장 항목 조합에서 외곽 실루엣이 원경과 겹쳐 뚫려 보임: 원경은 경기장 외곽 경계 상자 밖에만 놓인다.
- 생성기 버전이 올라가 같은 명세의 결과가 바뀜: 세이브는 항목 id만 가리키므로(077) 다시 배포한다. 공식 수용 인원 변화는 회귀 실패(FR-72).
- 전체 지붕(T5)·좁은 화각: 하늘·원경 지표(061 FR-11·15)는 061 규칙대로 "해당 없음" 처리.
- 템플릿·카탈로그 명세가 실존 경기장을 연상시키는 조합(특정 지붕 모양 + 특정 색 무늬): 자동 검사는 호환표·글자 없음까지만 하고, 육안 승인 질문에 포함한다(AC-08).

## 비기능 요구사항
- 결정론: (명세, 생성기 버전, Blender 버전) → 같은 glb·데이터 해시. 실행 중 변주는 (항목 id, 좌석 색, 원경 세트)의 함수 — 같은 입력이면 같은 이미지(048 NFR).
- 세이브 호환: 이 스펙은 저장하지 않는다. 세이브는 카탈로그 항목 id(안정 id, FR-31)만 가리킨다(077·022).
- 라이선스: 텍스처 CC0만(`Art/LICENSES.csv`). 좌석 무늬 글자·엠블럼 없음, 실존 경기장 형태·브랜딩 복제 금지(01-legal, 044 FR-50·51).
- 재생성: 레포의 생성 스크립트 + 카탈로그 명세 목록만으로 모든 경기장을 다시 만들 수 있다. 산출물을 손으로 고치지 않는다(50-art).

## 수용 기준
- AC-01 [로직]: 수용 인원 2,000 / 4,999 / 5,000 / 8,000 / 20,000 / 40,000 / 60,000 / 90,000으로 생성하면 실제 좌석 수가 요청 ±1% 이내이고, 좌석 데이터의 좌석 수 = 생성 요약의 공식 수용 인원이며, 규모 구간이 FR-02 표와 같다. 1,999 / 90,001 / −1 / 숫자 아님은 각각 0이 아닌 종료 코드·오류 메시지·출력 파일 없음 (FR-01~03·71).
- AC-02 [로직]: 유형 7종 각각을 호환표의 최소·최대 규모로 생성하면 형태 기술값이 FR-10 규칙을 만족한다(T2 열린 코너 4, T3·T5 막힌 코너 4, T4 트랙 있음·레인 6~8, T5 지붕 덮개 ≥ 90%·외장 파사드 있음, T6 대형 면 높이 ≥ 나머지 평균 × 1.4, T7 서로 다른 면 ≥ 3, T1 좌석 스탠드 ≥ 1면·1층). 호환표 밖 조합(예: T1 + R5, T5 + R2)과 알 수 없는 인자 값은 오류 종료 (FR-10~12·22~24·71).
- AC-03 [로직]: 카탈로그 전 항목과 044 기존 인자 세트(최소·기본·최대 + 새 최소 2천)에서 044 AC-01(규격)·AC-05(예산)·AC-06(인자 검증)·AC-07(카메라 가시성·런오프)·AC-08(라이트맵 UV)·AC-09(좌석 데이터)·AC-16(충돌 형상)이 통과한다 (FR-35·60, 경계).
- AC-04 [로직]: 개성 요소 — 무늬가 FR-20 6종 중 하나이고 좌석 영역에 글자·숫자 모양이 없다(좌석 무늬 맵 문자 인식 검출 0건 [채택]). 같은 항목에 서로 다른 클럽 색 2세트를 주면 좌석별 색 자리(색 1/색 2/중립)가 같고 쓰인 색은 각 클럽 색 2개 + 중립색 밖이 없다. 비슷한 색(ΔE < 20) 입력이면 중립색 대체가 일어난다. 지붕 앞쪽 기둥이 있는 항목에서 메인 카메라 → 피치 네 모서리 가시성 통과. 조명 형태가 FR-23 제약을 지킨다 (FR-20~25·27·33, 경계).
- AC-05 [로직]: 카탈로그 — 유형당 항목 ≥ 6, 합계 42~56, 항목 id 중복 0. 2,000~90,000을 100석 간격으로 훑으면 모든 값에서 ±15% 안 항목 ≥ 3개·유형 ≥ 2개(FR-32). R5~R6의 T3·T4·T5 항목이 각각 ≥ 1개. 같은 유형 항목 쌍 모두 주요 인자 ≥ 2개 차이(FR-34), 카탈로그 쌍별 IoU 표가 리포트에 있다 (FR-30~34).
- AC-06 [로직]: 모든 카탈로그 항목에서 042 AC-16(메인 카메라 위치가 거치 범위 안, 리플레이 앵글 전부 금지 영역 밖)이 통과한다. 좌석 데이터에 구역(홈/원정/중립)·'팀 A/팀 B' 블록 정보·블록별 지붕 덮임이 있고 원정 구역 비율 5~10%, T6 홈 응원 구역이 대형 면에 있으며, T1 입석 구역은 공식 수용에서 빠진다. 음향 속성(지붕 덮개 비율·폐쇄도 0~1·용적 등급·평균 거리)이 모두 있고 범위 안이며, 2천 석 T1의 폐쇄도·용적 등급이 9만 석 T5보다 작다 (FR-50~53).
