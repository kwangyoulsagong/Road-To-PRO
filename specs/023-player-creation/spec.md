# 023 — 선수 생성

상태: 초안
브랜치: feat/023-player-creation
기획 출처: docs/index.html § 기획서 1.2(핵심 컨셉 1), § 4.1(선수 생성), § 4.2(능력치 1~20), § 4.2.1(역할·성향·버릇) / 리서치 03 § B1(내부 0~100, 표시 1~20), § B2(주발·약발), § B4(CA/PA), § B7(절차적 생성·신체 앵커·PA 공식) / 리서치 05 § 5.2(커리어 경로), § 6.3(이름)

## 배경
게임의 첫 5분이다. 플레이어는 "내 선수"를 직접 만들고, 그 선택(국적·체형·포지션·아키타입·성격)이 이후 커리어 전체의 성장 속도·기용·이벤트로 이어진다. 잠재력은 숨겨서 "얼마나 클지 모른다"는 긴장을 남기되, 범위 힌트로 선택의 의미는 느끼게 한다. 같은 입력이면 같은 선수가 나와야 하고(결정론), 어떤 조합으로 만들어도 깨진 선수(능력치 범위 밖, 포지션에 쓸모없는 분포)가 나오면 안 된다.

## 범위
- 포함:
  - 생성 입력: 이름(성·이름), 국적, 생년(시작 나이), 주발·약발 수준, 키·체중, 주 포지션 1개 + 부 포지션 최대 2개, 아키타입, 성격 특성
  - 생성 출력: 초기 능력치(내부 0~100, 표시 1~20), CA, 숨김 PA, 숨김값(부상 경향·일관성·큰 경기·적응력), 초기 플레이 성향 14축, 초기 버릇(기본 없음), 포지션 친숙도, 시작 소속(유스 팀)
  - 국적별 유스 시스템 보정
  - 아키타입별 초기 능력치 분포
  - PA 범위 힌트 표시 규칙 (스카우트 리포트로 점차 좁혀짐)
  - 생성 화면 흐름 (단계별 입력 → 미리보기 → 확정)
  - 무작위 생성 버튼 (시드 기반)
- 제외:
  - 능력치 항목 정의와 엔진 매핑 (002가 제공)
  - 역할·성향·버릇 카탈로그 정의 (003이 제공)
  - AI 선수 대량 생성과 리그 티어별 분포 (020이 제공. 이 스펙은 같은 생성 모델을 "내 선수 1명" 입력으로 쓴다)
  - 성장·노화 (026)
  - 이름 필터·금칙어 데이터 자체 (051 소유)
  - 화면 컴포넌트·토큰 (037이 제공)

## 사용자 시나리오
1. 새 커리어 → "선수를 만들어 볼까요?" → 이름 입력 → 국적 선택 → 포지션·부포지션 → 아키타입 카드 고르기 → 체형(키·체중 슬라이더) → 주발 → 성격 특성 → 미리보기에서 능력치 레이더·주요 능력치 큰 숫자·잠재력 힌트("★★★☆☆ ~ ★★★★☆")를 본다 → 확정.
2. 미리보기에서 아키타입을 바꾸면 능력치가 즉시 다시 계산된다. 같은 선택으로 돌아오면 같은 값이 나온다.
3. "무작위로 만들기"를 누르면 모든 항목이 채워진다. 시드가 표시되고, 같은 시드를 넣으면 같은 선수가 나온다.
4. 키 210cm, 몸무게 최소처럼 극단 조합을 넣으면 허용 범위로 막히고 이유가 한 줄로 보인다.

## 요구사항

### 입력과 검증
- FR-01: 이름·성은 각각 1~20자(공백 앞뒤 제거 후). 빈 값·공백만·제어문자는 거부. 한글·라틴·확장 라틴 문자 허용. 이름 검사는 051 FR-46 API를 호출한다: 금칙어는 거부, 실존 의심은 경고만(차단하지 않음 — 본인 이름일 수 있음), 길이 초과는 거부. 실명 정책 A안 확정 (2026-11-02 사용자 결정).
- FR-02: 국적은 월드(020)의 국가 목록에서 고른다. 국적은 유스 시스템 보정(FR-20)과 이름 문화권 기본값에 쓰인다.
- FR-03: 시작 나이 15~18세 (기획서 § 3 커리어 루프 "유스(15~18세)"). 기본 16세 [제안]. 생년은 커리어 시작일 기준으로 역산한다.
- FR-04: 주발 왼/오. 약발 1~5. 무작위 생성 시 왼발 비율 약 21%, 약발 ≥4 비율 10~15% (리서치 03 § B2) [검증-2차, 설계값].
- FR-05: 키: 필드 N(181, 6) cm, GK N(188, 5) cm, 포지션 보정 CB +4, ST +2, W −3 (리서치 03 § B7). 입력 허용 범위는 평균 ±3σ로 자른다 [제안]. 체중 기본 = 22.5·(키/100)² kg, 입력 허용 ±10% [제안] (원문 ±2kg은 생성 노이즈).
- FR-06: 주 포지션 1개(GK, CB, FB, DM, CM, AM, W, ST 중) + 부 포지션 0~2개. 주 포지션과 같은 부 포지션, 중복 부 포지션은 거부. GK와 필드 포지션은 같이 고를 수 없다 [제안].
- FR-07: 아키타입은 주 포지션에 맞는 목록에서만 고를 수 있다 (예: 스피드형 윙어, 테크니션, 박스투박스, 타깃맨 — 기획서 § 4.1). 아키타입 목록과 포지션 매핑은 003의 역할 카탈로그와 연결한다 [미정: 아키타입 전체 목록과 개수].
- FR-08: 성격 특성 프로의식·야망·침착성·리더십·다혈질 등 (기획서 § 4.1). 플레이어는 "성격 카드"를 [미정: 개수] 개 고르고, 각 특성의 내부값은 선택에 따라 정해진 범위에서 시드로 뽑는다. 특성 사이 상충(예: 침착성 높음 + 다혈질 높음)은 [제안] 동시에 고르지 못하게 한다.

### 능력치 생성
- FR-10: 생성 모델은 020과 **같은** 잠재요인 모델을 쓴다: 일반 능력 g, 요인 f=[신체, 기술, 정신], 포지션 평균 μ_pos, 잔여 상관(Cholesky), 나이 보정 (리서치 03 § B7). 내 선수용 μ는 유스 등급 기준 [미정: 유스 μ_tier — 원문은 T1 68 ~ T4 45만 있음].
- FR-11: 아키타입은 요인 f와 포지션 템플릿에 가중치를 더해 분포를 바꾼다 (예: 스피드형 윙어 = 가속·최고속도·드리블 쪽으로 이동). 아키타입은 **CA 총량을 바꾸지 않고 분배만 바꾼다** — 같은 입력에서 아키타입만 바꾸면 CA는 같다.
- FR-12: 신체 앵커 상관: 키는 점프·헤딩·근력과 양(+), 가속·민첩성과 음(−) (리서치 03 § B7 잔여 상관 표). 키를 바꾸면 이 능력치들이 상관 방향대로 움직인다.
- FR-13: 생성 후 CA 예산으로 재스케일한다 (CA = Σ c_a·attr_a, 리서치 03 § B4). 공분산 행렬은 PSD 보정 후 분해한다.
- FR-14: 모든 능력치 내부값은 [0, 100]으로 자르고, 표시값 = 1~20 (변환 규칙은 002가 제공). 표시값 1 미만·20 초과는 나올 수 없다.
- FR-15: 숨김값(부상 경향·일관성·큰 경기 강도·적응력)은 시드로 뽑고 플레이어에게 직접 보이지 않는다. 성격 선택이 일부 숨김값의 평균을 움직인다 [제안: 예 — 프로의식 높음 → 일관성 +].
- FR-16: 플레이 성향 14축 초기값은 아키타입·성격에서 정한 평균 + 시드 노이즈 (0~100). 버릇은 생성 시 없음(획득 규칙은 003).
- FR-17: 포지션 친숙도: 주 포지션 1.0, 부 포지션 [제안] 0.6~0.8, 나머지 0 (리서치 03 § B4 Familiarity).

### 잠재력 (PA)
- FR-20: PA = CA + max(0, N(μ_gap(age), 6)), μ_gap(17) ≈ 18, μ_gap(21) ≈ 9, μ_gap(25) ≈ 2 (리서치 03 § B7). 15·16·18세 μ_gap은 이 점들을 잇는 보간 [제안: 선형 보간·외삽].
- FR-21: 국적 유스 시스템 보정: 국가 FootballStrength(0~1, 020 제공)가 높을수록 초기 CA와 μ_gap 평균이 소폭 오른다 [미정: 보정 크기]. 약한 국가는 대신 1군 데뷔 경쟁이 쉬운 출발 클럽을 받는다 [제안].
- FR-22: PA는 숨김값이다. 화면에는 범위 힌트(별 0.5 단위 하한~상한)만 보인다. 생성 직후 범위 폭은 [제안] 별 1.5개, 스카우트 리포트·나이 증가에 따라 좁혀진다 (좁히는 시점·규칙은 024/026이 이벤트로 호출, 표시 규칙은 여기서 정의).
- FR-23: 힌트 범위는 반드시 실제 PA를 포함한다. 힌트 하한 ≥ 현재 CA 별점.
- FR-24: PA 상한은 [미정] (원문 없음). 어떤 입력에서도 PA ≥ CA.

### 시작 소속과 출력
- FR-30: 시작 소속은 국적 국가의 유스 아카데미(리서치 05 § 5.2 Academy U16~U18). 클럽 후보는 020 월드에서 [제안] 국적 국가 1·2부 클럽 중 3곳을 제시해 고르게 한다. 후보 카드에 유스 아카데미 등급(020 FR-26)을 보여준다.
- FR-31: 확정 시 출력은 하나의 "선수 생성 결과"로 묶여 세이브(022)에 저장 가능한 형태여야 한다. 생성에 쓴 시드·입력값도 함께 저장해 재생성할 수 있다.
- FR-32: 무작위 생성: 하나의 64비트 시드에서 모든 항목을 결정한다. 시드는 화면에 보이고 입력할 수 있다.

### 화면 흐름
- FR-40: 단계: 이름 → 국적 → 포지션 → 아키타입 → 체형·주발 → 성격 → 미리보기 → 확정. 한 화면에 한 가지 일 (기획서 § 4.9). 뒤로 가기 시 이전 입력 유지.
- FR-41: 미리보기: 능력치 그룹별(기술·정신·신체) 표시값, 핵심 능력치 3개 큰 숫자, 역할 적합도 ★(003 제공 계산), 잠재력 힌트 별, 키·체중·주발. 입력을 바꾸면 300ms 안에 갱신.
- FR-42: 확정 전 확인 바텀시트 ("이 선수로 시작할까요?"). 확정 후에는 생성 입력을 바꿀 수 없다.
- FR-43: 입력 검증 실패 메시지는 해당 입력 바로 아래 한 줄.

## 경계 · 예외 상황
- 선수 생성 중 앱 종료: 생성 중 입력은 저장하지 않는다. 재실행하면 생성 첫 단계부터 다시 시작한다 [제안] (038 경계와 같은 규칙, 생성 확정 후 첫 자동 저장 전에 꺼지면 커리어는 만들어지지 않은 것으로 본다).
- 이름: 정확히 20자 허용, 21자 거부. 이모지·결합 문자(자모 분리 한글)·RTL 문자 처리 — 화면 표시 길이와 저장 길이 둘 다 검사.
- 키·체중 슬라이더 양 끝값에서 생성 결과가 능력치 범위 밖으로 나가지 않는다 (클램프 후 CA 재스케일로 총량 유지).
- 부 포지션 0개, 2개, GK + 부 포지션 시도.
- 아키타입 선택 후 주 포지션을 바꾸면 그 포지션에 없는 아키타입은 해제되고 다시 고르라고 알린다.
- 시드 0, 최대값(2^64−1), 음수 입력 문자열 → 파싱 규칙 명확히 (거부 또는 정규화).
- 15세 시작: 생년이 커리어 시작 연도 기준 정확히 15세가 되도록 생일이 시작일 이전인지 이후인지 경계 (시작일 당일 생일). 2월 29일 생일은 024 FR-33·경계 규칙(평년 3월 1일)을 따른다. 시작 나이 하한 15는 022 최소 나이 검증과 같은 값.
- 출발 클럽 후보(FR-30)가 3곳 미만인 작은 국가 → 있는 만큼 + 이웃 국가 클럽으로 채움 [제안]. 0곳이면 국가 선택 단계에서 그 국가를 고를 수 없게 표시.
- 공분산 행렬이 PSD 보정 후에도 수치적으로 분해 실패할 때 대체 규칙 (실패하면 안 됨 — 사전 검증 테스트로 막는다).
- 국가 목록이 비어 있거나 1개뿐인 모드 월드.
- 미리보기 반복 갱신 중 빠르게 입력을 바꿔도 마지막 입력의 결과만 보인다 (경합 없음).

## 비기능 요구사항
- 결정론: (입력값 전체 + 시드) → 생성 결과 비트 단위 동일. 입력 순서(어떤 순서로 단계를 거쳤는지)는 결과에 영향 없음.
- 세이브 호환: 생성 결과·시드·입력값은 022 스키마 버전에 맞춰 저장. 생성 모델 버전 번호를 같이 저장해, 모델이 바뀌어도 기존 세이브의 선수는 바뀌지 않는다.

## 수용 기준
- AC-01 [결정론]: 같은 입력 + 같은 시드로 2회 생성하면 모든 능력치·숨김값·성향·PA가 동일하다. 단계를 다른 순서로 거쳐 같은 입력에 도달해도 동일하다.
- AC-02 [로직]: 아키타입만 바꾼 두 선수(나머지 입력·시드 동일)의 CA 차이가 0.5% 이내다.
- AC-03 [로직]: 무작위 생성 10,000명에서 모든 내부 능력치 ∈ [0,100], 표시값 ∈ [1,20], PA ≥ CA, PA 힌트 범위가 실제 PA를 포함한다.
- AC-04 [로직]: 무작위 생성 10,000명에서 왼발 비율 21% ± 2%p, 약발 ≥4 비율 10~15%, 필드 선수 키 평균 181 ± 1cm·표준편차 6 ± 0.5 (포지션 보정 전 기준), GK 키 평균 188 ± 1cm.
