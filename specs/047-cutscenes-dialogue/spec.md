## 배경
선수 한 명의 인생을 다루는 게임이라 경기 밖 순간(입단 사인, 기자회견, 라커룸, 감독 면담, 프러포즈, 은퇴 권고)이 서사의 뼈대다. 이 순간들이 텍스트 한 줄로 지나가면 무게가 없고, 매번 손으로 만든 컷신을 쓰면 1인 개발로 감당이 안 된다. 그래서 **슬롯형 템플릿 연출 + 데이터 바인딩 + 대화 스크립트** 조합으로, 적은 템플릿으로 많은 순간을 만든다. 톤은 상황에 맞춘다: 데뷔골은 가볍고 들뜨게, 심장 이상 진단은 조용하고 진지하게.

## 범위
- 포함:
  - 대화 연출: 화자·대사·선택지(바텀시트)·자막, 대화 결과를 스토리렛 결과로 돌려주기
  - 대화 표현 형식 4종: 3D 장면 대화(기자회견·라커룸·면담 등), 2D 대화 카드(초상 + 대사), 메신저(연애·가족·에이전트 메시지, 기획서 4.10 — 화면은 038 관계 화면을 쓰고 이 스펙은 대화 노드만 공급), 텍스트만(받은편지함 본문, 038 FR-41). 어떤 형식으로 보일지는 이벤트 데이터의 연출 형식 필드가 정한다 (031이 필드를 가져야 함)
  - 템플릿 컷신: 입장·터널 워크아웃, 트로피 리프트(076 참조 — 우승 세레모니·3D 시상 장면은 076 소유), 입단 사인·기자회견, 라커룸 연설, 감독 면담, 진료실(질병·부상 진단), 은퇴 기자회견 [제안: 출시 목록은 미정]
  - 절차적 세리머니: 득점자 위치 → 코너플래그·관중석 방향 → 성격별 세리머니 → 동료 합류 (research 07 § 3.1)
  - 템플릿 바인딩: 등장 인물(내 선수·감독·동료·기자·가족), 의상, 배경 엠블럼(가상), 소품
  - 톤 프리셋: 축하 / 일상 / 긴장 / 진지 — 조명·카메라 움직임·음악·전환 속도를 함께 바꾼다
  - 스킵: 모든 컷신과 대사 진행은 건너뛸 수 있다. 건너뛰어도 결과(선택지 결과·상태 변화)는 같다
  - 15세 등급 표현 규칙: 연애·유흥은 화면 전환·텍스트로 암시
  - 현지화: 대사는 로컬라이즈 키, ko 기본, en 지원 (037 현지화 체계 사용)
- 제외:
  - 이벤트가 **언제·왜** 일어나는지, 선택지 결과 수치 (030 스토리렛 디렉터·031 이벤트 카탈로그가 제공. 이 스펙은 받은 이벤트를 **보여주고** 선택을 돌려준다)
  - 경기 하이라이트 재생·리플레이 카메라 (041, 042)
  - 대사 음성 녹음·립싱크 — 이후 확장 [미정] (research 07 § 3.2 도구 조사는 참고만). 출시 초기는 텍스트 대사 + 표정·제스처 애니메이션
  - 선수 모델·애니메이션 클립 자체 (043)
  - 컷신 사운드트랙 제작 (046은 덕킹 연결만, 음악 소스는 [미정])

## 사용자 시나리오
1. 이적 협상이 끝나면 새 클럽 사무실에서 사인하는 짧은 장면이 나오고, 기자회견으로 이어진다. 기자 질문이 나오면 아래에서 바텀시트가 올라와 답변 3개 중 하나를 고른다.
2. 첫 더비 이틀 전 라커룸에서 주장이 연설한다. 플레이어는 "같이 결의를 다진다 / 조용히 듣는다" 중 고른다.
3. 메디컬 테스트에서 심장 이상이 발견되면, 음악 없이 조용한 진료실 장면이 나온다. 의사가 차분히 설명하고, 선택지(즉시 은퇴 / 치료 후 복귀 도전 / 하위 리그 이적)가 신중한 문장으로 뜬다.
4. 연인에게서 메시지가 오면 메신저 화면이 열리고 답장 선택지를 고른다. 데이트 장면은 레스토랑 입구에서 화면이 어두워지고 "즐거운 저녁이었다." 한 줄로 넘어간다.
5. 골을 넣으면 하이라이트 안에서 내 선수가 코너플래그로 달려가 세리머니하고 동료들이 합류한다.
6. 이미 본 연출은 탭 한 번으로 건너뛴다.

## 요구사항

### 대화
- FR-01: 대화 데이터는 노드 단위: 화자, 대사(로컬라이즈 키), 표정·제스처 태그, 카메라 태그, 다음 노드 또는 선택지. 대화 스크립트 형식·도구는 [미정] (research 07 § 3.3: 대화형은 Yarn Spinner, 대량 텍스트는 ink 추천 — 둘 다 MIT).
- FR-02: 선택지는 바텀시트로 띄운다 (기획서 4.9). 선택지 수 2~4개 [제안]. 각 선택지는 결과 미리보기(예: "감독 신뢰 ↑ 가능성")를 보일지 이벤트 데이터가 정한다.
- FR-03: 선택 결과는 받은 이벤트 식별자와 함께 030에 돌려준다. 이 스펙은 상태(사기·신뢰 등)를 직접 바꾸지 않는다.
- FR-04: 대사 진행: 탭/클릭/키로 다음, 길게 누르면 빠르게, 자동 진행 옵션. 타이핑 효과는 끌 수 있다.
- FR-05: 자막·대사 상자: 화자 이름, 글자 크기 3단계, 배경 불투명도 조절 (research 07 § 5.3).
- FR-06: 문장 톤: 짧고 대화체 (기획서 4.9). 한 대사 최대 길이 ko 80자 / en 140자 [제안] — 넘으면 데이터 검증 오류.
- FR-07: 대사 안 변수(선수 이름, 클럽명, 금액, 날짜)를 바인딩한다. 숫자·통화·날짜는 언어별 형식.
- FR-08: 메신저 형식: 말풍선·보낸 시각·읽음 표시·답장 선택지 화면은 038 FR-80~83(관계 화면)이 원본이다. 이 스펙은 메신저 형식 이벤트를 대화 노드(화자·대사·선택지)로 바꿔 038 화면에 넘기고, 선택 결과를 030에 돌려준다. 메신저 화면 레이아웃 검증은 038 AC-13.

### 컷신 템플릿
- FR-10: 컷신은 슬롯형 템플릿 + 런타임 바인딩으로 만든다. 템플릿 하나가 여러 이벤트에 재사용된다 (research 07 § 3.1). 템플릿 목록과 출시 수량은 [미정].
- FR-11: 슬롯: 인물(최대 인원은 템플릿마다), 장소, 의상(클럽 유니폼·정장·캐주얼), 배경 엠블럼(가상 클럽), 소품, 톤 프리셋.
- FR-12: 입장 템플릿은 실제 선발 라인업을 바인딩하고, 선두는 실제 주장이다 (research 07 § 3.1).
- FR-13: 컷신 중 시뮬은 일시정지 상태다 (research 07 § 3.1). 컷신이 시뮬 결과·시각을 바꾸지 않는다.
- FR-14: 바인딩할 대상이 없을 때(예: 가족 없음, 주장 미정) 템플릿은 정의된 대체(다른 인물·생략 컷)로 진행하고 빈 슬롯을 화면에 노출하지 않는다.
- FR-15: 컷신 전환 직전에 필요한 에셋을 미리 로드해 시작 시 프레임 스파이크가 없게 한다 (기획서 5.5.1 장면 전환 프리로드).

### 절차적 세리머니
- FR-20~23 (절차적 세리머니): 060 참조 — 2026-11-11 사용자 결정으로 060(골 세리머니)에 이관됐다. AC-11도 060 AC-12로 이관.

### 톤과 등급
- FR-30: 톤 프리셋 4종: 축하 / 일상 / 긴장 / 진지. 이벤트 데이터가 톤을 지정한다.
- FR-31: 진지 톤 (커리어 위협 질병, 가족 병환, 심각한 부상, 은퇴 권고): 밝은 축하 연출·음악·카운트업 애니메이션 금지. 느린 전환, 조용한 앰비언스, 자동 진행 끔, 선택지 확정 전 한 번 더 확인 [제안] (기획서 4.6.1 "진지한 톤").
- FR-32: 15세 등급: 연애·유흥 장면은 장소 입구·화면 전환·텍스트 한 줄로 암시한다. 노출·성적 묘사·신체 접촉 클로즈업 없음. 음주는 결과(다음 날 컨디션 등)로만, 미화 없음. 도박은 가상 화폐로만 (기획서 4.10).
- FR-33: 실명 질병 묘사는 가볍게, 의학적 세부 묘사·자극적 표현 없음 (기획서 4.6.1).

### 스킵과 진행 상태
- FR-40: 모든 컷신·대사는 스킵 가능. 선택지가 있는 노드는 스킵하면 선택지 직전에 멈춘다 (선택은 건너뛸 수 없다).
- FR-41: 스킵해도 결과(선택 결과, 연출 종료 후 상태)가 끝까지 본 것과 같다.
- FR-42: 본 적 있는 템플릿 연출은 "다시 보지 않기" 옵션 [제안].
- FR-43: 컷신 도중 앱 종료·크래시 후 재시작: 이벤트는 컷신 시작 전 상태에서 다시 시작한다 (중간 상태 저장 안 함). 선택이 확정된 뒤의 종료는 결과가 유지된다 (확정 시점 저장은 022/030).

### 경계 · 예외 상황
- 같은 주에 컷신 이벤트 여러 개 (이적 + 결혼식): 030이 정한 순서대로 연속 재생, 사이에 전환 화면. 겹쳐 재생되지 않는다.
- 대사 변수 누락 (클럽명 없음): 로컬라이즈 키 원문·빈 괄호가 화면에 나오지 않는다. 데이터 검증 단계에서 오류로 잡는다.
- 긴 이름·긴 en 번역: 대사 상자·말풍선·바텀시트에서 잘리거나 겹치지 않는다 (000 `잘림 없음`·`겹침 없음` 단언).
- 선택지 0개 이벤트: 바텀시트 없이 "다음"으로 진행.
- 진지 톤 이벤트가 축하 이벤트 직후 (우승 직후 가족 병환): 축하 연출이 끝나고 전환 화면을 거쳐 톤이 바뀐다. 축하 음악이 진지 장면에 남지 않는다.
- 인물 바인딩 대상이 이미 이적·은퇴한 동료: 대체 인물로 바뀌고 대사도 대체 대사로.
- 재생 중 해상도·창 크기 변경: 레이아웃이 다시 계산되고 바텀시트가 화면 밖으로 나가지 않는다.
- 다크 모드: 대사 상자·메신저 화면 대비가 유지된다.
- 키보드·게임패드만으로 대화 진행·선택 가능.

## 비기능 요구사항
- 결정론: 같은 이벤트 + 같은 시드 → 같은 연출 선택(템플릿, 바인딩 인물, 세리머니). 연출은 게임 상태를 바꾸지 않는다 (결과는 030으로 돌려줄 뿐).
- 접근성: 자막 크기·불투명도, 자동 진행, 깜빡임 효과 제한, 카메라 흔들림 끄기 (research 07 § 5.3).
- 세이브 호환: 진행 중 컷신 상태는 저장하지 않는다. "본 연출" 목록은 세이브에 포함 [제안].

## 수용 기준
- AC-01 [로직]: 대화 데이터 검증기가 (누락된 로컬라이즈 키, 최대 길이 초과, 존재하지 않는 다음 노드, 도달 불가 노드, 선택지 5개 이상)을 모두 오류로 보고한다. 정상 샘플 데이터는 오류 0.
- AC-02 [로직]: 선택지를 고르면 (이벤트 식별자, 선택 인덱스)가 030 인터페이스로 정확히 1회 전달되고, 이 스펙의 코드가 게임 상태를 직접 바꾸지 않는다.
- AC-03 [로직]: 선택지 노드 직전까지 스킵하면 선택지에서 멈춘다. 끝까지 본 경우와 스킵한 경우의 전달 결과가 같다.
- AC-04 [결정론]: 같은 이벤트·같은 시드로 2회 재생하면 (템플릿, 바인딩 인물, 세리머니 동작, 카메라 컷 순서) 해시가 같다.

- AC-06 [로직]: 진지 톤 이벤트의 연출 데이터에 축하 음악·카운트업·밝은 전환 큐가 0개다. 축하 이벤트 직후 진지 이벤트가 오면 축하 음악 큐가 진지 장면 시작 전에 종료된다.
