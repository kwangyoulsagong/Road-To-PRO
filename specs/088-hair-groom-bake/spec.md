## 배경
062로 선수가 "사람"에 가까워졌지만, 사용자는 생성 헤어("뾰족 대가리", "탈모 같다")와 얼굴("애니메이션 같다")을 계속 거부했다. 2026-11-22 시안 작업에서 두 가지가 승인됐다. ① **얼굴·피부·눈**: MPFB 사람 생성(MakeHuman CC0 피부 재질·고해상도 눈·눈썹·속눈썹 에셋) — "얼굴은 좋아". ② **헤어**: 가닥 그루밍 v2(흐름장·두께 상한·가이드 가닥, 참고 사진과 나란히 비교해 맞춤) 4종 — 포마드·가일컷(3:7)·시스루·가르마(6:4 펌).
시안은 Blender 렌더용(가닥 15~16만 개, 고해상도 텍스처)이라 게임에 그대로 못 넣는다. 이 스펙은 승인된 모습을 **게임 예산 안의 선수 모델로 옮기고**, 옮긴 결과가 시안과 같아 보이는지 나란히 비교로 확인한다.
**전면 교체 원칙 (2026-11-22 사용자 결정 "다 이번걸로 다 대체 해야돼 예전꺼 남기면 안돼")**: 062의 체형(자체 기준 선수 + 체형 축)·바탕 머리·절차적 피부(몸·얼굴)·눈과 절차적 헤어(셸 매개변수 방식 35종)는 하나도 남기지 않는다("얼굴 피부 체형이든 모든"). 모든 선수의 몸·체형은 시안과 같은 MPFB 사람 생성(체형 매크로·인종 혼합·얼굴 타깃), 피부·눈·눈썹·속눈썹은 MakeHuman CC0 에셋, 모든 헤어 스타일은 그루밍 v2 시안(사진 비교 승인)에서 굽는다. 옛 생성 경로와 옛 생성물은 지운다.

## 범위
- 포함:
  - 몸·체형: 시안과 같은 MPFB 사람 생성(성별·나이·근육·체중·비율·키 매크로 + 인종 혼합)으로 선수 몸을 만든다. 062 기준 선수·체형 축·바탕 머리 7종을 대체. 뼈대(043 22뼈·Humanoid·손가락 뼈)와 클립 82개는 그대로 동작
  - 얼굴·피부: 몸 전체 피부와 얼굴을 MakeHuman CC0 피부 재질, 눈은 고해상도 눈, 눈썹·속눈썹은 시안과 같은 에셋으로. 지역 얼굴형·피부톤 단계·수염·표정은 새 사람 위에서 다시 만든다
  - 의상: 유니폼(셔츠·반바지·양말)·축구화·정강이 보호대·정장도 옛 메시를 남기지 않고 **새 몸 기준으로 전부 다시 만든다**("kit 옷도 … 다 수정하면 돼"). 기준은 062 의상 요구(FR-20~27)·구운 디테일(FR-90·91)·043 번호/이름 영역 그대로, 실존 클럽·브랜드 디자인 복제 금지(01-legal)
  - 헤어 **전 스타일**(062 분류표 35종, 삭발 제외 34종): 스타일마다 그루밍 v2 시안을 만들어 참고 사진과 나란히 비교 → 사용자 승인 → 게임 헤어(셸 + 가닥 카드 + 구운 텍스처)로 굽는다. 이미 승인된 4종은 해당 스타일을 대체: 포마드 → 쿠이프(14), 가일컷 → 가르마 투블록(30), 시스루 → 텍스처드 크롭(16), 가르마 → 커튼(15). 나머지 30종은 새로 시안을 만든다
  - 굽기 품질 판정: 시안 렌더와 게임 렌더의 머리카락 실루엣·색 비교 지표
  - 옛 경로 제거: 062 절차적 헤어 생성(셸 매개변수 표)·절차적 얼굴 피부·눈과 그 생성물·테스트 기준을 지운다. 옛 출력이 남지 않았는지 검사한다.
  - 스타일 시안 절차를 문서로 남김
- 제외:
  - 런타임 가닥(스트랜드) 렌더링 — 기획서는 "클로즈업 컷신에서만 시험"으로 남김, 이번엔 안 함
  - MakeHuman 헤어 팩(대부분 여성·장발, 사용자 판단 "쓸 만한 건 4개뿐") — 쓰지 않음
  - 유료 에셋 (사용자 결정 "유료는 안돼")
  - 키트 색·무늬 체계·번호 폰트 변경 (043·062 그대로)

## 사용자 시나리오
1. 상반신·전신 클로즈업에서 선수 몸이 시안처럼 사람 체형·피부로 보이고(마네킹·플라스틱 없음), 세리머니 클로즈업에서 얼굴이 시안처럼 사실적인 피부·눈·눈썹·속눈썹을 가진다(애니메이션 같지 않다).
2. 모든 헤어 스타일이 클로즈업·LOD0에서 승인한 시안과 같은 모양으로 보인다(헬멧·뾰족·탈모 없음). 옛 절차적 헤어나 옛 얼굴을 가진 선수는 없다.
3. 방송 시점 원거리(LOD1·LOD2)에서도 각 헤어의 실루엣 계열이 유지되고, 카메라가 다가와 등급이 바뀔 때 머리 모양이 튀지 않는다.

### 헤어 그루밍 굽기
- FR-10: 모든 헤어 스타일을 승인된 그루밍 시안에서 굽는다(시안 승인 없는 스타일은 게임에 넣지 않는다): 실루엣은 기하(셸 + 가닥 카드), 결·가닥·다발·웨이브·끝 흩어짐은 가닥 원형에서 구운 텍스처(색 밝기·불투명도·결 방향·차폐)로 표현한다(062 FR-90 원칙).

- FR-13: 바탕 머리 호환 — 시안은 한 사람 머리에서 그루밍했지만, 게임 헤어는 062 바탕 머리 전부와 체형 극단에서 두피 간격·관통 0(062 FR-45·057 FR-13)을 지킨다.
