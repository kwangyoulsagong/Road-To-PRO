## 배경
선수 시점 게임이라도 구단이 살아 있어야 커리어가 흔들린다. 성적이 나쁘면 감독이 잘리고, 신임 감독이 오면 주전 경쟁이 처음부터 다시 시작된다(기획서 4.5 "리스크이자 기회"). 경기 안에서도 AI 감독이 지고 있으면 공격수를 넣고, 이기고 있으면 잠근다. 경고가 쌓이면 다음 경기를 못 뛴다. 지금까지 이 판단들은 담당 스펙이 없었다(009·012·025가 각자 "담당 없음"으로 남김). 이 스펙은 **구단과 AI 감독의 의사결정**을 맡고, 실행은 기존 스펙에 넘긴다.

## 범위
- 포함:
  - 구단 시즌 목표 설정 (리그 순위·컵 목표·재정 목표)과 이사회 평가
  - 감독 경질 판단·시점, 대행·신임 감독 선임 (신임 감독 성향 결정)
  - 감독 교체 알림 발행 → 025가 신뢰 리셋 수행
  - AI 감독의 경기 중 운영: 스코어·시간·퇴장·부상에 따른 전술 변경 요청, 교체 시점·인원 결정
  - 경기 간 징계 관리: 경고 누적 출전정지, 퇴장 징계 경기 수, 대회별 누적 초기화, 출전정지 선수 선발 제외
  - 심판 배정 (경기별 심판 프로필 선택 규칙)
  - 경기 전 명단 부족 처리: 출전 가능 선수가 리그 최소 인원 미만이면 유스 승격으로 충원 [제안], 그래도 부족하면 리그 규칙(020 FR-15)에 따라 몰수 — 016·024가 호출
  - 구단 재정 상태 단계 (건전 / 긴축 / 위기)와 이적 예산·연봉 예산 조정 신호
  - 강등·승격 확정 후 구단 상태 갱신 (예산·목표·감독 평가)
- 제외:
  - 감독 신뢰 수치·선발 점수 계산 → 025
  - 경기 중 전술 변경의 실제 반영(앵커 보간) → 009 FR-71
  - 교체 대상 선수 후보 점수 → 025 FR-10, 교체 실행·교체 슬롯 규칙 → 006
  - 경기 안 카드 판정 → 012
  - 이적 입찰·가치평가 → 029, 계약 → 028
  - 이벤트 문구·선택지 → 030/031 (이 스펙은 이벤트 트리거 사실만 발행)
  - 클럽·감독 생성 → 020
  - 내 선수가 감독이 되는 모드 (은퇴 후 확장, 036 범위 밖)

## 사용자 시나리오
1. 시즌 11라운드, 우리 팀이 강등권이다. 받은편지함에 "구단이 감독에게 최후통첩을 보냈다는 기사"가 온다. 2경기 뒤 감독이 경질되고, 신임 감독은 유스 선호라 18세인 내 선수가 선발 명단에 든다.
2. 0-1로 지고 있는 70분, 상대 감독이 아니라 우리 감독이 수비형 미드필더를 빼고 공격수를 넣는다. 내 선수가 교체 투입된다.
3. 시즌 다섯 번째 경고를 받았다. 경기 후 "다음 리그 경기 출전정지" 알림이 뜨고, 다음 주 선발 명단에 내 선수가 없다. 컵 경기는 뛸 수 있다.
4. 구단 재정 위기 단계에 들어가면 이적 예산이 깎이고, 고연봉 선수 판매 의향이 오른다 (내 선수 이적 이벤트 계기).

## 요구사항

### 시즌 목표 · 이사회 평가
- FR-01: 시즌 시작 시 각 클럽의 목표를 정한다: 리그 기대 순위 구간(명성·예산 순위 기반 [제안]), 컵 목표(라운드), 재정 목표(적자 한도). 목표는 시즌 중 바뀌지 않는다 (감독 교체 시에도 유지).
- FR-02: 이사회 평가 점수는 매 경기 후 갱신한다. 입력: 현재 순위와 기대 순위 차, 최근 N경기 승점(폼, [제안 N=6]), 컵 결과, 재정 상태, 감독 재임 기간(짧을수록 관용). 계수 [미정].
- FR-03: 평가 점수 구간 → 상태: 안정 / 주시 / 최후통첩 / 경질. 상태 전이는 한 단계씩만 (안정에서 바로 경질 금지) [제안]. 단 중대 사건(구단 규정 위반 이벤트)은 예외로 즉시 경질 가능.
- FR-04: 상태가 바뀌면 이벤트 트리거 사실을 발행한다 (030/031이 기사·소문·면담 이벤트로 연결).

### 감독 경질 · 신임
- FR-10: 경질 판단 시점: 경기 후 처리 단계(024 주간 루프)와 시즌 종료 시. 시즌 마지막 [제안 3]경기 전에는 시즌 중 경질 빈도를 낮춘다 [제안 확률 ×0.3].
- FR-11: 경질되면 즉시 대행(수석코치, 기존 성향의 [제안 70%] 유지)이 맡고, [제안 1~3]주 안에 신임 감독을 선임한다. 대행 기간에도 025 신뢰 리셋은 대행 부임 시 1회, 신임 부임 시 1회 일어난다 [제안]. (리셋 횟수 규칙은 025와 확정)
- FR-12: 신임 감독은 월드의 무직 감독 풀 또는 생성(020 규칙)에서 고른다. 선택 기준: 클럽 명성·예산 적합, 클럽 전술 성향과의 일치 [제안 가중], 다른 클럽 재직 감독 영입은 [제안] 상위 명성 클럽만.
- FR-13: 신임 감독 성향(선호 포메이션, 유스 선호, 피지컬 선호, 로테이션 성향 τ — 025 리서치 05 § 3.2 고집형 0.03 / 로테이션형 0.08)을 확정하고 025에 감독 교체 알림을 보낸다 (025 FR-32).
- FR-14: 경질된 감독은 무직 풀로 간다. 무직 감독은 시즌이 지날수록 명성이 감소 [제안]. 다른 클럽에 재취업 가능.
- FR-15: 월드 전체 감독 교체 수를 시즌 단위로 기록한다 (밸런스 지표, AC-08).

### AI 감독 경기 중 운영
- FR-20: 결정 시점: 결정 틱마다가 아니라 경기 시각 [제안 5분] 간격 + 사건 직후(골, 퇴장, 부상, 하프타임)에만 판단한다.
- FR-21: 상태 입력: 스코어 차, 남은 시간, 필드 인원 차, 대회 상황(무승부가 충분한지 — 컵 2차전 합산 등), 팀 체력 평균, 감독 성향(공격적/보수적 [제안 0~1]).
- FR-22: 출력 1 — 팀 지시 변경 요청: 라인 높이, 압박 강도, Tempo, Directness, Risk, TimeWasting (리서치 03 § A6). 출력 2 — 포메이션 변경 요청(포메이션 데이터의 공격형·수비형 변형). 요청은 009 FR-71 입구로 보낸다.
- FR-23: 출력 3 — 교체 결정: 언제(시각), 몇 명, 어떤 포지션 필요. 대상 선수 선택은 025 FR-10 점수에 위임. 교체 상한·창 규칙은 006을 따른다.
- FR-24: 기본 경향 [제안]: 지고 있고 남은 시간 ≤ 30분이면 공격 변경 확률 증가, 이기고 있고 ≤ 15분이면 수비 변경·TimeWasting 증가, 퇴장으로 수적 열세면 포메이션 인원 감소 변형(009 FR-92) 이후 블록 하강. 계수 [미정].
- FR-25: 같은 판단을 연속으로 반복하지 않는다 (변경 후 [제안 10분] 쿨다운, 단 새 사건 발생 시 해제).
- FR-26: 모든 판단은 SimEvent로 기록한다 (006): 판단 시각, 입력 요약, 출력. 하이라이트·텍스트 타임라인(039)이 "전술 변경" 표시에 쓴다.
- FR-27: 내 선수의 팀도 AI 감독이 운영한다 (플레이어는 감독이 아님). 키 모먼트 선택(019)이 감독 판단을 직접 바꾸지 않는다.

### 경기 간 징계
- FR-30: 012가 경기 안에서 낸 카드(경고·퇴장, 사유)를 경기 후 받아 선수별 누적 기록에 더한다.
- FR-31: 출전정지 규칙은 **대회 규칙 데이터**로 정의한다: 경고 누적 임계값(예: [제안] 5장 → 1경기, 10장 → 2경기), 누적 초기화 시점(예: 리그 [제안] 19라운드 후 1차 초기화), 직접 퇴장 기본 [제안 1~3경기 — 사유별], 경고 2장 퇴장 [제안 1경기]. 실존 리그 규정을 그대로 옮기지 않고 가상 대회 규칙으로 둔다.
- FR-32: 징계는 대회별로 분리한다 (리그 징계는 리그 경기에만 적용) [제안 — 대회 데이터에서 공유 여부 지정 가능].
- FR-33: 출전정지 선수는 그 경기 선발·벤치 후보에서 제외된다 (025 선발 입력에 '출전 불가' 플래그 전달).
- FR-34: 출전정지 소화는 해당 대회 경기가 실제로 치러질 때만 차감한다 (연기된 경기는 차감 안 함).
- FR-35: 시즌이 끝날 때 남은 출전정지는 다음 시즌 같은 대회로 이월 [제안]. 이적하면 같은 리그 이적일 때만 유지 [제안].
- FR-36: 징계 발생·소화·해제 각각을 이벤트 트리거로 발행한다 (031 '경기 · 커리어' 이벤트 연결).
- FR-37: 감독 퇴장(012 FR-28)은 다음 경기 벤치 착석 금지 [제안 1경기]. 이 동안 대행이 경기 운영(FR-20~26)을 맡고 성향은 [제안 70%] 유지.

### 심판 배정
- FR-40: 심판 프로필(엄격도, 일관성, 어드밴티지 성향 — 012 FR-34 데이터)을 리그별 풀로 둔다. 이름은 가상 (051 제공).
- FR-41: 배정 규칙 [제안]: 경기 중요도(더비, 상위권 맞대결, 결승) 높을수록 일관성 높은 심판 확률 증가. 같은 심판이 같은 팀을 [제안 3]경기 연속 맡지 않는다.
- FR-42: 배정은 일정(021) 확정 후 경기 [제안 1주] 전에 결정하고 경기 입력(006)에 넣는다. 결정론: (월드 시드, 경기 id) → 같은 배정.

- FR-43: 경기 전 명단 부족 처리 (범위 참조): 출전 가능 인원 = 1군 − 부상·질병(027) − 출전정지(FR-30~35) − 소집. 리그 최소 인원 미만이면 유스에서 포지션 필요 순으로 임시 승격 [제안], 유스도 부족하면 몰수 + 이벤트. 같은 입력 → 같은 승격 명단.

### 재정 상태
- FR-50: 클럽 재정 상태 단계: 건전 / 긴축 / 위기. 입력: 수입(020 클럽 수입 모델), 연봉 총액(028), 이적 수지(029), 상금. 판정 주기: 월 1회 [제안].
- FR-51: 긴축이면 이적 예산 [제안 −50%], 위기면 이적 예산 0 + 고연봉 선수 판매 의향 상승 신호를 029에 보낸다. 연봉 예산 상한은 028에 보낸다.
- FR-52: 재정 위기 진입·해소는 이벤트 트리거로 발행한다 (기획서 4.6.2 '구단 재정 위기').
- FR-53: 승격 시 수입·예산 상향, 강등 시 하향 [제안 배수 미정] — 020 리그 등급 수입표 기준.

### 경계 · 예외 상황
- 시즌 첫 경기 전에 경질 판단 금지 (평가 데이터 없음). 시즌 첫 [제안 4]경기는 최후통첩 이상 금지.
- 같은 주에 경질과 경기 당일이 겹침 → 그 경기는 이전 감독 판단 유지 (025 경계와 동일), 경질 처리는 경기 후.
- 무직 감독 풀이 비어 있음 → 020 규칙으로 즉시 생성. 생성 실패 시 대행이 시즌 끝까지 (오류 아님, 경고 로그 아님 — 정상 경로).
- 한 클럽이 한 시즌에 감독을 [제안 3]명 넘게 바꾸지 않는다 (상한).
- 출전정지 경기 수 > 남은 시즌 경기 수 → FR-35 이월.
- 같은 경기에서 경고 누적 임계 도달 + 퇴장 → 두 징계를 각각 계산해 합산 [제안] (대회 데이터로 '큰 쪽만' 선택 가능).
- 연기·몰수된 경기(016·024): 출전정지 차감 규칙 FR-34, 이사회 평가는 몰수 결과 반영.
- 대회 규칙 데이터에 누적 임계값이 없음 → 로드 단계에서 오류 (조용한 기본값 금지).
- 교체 창·인원이 이미 소진된 상태에서 교체 결정 → 결정 자체를 내지 않는다 (요청 후 거절이 아니라 사전 차단).
- 필드 인원 7명 미만 → 경기 중단은 006/012. 이 스펙은 판단하지 않는다.
- 경질 판단과 시즌 종료 처리가 같은 날 → 시즌 종료 순서(024 FR-32)를 따른다.
- 내 선수 클럽 감독이 경질되는 비율이 월드 평균과 다르면 안 된다 (플레이어 클럽 특혜·차별 금지).

## 비기능 요구사항
- 결정론: 이사회 평가·경질·신임 선택·경기 중 판단·심판 배정은 모두 시드 RNG(001)의 별도 스트림. 같은 시드·같은 입력 → 같은 판단.
- 세이브 호환: 누적 경고·출전정지·감독 재임 기록·무직 감독 풀·재정 단계는 세이브(022)에 포함. 경기 중 판단 상태는 경기 중 저장 정책(README P1)에 따름.
- 투명성: 모든 판단에 이유 요약(입력값)을 남겨 디버그·밸런스에서 "왜 잘렸는지" 볼 수 있다.

## 수용 기준
- AC-01 [로직]: 기대 순위 1~4위 구간 클럽이 10경기 연속 강등권이면 상태가 안정→주시→최후통첩→경질 순으로 한 단계씩 전이하고, 건너뛰지 않는다.
- AC-02 [로직]: 시즌 첫 4경기 동안 어떤 클럽도 최후통첩 이상 상태가 되지 않는다 (100시즌 헤드리스).
- AC-03 [로직]: 경질 시 대행이 즉시 지정되고, 신임 감독 선임까지 3주 이내, 025에 감독 교체 알림이 정확히 규칙 횟수만큼 발행된다 (FR-11 확정 횟수).
- AC-04 [로직]: 지고 있는 팀은 75분 이후 공격 쪽 지시 변경 비율이 이기고 있는 팀보다 높고, 이기고 있는 팀은 TimeWasting 상승 비율이 높다 (1,000경기 통계, 방향만 검증).
- AC-05 [로직]: 교체 결정은 006 교체 상한·창을 절대 넘지 않는다 (1,000경기 위반 0).
- AC-06 [로직]: 경고 누적 임계 도달 선수는 다음 같은 대회 경기 선발·벤치 후보에서 빠지고, 다른 대회 경기에는 나온다 (대회 분리 설정일 때).
- AC-07 [로직]: 연기된 경기는 출전정지를 차감하지 않고, 실제 치러진 경기만 차감한다. 시즌 종료 시 남은 정지는 다음 시즌으로 넘어간다.
- AC-08 [로직]: 월드 3시즌 헤드리스에서 시즌당 감독 교체 비율이 [제안] 리그 클럽 수의 15~35% 범위 안이고, 한 클럽 한 시즌 교체 ≤ 3회, 내 선수 클럽과 다른 클럽의 경질 비율 차이가 통계적으로 유의하지 않다.
- AC-09 [로직]: 같은 심판이 같은 팀을 4경기 연속 맡는 경우 0건. 결승·더비 경기 심판의 평균 일관성이 리그 평균보다 높다.
- AC-10 [로직]: 재정 위기 단계 클럽의 이적 입찰 0건(029), 긴축 단계 이적 예산은 건전 대비 50%.
- AC-11 [결정론]: 같은 시드로 1시즌 2회 시뮬 → 경질 목록·시점·신임 감독·경기 중 판단 로그·심판 배정·징계 기록 해시 동일.
- AC-12 [로직]: 대회 규칙 데이터에 누적 임계값 필드가 빠진 파일을 로드하면 명확한 오류로 거부된다.
- AC-13 [E2E]: `e2e/050-manager-sacked` — 고정 세이브에서 경질 직전 경기를 진행하면 받은편지함에 경질 기사 카드, 홈 화면 감독 카드가 대행으로 바뀐 화면이 기준 이미지와 일치. 프로필: smoke.
- AC-14 [E2E]: `e2e/050-suspension` — 다섯 번째 경고를 받은 경기 후 결과 화면의 "다음 경기 출전정지" 표시와, 다음 주 선발 명단 화면에서 내 선수가 '출전정지' 배지로 빠진 화면이 en/ko 모두 잘림 없이 일치. 프로필: smoke + `phone-portrait`.
- AC-15 [E2E]: `e2e/050-tactic-change` — 고정 시드 경기 70분 지는 상황에서 텍스트 타임라인(039)에 "전술 변경"·"교체" 항목이 표시된 화면이 일치. 프로필: smoke.
- AC-16 [성능]: 성능 예산 표 항목이 기준 프로필에서 예산 안, 경기 중 판단 GC 0 B.
- AC-17 [로직]: 출전 가능 1군 10명(리그 최소 [제안] 11명 + 벤치) 픽스처에서 유스 임시 승격으로 명단이 채워지고, 유스도 없으면 몰수 처리 + 이벤트 1개. 같은 입력 2회 → 같은 승격 명단.
