# 036 — 은퇴 · 레거시 · 뉴게임+

상태: 초안
브랜치: feat/036-retirement-legacy
기획 출처: docs/index.html § 기획서 1.2(엔딩은 은퇴: 레거시 점수와 명예의 전당, 다음 세대로 이어지는 뉴게임+), 3(커리어 루프: … → 하락기 → 은퇴 → 레거시), 4.8(레거시 점수: 트로피, 개인상, 대표팀 기록, 클럽 레전드 지위 / 은퇴 후 경로: 코치·해설가·에이전트 확장 모드(장기 로드맵) / 뉴게임+: 자녀 선수로 2세대 커리어), 4.6.1(커리어 위협 질병 → 은퇴 권고 이벤트), 4.6.2(은퇴·레거시 10) / § 리서치 05 §5.3(포지션별 은퇴 연령 평균·σ [U], 은퇴 확률 logistic 식)

## 배경
이 게임의 엔딩은 은퇴다. 커리어 동안 쌓은 트로피·기록·관계가 "레거시 점수"로 정리되고, 명예의 전당에 남는다. 그리고 자녀(또는 제자)로 다음 세대 커리어를 시작할 수 있다. 은퇴는 나이·출전·부상·질병에서 자연스럽게 다가와야 하고, 플레이어가 언제 끝낼지 선택하는 무게가 있어야 한다.

## 범위
- 포함:
  - 은퇴 경로: 자발적 은퇴(선택), 은퇴 권유(시즌 말 확률), 강제 은퇴(커리어 위협 질병·부상에서 즉시 은퇴 선택, 027이 트리거), 계약 없음 장기화
  - 시즌 말 은퇴 확률 모델 (리서치 05 §5.3 logistic)
  - 은퇴 경기·작별 이벤트 훅 (031)
  - 레거시 점수: 구성 요소와 계산, 등급
  - 명예의 전당: 계정(로컬) 단위로 역대 커리어 보관·비교
  - 클럽 레전드 지위 판정
  - 커리어 요약 화면 (기록·트로피·타임라인)
  - 뉴게임+: 자녀(033 기록) 또는 제자로 2세대 커리어 시작, 이어받는 것과 안 이어받는 것
  - 은퇴 후 경로(코치·해설·에이전트)는 **선택지 표시와 기록만** (확장 모드는 장기 로드맵)
- 제외:
  - 질병·부상의 은퇴 권고 판정 → 027 (이 스펙은 은퇴 처리만)
  - 능력치 하락 곡선 → 026
  - 이벤트 텍스트 → 031
  - 은퇴 후 지도자·해설·에이전트 플레이 모드 → 범위 밖 (장기 로드맵, 기획서 4.8)
  - 세이브 파일 형식 → 022 (명예의 전당 저장 위치·형식은 022와 협의)

## 사용자 시나리오
1. 34세 시즌 말, 출전 시간이 줄자 "은퇴를 고민하고 있어요" 이벤트가 뜬다. 1년 더 뛰기로 한다.
2. 35세에 은퇴를 선택. 은퇴 경기 하이라이트 후 커리어 요약 화면에 트로피, 캡, 골, 레거시 점수 큰 숫자와 등급이 나온다.
3. 명예의 전당에서 이전 커리어 2개와 나란히 비교한다.
4. "자녀로 다음 세대 시작"을 고르자, 아버지/어머니의 레거시 일부(명성 보너스, 유스 아카데미 관심)를 이어받은 새 선수 생성 화면으로 넘어간다.

## 요구사항

### 은퇴 판정
- FR-01: **은퇴 판정 — 이 스펙이 소유** (024는 시즌 경계 FR-32에서 호출만). 시즌 말마다 은퇴 확률 (리서치 05 §5.3):
  `P(은퇴/시즌말) = logistic(0.9·(age − mean_pos) + 1.5·(1 − MinutesShare) + 1.0·장기부상 − 0.8·Ability_norm − 0.5·계약잔여)`
  포지션별 평균 은퇴 연령 [U]: GK 37(σ 2.5), CB 34(σ 2), FB/CM 33.5(σ 2), W/ST 33(σ 2). 원문 미검증 값이므로 튜닝 출발값.
- FR-02: AI 선수: 확률 판정으로 바로 은퇴. 내 선수: 확률이 [제안] 0.3 이상이면 "은퇴 고민" 이벤트(031) → 선택(은퇴 / 1년 더 / 하부 리그·해외 이적 모색). 내 선수는 강제 은퇴하지 않는다 (예외: FR-03).
- FR-03: 강제 경로: 027의 커리어 위협 질병·부상 은퇴 권고 이벤트에서 "즉시 은퇴"를 고르면 즉시 은퇴 처리 (시즌 중에도). "치료 후 복귀 도전" 실패 시 선택지가 줄어드는 규칙은 027 FR-36이 소유 (즉시 은퇴 / 하위 리그 이적 2개). 이 스펙은 은퇴 처리만 한다.
- FR-04: 계약 없음(자유계약) 상태로 [제안] 1년 이상 소속 없으면 은퇴 권유 이벤트. 40세 이상이 시즌 말에 계약 오퍼 0개면 같은 이벤트를 연다 [제안] (024에서 이동).
- FR-05: 자발적 은퇴: 시즌 말(또는 계약 만료 시) 언제든 선택 가능. 시즌 중 은퇴는 [제안] 지원하지 않음 (시즌 말로 예약).

### 은퇴 처리
- FR-10: 은퇴 시점에 커리어를 동결: 최종 기록 스냅샷(시즌별 클럽·출전·골·어시스트·평점 평균·트로피·개인상·대표팀 기록·이적료·최고 시장가치·최고 연봉·레전드 지위·자산 요약·가족).
- FR-11: 은퇴 경기 이벤트(031): 마지막 홈 경기를 은퇴 경기로 지정 가능 [제안], 하이라이트(018)에 "마지막 경기" 가중치.
- FR-12: 은퇴 후 경로 선택지 표시: 코치 / 해설가 / 에이전트 / 조용한 은퇴 — 선택은 기록만 하고 이후 플레이 모드는 없음 (장기 로드맵). 선택 가능 조건 [제안] (예: 코치는 Respect·리더십 기반).
- FR-13: 은퇴 후 세이브는 "완료된 커리어"로 잠기고 다시 진행할 수 없다. 은퇴 직전 자동 백업 세이브 1개 [제안].

### 레거시 점수
- FR-20: 구성 (기획서 4.8): 트로피, 개인상, 대표팀 기록, 클럽 레전드 지위. 추가 [제안]: 통산 출전·골·어시스트(포지션 보정), 최고 시장가치, 커리어 길이, 하이라이트급 장면 수.
- FR-21: 포지션 공평성: GK·수비수도 같은 수준의 점수에 도달할 수 있게 포지션별 지표를 쓴다 [제안] (GK: 클린시트·선방, 수비수: 태클·인터셉트·클린시트, 리서치 05 §8 시사점 1).
- FR-22: 대회 수준 가중: 리그 수준(020 피라미드 티어)·대회 종류(리그·컵·대륙·국가대표)별 가중치 [제안].
- FR-23: 점수 → 등급 [제안] 5단계 (로컬 레전드 → 클럽 레전드 → 국가 영웅 → 월드 클래스 → 불멸). 구간은 헤드리스 커리어 시뮬 분포로 정한다 (상위 1% = 최고 등급 [제안]).
- FR-24: 점수 내역(어느 항목이 몇 점)을 보여줄 수 있게 항목별 점수를 저장한다.

### 클럽 레전드
- FR-30: 클럽별 레전드 지위 판정 [제안]: 그 클럽 출전 ≥ 200 또는 (≥ 100 ∧ 주요 트로피 ≥ 1) 또는 클럽 역대 득점 상위 5위. 라이벌 클럽 이적 이력이 있으면 감점(034 팬 평판 연동).

### 명예의 전당
- FR-40: 완료된 커리어를 로컬 명예의 전당에 보관 (세이브와 별도, 세이브를 지워도 남음 [제안]). 항목: 이름, 포지션, 국적(가상), 활동 기간, 대표 클럽, 레거시 점수·등급, 주요 기록, 세대(1세대/2세대…).
- FR-41: 정렬·비교: 점수순, 세대별, 두 커리어 나란히 비교.
- FR-42: 명예의 전당 데이터 손상 시 해당 항목만 건너뛰고 나머지는 보인다.

### 뉴게임+
- FR-50: 시작 조건: 은퇴 완료 커리어에서 자녀(033 기록, 시작 가능 나이 [제안] 15세가 되는 시점까지 월드 진행) 또는 제자(코치 경로 선택 시, 자녀 없을 때 대체).
- FR-51: 이어받는 것 [제안]: 부모 레거시 등급에 따른 시작 명성 보너스, 부모 클럽 아카데미 관심(첫 클럽 선택지에 포함), 성씨, 성향 일부(033 자녀 성향 시드 기반 유전 [제안] 성향 축 14개 중 무작위 3개 부모값 ±15), 가족 이벤트 훅. 이어받지 않는 것: 능력치, 돈 대부분(상속 [제안] 상한 있음), 관계 수치.
- FR-52: 월드는 같은 월드를 이어서 진행 [제안] (부모 시대 선수들이 감독·베테랑으로 남아 있음). 진행 연수만큼 월드를 빠르게 돌린다: **시즌 단위 근사 모드** [제안] — 경기는 016 저정밀을 시즌 결과 단위로, 성장·노화(026)·은퇴(FR-01)·재계약(028)·이적(029)은 주 단위 대신 시즌 단위로 묶어 계산. 주간 루프(024)를 12년 × 52주 그대로 돌리지 않는다 (024 기본 세계 1시즌 90 s로는 성능 예산을 못 맞춤). 시즌 단위 근사의 분포는 주간 진행과 [제안] 주요 지표(평균 CA, 은퇴 연령, 클럽 명성 순위) ±5% 안이어야 한다.
- FR-53: 2세대 선수 생성은 023 선수 생성 화면을 쓰되, 이어받은 값이 미리 채워지고 일부 고정.

### 화면 계약
- FR-60: 커리어 요약 화면: 레거시 점수(가장 큰 숫자, 카운트업), 등급, 항목별 점수, 시즌 타임라인(클럽 이동), 트로피 진열, 대표팀 기록, 은퇴 후 경로 선택.
- FR-61: 명예의 전당 화면: 목록 카드, 비교 화면.

## 경계 · 예외 상황
- 커리어 1시즌 만에 은퇴(질병) → 레거시 점수 계산이 0 나누기 없이 동작, 최저 등급.
- 15세 유스 단계에서 커리어 위협 질병 → 은퇴 처리 가능해야 함 (1군 기록 0).
- 같은 시즌 말에 계약 만료·은퇴 확률·이적 오퍼 동시 발생 → 024 FR-32 시즌 경계 순서(은퇴 판정 → 임대 종료 → 계약 만료)를 따르고, 은퇴 판정 단계 안에서는 027 강제 경로 → 은퇴 고민 이벤트 → 029 이적 순서 [제안].
- 은퇴 직전 이적·협상 진행 중 → 은퇴 확정 시 029 FR-55·028 경계 규칙으로 모두 취소, 유효 계약 해지.
- 은퇴 확정 직후 스폰서(034)·장부(032)·대표팀(035) → 각 스펙 규칙(스폰서 시즌 말 종료, 장부 유지, 대표팀 후보 제외).
- 뉴게임+ 빠른 진행 도중 앱 종료 → 진행 시작 전 자동 저장 지점으로 복귀 (진행 결과는 결정론이라 다시 돌려도 같다).
- 자녀가 아직 어림(예: 은퇴 시 자녀 3세) → 뉴게임+ 시작 시 월드를 12년 저정밀 진행. 진행 시간이 성능 예산 안이어야 함.
- 자녀 0명 & 코치 경로 아님 → 뉴게임+ 선택지에 "제자" 대신 "새 선수로 같은 월드 시작" [제안].
- 레거시 점수 오버플로 없음 (정수 또는 상한).
- 명예의 전당 항목 수 많아짐(100+) → 목록 가상 스크롤.
- 은퇴 후 잠긴 세이브를 모드·편집기로 수정 시도 → 049가 처리, 이 스펙은 잠금 플래그만.

## 비기능 요구사항
- 결정론: 은퇴 판정·뉴게임+ 성향 유전·월드 빠른 진행은 시드 RNG. 같은 세이브·시드 → 같은 결과.
- 세이브 호환: 명예의 전당 형식은 버전 관리, 이전 버전 항목을 읽을 수 있어야 한다 (022).
- 순수 C#, UnityEngine 비참조.

## 수용 기준
- AC-01 [로직]: 은퇴 확률 식이 입력 경계값(나이 = 평균, MinutesShare 0/1, 장기부상 0/1, 계약잔여 0)에서 식과 일치한다. 포지션별 평균·σ 표가 데이터로 로드된다.
- AC-02 [로직]: 헤드리스 월드 시뮬 20시즌에서 AI 선수 은퇴 연령 분포의 포지션별 평균이 표 평균 ±1세 안 (튜닝 목표 [제안]).
- AC-03 [로직]: 내 선수는 확률 판정으로 강제 은퇴되지 않고, 확률 ≥ 임계일 때만 은퇴 고민 이벤트가 뜬다. 027 강제 경로에서 즉시 은퇴 선택 시 즉시 은퇴된다.
- AC-04 [로직]: 은퇴 시 기록 스냅샷 필드가 모두 채워지고, 은퇴 후 세이브는 진행 불가 상태다. 직전 백업 세이브가 1개 생긴다.
- AC-05 [로직]: 레거시 점수 항목별 합 = 총점이고, 같은 성적의 GK·CB·ST 샘플 커리어(포지션별 상위 10% 성적)가 같은 등급에 든다 (포지션 공평성).
- AC-06 [로직]: 1시즌 커리어·0경기 커리어에서 계산 오류(0 나누기·NaN) 없이 최저 등급이 나온다.
