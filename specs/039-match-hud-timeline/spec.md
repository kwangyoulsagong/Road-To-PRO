# 039 — 경기 HUD · 텍스트 타임라인 · 미니맵

상태: 승인됨
브랜치: feat/039-match-hud-timeline
기획 출처: docs/index.html § 기획서 4.4(경기 참여 방식: 하이라이트 + 키 모먼트, 사이는 텍스트 타임라인·미니맵으로 빠르게 넘김, 재생 속도, 경기당 8~15개, 시청 2~3분), § 4.9(옛 UI 방향: 키 모먼트 선택은 바텀시트 — 2026-11-11 037 FR-23 선택 패널로 재정의) / § 아키텍처 1(UI2 경기 HUD: 스코어버그·평점·배속), § 4(하이라이트 재생 흐름: 키 모먼트면 일시정지 후 선택지) / research 07 § 5.1(경기 HUD 중계 스타일), § 5.3(접근성: 색만이 아닌 텍스트 병기, 카드 아이콘 모양 차이), § 2.4(즉시 리플레이 규칙)

## 배경
경기 90분은 화면 없이 계산되고, 플레이어는 하이라이트 장면과 내 선수의 키 모먼트만 본다 (기획서 4.4, 확정). 그 사이 시간은 **텍스트 타임라인과 미니맵으로 빠르게** 넘긴다. 이 스펙은 경기를 보는 동안 화면 위에 올라가는 모든 정보 층(스코어버그, 내 선수 평점·체력, 배속, 리플레이 표시, 타임라인, 미니맵)과 키 모먼트 선택 패널을 정한다. 장면 선정은 018, 3D 재생은 041, 2D 재생은 040, 키 모먼트 규칙은 019가 제공한다. HUD는 SimEvent와 재생 시계만 읽는다.

## 범위
- 포함:
  - 스코어버그: 팀 약칭 3글자, 스코어, 경기 시간, 추가시간 +N, 카드 아이콘 (research 07 § 5.1)
  - 상태 배너: VAR 확인, 교체(L-bar), 리플레이 시작 와이프와 'REPLAY' 표시 (research 07 § 5.1)
  - 내 선수 패널: 실시간 평점(6.0 시작, 이벤트 가감), 체력 막대, 감독 지시 토스트 (research 07 § 5.1)
  - 재생 조작: 배속 1x / 1.5x(기본) / 2x / 3x, 일시정지, 장면 건너뛰기, 남은 장면 수 (기획서 4.4)
  - 하이라이트 사이 텍스트 타임라인 (분 단위 이벤트 줄) + 미니맵 빠른 넘김
  - 키 모먼트: 일시정지, 상황 설명 한 줄, 선택 패널(037 FR-23), 선택 후 재개 (기획서 4.4, 아키텍처 4)
  - 경기 종료 → 경기 후 화면(038)으로 넘김
  - 2D 매치뷰(040)와 3D 하이라이트(041) 양쪽 위에 같은 HUD
- 제외:
  - 장면 선정·점수화(018), 장면 재생·카메라(041, 042), 2D 탑뷰 렌더(040)
  - 키 모먼트 발생 조건·선택지 생성·결과 반영(019)
  - 평점 계산식(015). HUD는 015가 주는 값을 표시만
  - 해설 자막: 해설 없음 (확정 사항). 대사 자막은 047

## 사용자 시나리오
1. 경기가 시작되면 좌상단에 "HOM 0 – 0 AWY 00:00"이 보이고, 첫 하이라이트까지 텍스트 타임라인이 빠르게 흘러간다 ("12' 상대 코너킥", "17' 내 선수 패스 성공").
2. 하이라이트 장면이 1.5배속으로 재생된다. 골이 나면 스코어가 바뀌고 'REPLAY' 와이프 뒤 리플레이가 0.5x로 나온다.
3. 내 선수가 결정적 패스를 하면 평점이 6.4 → 6.9로 오른다. 체력 막대가 70분쯤 줄어든 게 보인다.
4. 수비 뒷공간이 열리는 순간 화면이 멈추고 선택 패널에 "① 침투 요구 ② 내려와서 받기 ③ 포지션 유지"가 뜬다. 고르면 그 장면이 이어서 재생된다.
5. 배속을 3x로 바꾸면 남은 장면이 빨라지고, 다음 경기에도 그 배속이 기본으로 유지된다 (041 FR-10).

## 요구사항

### 스코어버그 · 배너
- FR-01: 좌상단 스코어버그: 홈·원정 약칭 3글자, 스코어, 경기 시간(분:초), 추가시간 +N, 각 팀 카드(경고·퇴장) 표시 (research 07 § 5.1).
- FR-02: 경기 시간은 재생 중인 장면의 시뮬 시각을 따른다. 타임라인 빠른 넘김 중에는 넘기는 시각을 따른다. 장면이 바뀔 때 시간이 거꾸로 가지 않는다 (리플레이 제외: 리플레이 중에는 원래 시각을 고정 표시 + 'REPLAY').
- FR-03: 골이 나면 스코어가 바뀌는 시점은 공이 골라인을 넘는 시뮬 시각이다 (재생보다 먼저 바뀌어 결과를 미리 알려주지 않는다).
- FR-04: 카드는 색만으로 구분하지 않는다 (경고·퇴장 아이콘 모양 차이, research 07 § 5.3).
- FR-05: VAR 확인 배너, 교체 L-bar(나가는 선수·들어오는 선수), 리플레이 와이프 + 'REPLAY' 표시, 리버스 앵글 리플레이면 '리버스 앵글' 라벨(플래그는 042, 리플레이 상태는 041이 제공). 리플레이 표시는 이 스펙이 그리는 유일한 곳이다. 배너는 동시에 하나만 보이고 나머지는 대기열에서 순서대로.
- FR-06: 팀 약칭은 클럽 데이터(020)에서 받는다. 약칭이 같은 두 팀이 붙으면 구분 규칙 [미정] (색 띠, 홈/원정 표기).

### 내 선수 패널
- FR-10: 실시간 평점: 경기 시작 6.0, 이벤트마다 015가 주는 값으로 갱신. 바뀔 때 카운트업 + 증감 표시 (037 FR-21).
- FR-11: 체력 막대: 0~100, 시뮬 체력 값 (027·006이 제공).
- FR-12: 감독 지시 토스트: 지시 내용 한 줄 (예: "크로스 그만 올려라", 기획서 4.2.1). 지시 준수 여부는 019·025가 다룬다.
- FR-13: 내 선수가 벤치면 패널은 "벤치에서 대기 중"으로 바뀌고, 교체 투입 시 그 시각부터 평점·체력을 표시한다.
- FR-14: 내 선수가 퇴장·부상 교체되면 패널은 최종 평점과 사유를 표시하고 이후 갱신하지 않는다.

### 재생 조작
- FR-20: 배속 1x / 1.5x / 2x / 3x. 기본 1.5x (확정). 속도 규칙·저장은 041 FR-10이 원본이다. HUD는 버튼과 현재 값을 보이고 041에 변경을 보낸다.
- FR-21: 리플레이는 0.5x 슬로모 (확정). 리플레이 중 배속 버튼은 이후 라이브 장면 배속을 바꾼다 (041 FR-56과 같은 규칙).
- FR-22: 일시정지/재개, 현재 장면 건너뛰기, 남은 하이라이트 수 표시 ("3/11").
- FR-23: 키 모먼트 장면은 건너뛸 수 없다 (선택이 필요). 건너뛰기를 누르면 키 모먼트 시점까지 이동한다.
- FR-24: "모든 하이라이트 건너뛰기" 버튼을 둔다 (확정 (2026-11-02 사용자 결정)). 동작은 041 FR-21: 남은 하이라이트 3D 재생은 건너뛰되 **키 모먼트는 남긴다** — 남은 키 모먼트마다 이 스펙의 텍스트 타임라인 + 미니맵으로 상황을 보여주고 선택 패널을 띄운다 (019). HUD는 버튼만 둔다.
- FR-25: 배속 변경은 다음 프레임에 반영되고, 재생 중인 장면의 시뮬 시각 위치를 유지한다.

### 텍스트 타임라인 · 미니맵
- FR-30: 하이라이트 사이 구간은 텍스트 타임라인으로 보인다: 분 표시 + 이벤트 한 줄 (골, 슈팅, 카드, 교체, 부상, 내 선수 관여 이벤트). 표시할 이벤트 종류와 문구 키는 SimEvent(006) 종류별로 정의한다.
- FR-31: 미니맵: 피치 탑뷰에 공 위치와 양 팀 점(내 선수 강조)을 보인다. 빠른 넘김 중 공 위치가 이동 경로로 보인다.
- FR-32: 빠른 넘김 속도: 하이라이트 사이 구간을 [제안] 최대 3초 안에 넘긴다 (경기 1회 시청 2~3분 목표, 기획서 4.4). 구간 길이에 비례하되 상한·하한을 둔다.
- FR-33: 타임라인 줄을 누르면 해당 시점 요약을 볼 수 있다 (재생 이동은 아님) [제안].
- FR-34: 타임라인과 미니맵은 시뮬 결과를 바꾸지 않는다. 재생 위치만 바꾼다.
- FR-35: **날씨 표시 필요 여부 — 필요, 아이콘 1개** (078 FR-52, 064 Q8): 텍스트 타임라인 상단에 경기 당일 대표 날씨 아이콘 1개만 둔다. 경기 중 날씨 변화(064 타임라인)는 HUD에 예고·갱신하지 않는다. 문구는 ko/en 리소스(037), 길이 넘침 없음. 값은 064 경기 레코드에서 읽고 시뮬 결과를 바꾸지 않는다.

### 키 모먼트
- FR-40: 키 모먼트 시점에 재생이 멈추고, 화면이 살짝 어두워지며(딤), 상황 설명 한 줄과 선택 패널이 하이라이트 화면 아래쪽 가운데에 뜬다 (037 FR-23, 닫기 불가).
- FR-41: 선택지마다 짧은 설명과 성공 가능성 표시 방식 [미정] (숫자 확률 vs 높음/보통/낮음). 값은 019가 제공.
- FR-42: 선택 제한 시간 여부는 [미정]. 제한 시간이 있으면 남은 시간 표시와 기본 선택 규칙(019).
- FR-43: 선택하면 패널이 닫히고 019가 다시 계산한 결과로 재생이 이어진다. 재계산 중에는 진행 표시를 보이고, 재계산 시간이 [제안] 300 ms를 넘지 않으면 표시하지 않는다.
- FR-44: 키 모먼트 이후 스코어·평점·남은 하이라이트 수는 재계산 결과로 갱신된다. 이전 결과의 흔적(미래 이벤트)이 남지 않는다.

### 화면 · 레이아웃
- FR-50: HUD는 3D 하이라이트(041)와 2D 매치뷰(040) 위에 같은 배치로 올라간다.
- FR-51: HUD 요소가 경기 장면의 중심(공 주변)을 가리지 않도록 가장자리에 둔다. 화면 가장자리 안전 영역 [제안] 각 변 4%.
- FR-52: PC 해상도 범위(037 FR-80: 1280×800 ~ 3840×2160, 16:10 ~ 21:9)와 UI 배율(037 FR-81)에서 HUD가 겹치거나 잘리지 않는다. 검증은 `mac-m1-1600p`에서 창 크기·UI 배율을 바꿔 한다 (PC 전용 — 세로 화면 레이아웃은 만들지 않는다).
- FR-53: 텍스트 배율 130%(037 FR-62)에서도 스코어버그가 한 줄을 유지한다 (약칭·스코어·시간이 줄바꿈되지 않음).
- FR-54: HUD와 키 모먼트 선택 패널은 037 다크 토큰을 쓴다 (037 FR-10 다크 단독, 2026-11-11). 상승/하락 색(평점 증감)은 037 설정의 색 쌍을 따른다.

### 접근성
- FR-60: 관중 강도 시각 표시(청각 장애 대응, research 07 § 5.3): 설정으로 켜는 옵션 [제안: 기본 꺼짐]. 표시 값은 045의 구역별 흥분도(0~1)를 그대로 쓴다(046도 같은 값을 소리에 쓴다). 표시 위치는 스코어버그 옆 작은 막대 [제안]. 이 표시를 그리는 곳은 이 스펙이다.
- FR-61: 모션 줄이기(037 FR-41) 켜면 리플레이 와이프는 페이드로, 평점 카운트업은 즉시 값으로.
- FR-62: 키보드·게임패드로 배속·일시정지·건너뛰기·키 모먼트 선택이 가능하다.

## 경계 · 예외 상황
- 하이라이트 0개 경기 (지루한 0-0): 텍스트 타임라인만으로 경기를 끝까지 넘기고 경기 후로 간다.
- 하이라이트 15개 초과 요청(018의 상한 위반): 표시 쪽은 받은 그대로 재생하되 경고 로그.
- 추가시간 +0, +10 이상, 연장전(90+, 105, 120 [미정: 컵 대회 규칙 012·021]), 승부차기 표시 [미정].
- 큰 스코어 (10–0, 두 자리) 스코어버그 폭.
- 경고 2장 → 퇴장 표시 전환, 한 팀 퇴장 여러 명.
- 같은 시각에 골·카드·교체 동시 발생 → 배너 대기열 순서, 스코어 먼저.
- 키 모먼트가 리플레이 도중 또는 경기 마지막 순간(추가시간 종료 직전)에 걸리는 경우.
- 키 모먼트 선택 후 재계산 결과 남은 하이라이트가 0개가 되는 경우.
- 내 선수 교체 투입이 하이라이트 사이 구간에 일어나는 경우 패널 전환 시점.
- 배속을 재생 도중 빠르게 연속 변경, 일시정지 중 배속 변경.
- 내 선수가 출전하지 않는 경기는 HUD 없이 결과 요약만 (038 FR-92).

## 비기능 요구사항
- 결정론: HUD·재생 조작(배속, 일시정지, 건너뛰기)은 시뮬 결과에 영향을 주지 않는다. 같은 경기를 배속을 바꿔 봐도 최종 스코어·평점·이벤트 해시가 같다. 키 모먼트 선택만이 결과를 바꾼다 (019).
- 세이브 호환: 기본 배속 설정은 사용자 설정.

## 수용 기준
E2E는 `mac-m1-1600p` 1프로필 스크린샷 + 사용자 육안 승인이다 (2026-11-11 프로필 매트릭스·기준 이미지 비교 폐지, PC 전용). 해상도 차이는 같은 기기에서 창 크기·UI 배율을 바꿔 확인한다.

- AC-01 [E2E]: `e2e/039-match-view`: 픽스처 경기(골 2, 카드 1, 교체 1, 키 모먼트 1)를 처음부터 끝까지 재생하며 주요 시점(킥오프, 첫 타임라인, 골, 리플레이, 카드, 교체 L-bar, 키 모먼트 선택 패널, 종료)을 캡처. `mac-m1-1600p` 1프로필 스크린샷 + 사용자 육안 승인, 겹침·잘림 0.
- AC-02 [로직]: 재생 시계가 장면 전환·빠른 넘김을 거치며 단조 증가한다 (리플레이 구간 제외). 리플레이 중 표시 시각은 원래 이벤트 시각에 고정된다.
- AC-03 [로직]: 골 스코어 갱신 시각이 골 SimEvent의 시뮬 시각과 같다 (재생 프레임 기준 ±1 프레임). 골 장면 시작 시점의 스코어는 골 이전 값이다.
- AC-04 [결정론]: 같은 픽스처 경기를 1x, 1.5x, 3x, 중간 일시정지·건너뛰기 섞어 3회 재생하면 최종 스코어·내 선수 평점·이벤트 로그 해시가 모두 같다.
- AC-05 [로직]: 배너 대기열: 같은 시각 골+카드+교체가 오면 골 배너(스코어) → 카드 → 교체 순으로 하나씩 표시되고 동시에 둘이 보이지 않는다.
- AC-06 [E2E]: 경고 2장 픽스처에서 카드 아이콘이 경고 → 퇴장으로 바뀌고, 퇴장 아이콘은 경고 아이콘과 모양이 다르다.
- AC-07 [E2E]: 스코어 10–0, 추가시간 +12 픽스처에서 스코어버그가 한 줄을 유지하고 잘리지 않는다 (`mac-m1-1600p`에서 창 1280×800·2560×1080, 텍스트 배율 130% 포함).
- AC-08 [E2E]: `e2e/039-key-moment`: 키 모먼트 시점에 재생이 멈추고 닫기 불가 선택 패널에 선택지 3개가 보인다. Esc·건너뛰기로 닫히지 않는다. 선택 후 재생이 이어지고 스코어·남은 장면 수가 재계산 결과와 같다.
- AC-09 [로직]: 건너뛰기를 키 모먼트 이전에 누르면 키 모먼트 시점으로 이동하고, 키 모먼트를 넘어서 이동하지 않는다.
- AC-10 [E2E]: 하이라이트 0개 픽스처 경기가 텍스트 타임라인만으로 끝까지 진행되고 경기 후 화면으로 넘어간다. 콘솔 에러·경고 0.
- AC-11 [E2E]: 내 선수 벤치 → 63분 교체 투입 픽스처: 63분 전에는 "벤치에서 대기 중", 투입 후 평점 6.0과 체력이 표시된다. 퇴장 픽스처: 퇴장 이후 평점이 고정되고 사유가 보인다.

- AC-15 [E2E]: 키보드만으로 배속 4단계 전환·일시정지·건너뛰기·키 모먼트 선택이 된다 (`mac-m1-1600p`).
