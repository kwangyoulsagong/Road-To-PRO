# 056 — 사람다운 선수 모델 (MPFB2 CC0 바탕 · 얼굴 · 피부 · 머리카락)

상태: 초안
브랜치: feat/056-realistic-player-model
기획 출처: docs/index.html § 기획서 5.5.1(FM급 그래픽·저사양 60fps·선수 LOD), 4.4(하이라이트 3D) / CLAUDE.md 확정 결정(그래픽 FM급·AAA 아님, 선수 폴리곤 LOD0 6~10k / LOD1 2~3k, 실명 A안, 3D 아트 bpy 생성·CC0 텍스처) / 사용자 결정 2026-11-04: "모델이 인형 같다 → 실제 사람처럼, FIFA·FM 참고", 바탕은 **MPFB2 CC0**

## 배경
043에서 만든 선수는 bpy 튜브 메시라 하이라이트에서 "목각 인형"처럼 보인다. 어깨·가슴·종아리 같은 근육 덩어리가 없고, 얼굴은 형태가 아니라 무늬에 가깝다. FIFA(EA FC)는 실제 선수 얼굴 스캔과 경기장 볼류메트릭 캡처를 쓰고, FM26은 Unity로 엔진을 바꾸면서 새 3D 남녀 선수 모델과 Hawk-Eye 골격 데이터 + 자체 모캡을 쓴다(아래 리서치). 우리는 스캔도 모캡도 없고, 실존 인물을 닮게 만들 수도 없다(01-legal, 실명 A안). 그래서 **해부학 기반 공개 인체 모델(MakeHuman/MPFB2, CC0)**을 바탕으로 가상 인물을 절차적으로 만든다. 목표는 FIFA급 스캔 얼굴이 아니라 "**잘 빚은 찰흙 같은 사람 얼굴과 운동선수 몸**"이 내장 GPU 60fps 안에서 나오는 것이다.

## 리서치 요약 (공개 자료만)
- EA FC HyperMotion: 180경기 이상 실제 경기를 경기장 카메라로 볼류메트릭 캡처, 머신러닝으로 실시간 보폭·케이던스 조정, 상위 선수 1,200개 고유 러닝 스타일. FIFA 22는 Xsens 슈트 11v11 캡처 870만 프레임. ([EA Pitch Notes FC24](https://www.ea.com/games/ea-sports-fc/pitch-notes/news/fc-24-gameplay-deepdive), [Trusted Reviews](https://www.trustedreviews.com/explainer/what-is-hypermotion-v-4352934), [80.lv](https://80.lv/articles/ea-uses-machine-learning-for-animations-in-fifa-22))
- FM26: Unity 전환, 새 남녀 3D 모델, Hawk-Eye 골격 볼류메트릭 데이터를 애니메이션으로 변환해 자체 모캡과 섞음. Unity 비주얼 개편으로 사양 소폭 상승. ([PureXbox](https://www.purexbox.com/news/2025/09/football-manager-26-unveils-new-match-engine-with-huge-graphical-improvements), [FMScout](https://www.fmscout.com/a-fm26-match-engine-first-look.html), [TopGear](https://topgear.com/car-news/gaming/football-manager-26-review-fantastic-match-engine-tangled-mess-menus))
- 시사점: 둘 다 "사람다움"의 핵심을 **실측 데이터**에서 얻는다. 우리가 합법적으로 쓸 수 있는 실측 기반은 MakeHuman 인체 측정 기반 메시·체형 타깃(CC0)이다.
- MPFB2: Blender 4.2+ 확장. 베이스 메시·타깃·스킨 등 **핵심 에셋 CC0**(상용·비공개 게임 사용 가능), 코드는 GPL — 코드는 배포물에 넣지 않고 생성 도구로만 쓴다. "GameEngine" 리그는 Unity Mecanim 100% 매핑 보고. 저해상도 프록시 또는 베이크 후 내보내기 권장. 서드파티 에셋(일부 머리카락·옷)은 라이선스가 다를 수 있어 개별 확인. ([MPFB FAQ](https://static.makehumancommunity.org/mpfb/faq/use_in_closed_source.html), [MPFB 내보내기 문서](https://static.makehumancommunity.org/mpfb/docs/exporting.html), [CG Channel](https://www.cgchannel.com/2025/03/check-out-open-source-blender-character-generation-plugin-mpfb-2))
- FIFA·FM의 게임 파일·에셋·데이터는 보지도 가져오지도 않는다(01-legal). 위는 공개 기사·공식 발표만 참고한다.

## 범위
- 포함:
  - MPFB2 CC0 베이스 메시·체형 타깃으로 선수 몸을 생성하는 bpy 파이프라인 (043 `gen_player.py` 대체)
  - 운동선수 체형: 043 AppearanceGenerator의 키·BMI·체형 분포를 MPFB 타깃 값으로 옮기기, 근육 정의
  - 얼굴: 해부학 랜드마크가 있는 얼굴 형태, 결정론적 얼굴 변주, 눈(안구·홍채·눈꺼풀)·눈썹·귀·입술·수염 옵션
  - 피부: 피부 텍스처(CC0 또는 절차 생성)·노멀맵·피부 셰이더(저비용 산란 근사)
  - 머리카락: 043의 9개 스타일을 사람다운 머리카락으로 (카드 또는 셸)
  - 유니폼: 상의·반바지·양말 경계가 형태로 보이고 피부가 뚫고 나오지 않게. 043 유니폼 합성(색·글자) 파이프라인을 새 UV로 이식
  - LOD0/LOD1(/LOD2) 메시, 얼굴 클로즈업용 머리 LOD [제안, 결정 필요]
  - 043과의 호환: 뼈 이름·Humanoid 매핑·클립·발 접지·유니폼 합성·성능 예산 회귀 없음
- 제외:
  - 실존 인물을 닮게 만드는 기능, 사진 → 얼굴 생성 (01-legal)
  - 표정 애니메이션·립싱크 (047 컷신에서 다룬다)
  - 천 시뮬레이션 (유니폼은 스킨드 메시)
  - 달리기·킥 동작 품질 (055), 궤적·접촉 동기화 (054)
  - 관중 모델 (045)

## 사용자 시나리오
1. 하이라이트 방송 시점에서 선수들이 마네킹이 아니라 사람으로 보인다. 어깨와 허벅지에 근육 덩어리가 있고, 반바지 아래 무릎과 종아리 형태가 보인다.
2. 골 세리머니 클로즈업에서 내 선수 얼굴이 보인다. 눈두덩·광대·콧대·입술·턱선이 빚어진 형태로 있고, 눈이 반짝이며, 피부가 플라스틱처럼 번들거리지 않는다.
3. 같은 팀 22명의 얼굴·키·체형·피부색·머리 모양이 모두 다르고, 같은 세이브를 다시 열면 같은 얼굴이다.
4. 저사양 노트북(내장 GPU)에서도 하이라이트가 60fps로 돈다.

## 요구사항

### 바탕 · 라이선스
- FR-01: 선수 메시는 MPFB2 CC0 베이스 메시와 CC0 타깃으로 만든다. 생성은 bpy 스크립트로 자동이며 사람 손 작업이 없다(같은 입력 → 같은 glb).
- FR-02: 사용하는 MPFB2 버전과 에셋 목록을 고정하고, 쓰는 에셋마다 `Art/LICENSES.csv`에 한 줄을 남긴다. CC0가 아닌 에셋(서드파티 머리카락·옷 등)은 쓰지 않는다. MPFB2 코드(GPL)는 생성 도구로만 쓰고 게임 빌드에 포함하지 않는다.
- FR-03: MPFB2가 설치되지 않은 환경에서는 생성 스크립트가 명확한 오류로 멈춘다(설치 방법 안내). 생성 결과 glb는 LFS로 레포에 있으므로 Unity 빌드는 MPFB2 없이 된다.

### 몸 · 체형
- FR-10: 체형 입력은 043 AppearanceGenerator(역할별 키 GK 188 / DF 183 / MF 179 / FW 181 cm, BMI 23.2 ± 1.1, 체형 3축)를 그대로 쓰고, 이를 MPFB 타깃 값(키·체중·근육량·비율)으로 변환한다. 변환 결과 메시 키 오차 ≤ [제안] 1 cm.
- FR-11: 운동선수 체형: 체지방이 낮고 근육이 있는 형태(어깨 삼각근, 가슴, 허벅지 앞·뒤, 종아리, 둔근)가 실루엣과 음영으로 보인다. 근육량·체지방 타깃 범위 [제안] MPFB muscle 0.6~0.9, weight는 BMI에서 유도.
- FR-12: 비율: 머리 크기·팔 길이·다리 길이·어깨 너비 비율이 성인 남성 인체 측정 범위 안(MPFB 기본 비율을 벗어나는 임의 스케일 금지). 머리 높이 ≈ 키의 [제안] 1/7.5~1/8.
- FR-13: 043의 극단 체형(가장 작은·큰·마른·무거운)에서도 메시가 찢어지거나 관절이 꺾이지 않는다.

### 얼굴
- FR-20: 얼굴은 눈두덩(눈썹뼈), 안와, 광대, 콧대·콧방울, 인중, 입술(윗·아랫입술 경계), 턱선·턱끝, 귀(바깥 귓바퀴 형태)가 **기하 형태로** 있다(텍스처 무늬만으로 그리지 않는다).
- FR-21: 눈: 안구는 별도 형상 또는 동등 표현으로 흰자·홍채·동공·하이라이트(반사)가 있고, 위·아래 눈꺼풀이 안구를 덮는다. 눈이 얼굴 표면에 붙은 스티커처럼 보이지 않는다.
- FR-22: 얼굴 변주: 선수 id·시드로 MPFB 얼굴 타깃(코·눈·입·턱·광대·이마·귀 등) [제안] 20개 이상을 결정론적으로 섞는다. 같은 팀 22명 중 얼굴 형태 지표(랜드마크 거리 벡터)가 서로 [제안] 일정 거리 이상 다르다.
- FR-23: 피부색·눈 색·머리색·수염(없음·짧은 수염·턱수염 등 [제안] 4종)의 분포는 [미정: 리그·국적별 분포 — 043 외형 분포를 따른다].
- FR-24: 실존 인물 닮음 금지: 얼굴은 무작위 타깃 조합으로만 만든다. 실존 인물 사진·스캔·이름을 입력으로 쓰는 경로가 없다.

### 피부 · 셰이딩
- FR-30: 피부 텍스처: CC0 피부(MPFB 스킨 또는 Poly Haven·ambientCG 등) 또는 절차 생성. 알베도에 피부색 변화(볼·코·귀 붉은 기운, 수염 자리), 노멀맵에 근육·모공 수준 디테일, 거칠기(이마·코 약간 번들, 나머지 무광).
- FR-31: 피부 셰이더는 산란 근사(예: 랩 라이팅·사전 적분 피부 같은 저비용 방식)로 그림자 경계가 붉게 부드럽다. "플라스틱 피부" 금지 기준: 피부 정반사 하이라이트가 [제안] 일정 면적·세기를 넘지 않는다.
- FR-32: 텍스처 해상도: 몸 [제안] 1024², 얼굴 [제안] 1024²(클로즈업 머리 LOD에서만 2048² 허용 [제안]), 압축 포맷은 043 규칙.

### 머리카락
- FR-40: 043의 머리 스타일 9종(Short·Long·Curly·Bun·Fade·Afro·Mohawk·Dreads·Bald)을 사람 머리카락처럼 표현한다. 두피 위에 칠한 색 덩어리가 아니라 머리카락 볼륨과 가닥 방향이 보인다(카드·셸 등 방식은 플랜에서).
- FR-41: 머리카락이 머리·목·어깨를 뚫고 나오지 않는다(043 클립 전체에서).

### 유니폼
- FR-50: 상의 소매 끝·목 칼라·반바지 밑단·양말 윗단이 형태(턱·두께)로 보인다. 어떤 클립 포즈에서도 피부가 유니폼을 뚫고 나오는 프레임 0.
- FR-51: 043 유니폼 합성(팀 색, 번호·이름 글자, ΔE·글자 영역 기준)이 새 UV에서 같은 기준으로 통과한다.

### LOD · 예산 · 호환
- FR-60: 폴리곤: LOD0 6~10k tris, LOD1 2~3k (CLAUDE.md 확정). LOD0 안에서 머리 ≥ [제안] 2.0k tris를 얼굴 형태에 쓴다.
- FR-61: 클로즈업 머리 LOD [제안, 결정 필요]: 세리머니·컷신 클로즈업(카메라가 얼굴을 화면 높이 [제안] 25% 이상으로 잡을 때)에만 머리를 [제안] ≤ 6k tris 고해상도 버전으로 바꾼다. 동시에 최대 [제안] 2명. 확정 결정(LOD0 6~10k)의 예외라 사용자 승인 필요.
- FR-62: 뼈대·뼈 이름·Humanoid 매핑은 043과 같다(22뼈 + 필요 시 얼굴 보조 뼈는 Humanoid 밖). 043의 82개 클립·발 접지 IK·LOD 히스테리시스·Freeze가 수정 없이 동작한다.
- FR-63: 선수 25명 하이라이트에서 043 성능 예산(애니메이션 p95 ≤ 2 ms IL2CPP, GC 0)과 048 프레임 예산(p95 ≤ 16.6 ms, low-igpu-1080p)을 지킨다. 드로우콜·머티리얼 수는 043 대비 [제안] +25% 이내.

## 비기능 요구사항
- 결정론: 같은 선수 id·시드 → 같은 얼굴·체형·머리·피부 (생성 결과 해시 동일).
- 세이브 호환: 외형은 시드에서 다시 만든다. 세이브에 메시를 넣지 않는다(043과 같음).
- 법: 01-legal. 실존 인물 닮음 금지, CC0 외 에셋 금지, 상용 게임 에셋 금지.
