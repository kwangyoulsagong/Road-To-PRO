# 004 — 공 물리 · 공 상태 머신

상태: 승인됨
브랜치: feat/004-ball-physics
기획 출처: docs/index.html § 아키텍처 5(공 상태 머신), § 아키텍처 3(물리 서브스텝 100Hz), § 기획서 5.1(Ball Physics 간이 2.5D), § 리서치 01 A(A-1~A-8)

## 배경
패스가 얼마나 굴러가는지, 감아찬 프리킥이 얼마나 휘는지, 크로스가 어디에 떨어지는지가 하이라이트를 "축구처럼" 보이게 만든다. 공의 움직임은 모든 액션 판정(008)·피치 컨트롤(007)·골키퍼(011)·3D 재생(041)의 공통 기반이다. 같은 입력이면 언제나 같은 궤적이 나와야 리플레이와 키 모먼트 재시뮬(019)이 성립한다.

## 범위
- 포함:
  - 공 상태 6개(Controlled · Air · Bounce · Rolling · Rest · 아웃/골 판정용 경계 통과 신호)와 전이 규칙
  - Air: 중력 + 항력(드래그 크라이시스) + 마그누스 + 스핀 감쇠 (3D)
  - Bounce: 법선 반발 + 접선 마찰 충격량, 스핀 갱신
  - Rolling: `a + b·v` 감속 + 공기저항 (2D, 마그누스 무시)
  - 피치 표면 조건(건조·젖음·인조·침수·긴 잔디)과 공 종류(32패널·현대 공) 파라미터 세트
  - 고정 dt 서브스텝 적분, 선분 기반(swept) 접촉 판정 지원
  - 궤적 예측기: 같은 모델로 미래 궤적(위치·높이·속도·시각)을 미리 계산 (AI·피치 컨트롤·GK용)
  - 역산: 목표 거리·지점에 도달하는 초기 속도 계산 (패스 파워 결정용)
  - 골대·크로스바·골라인·터치라인 경계 통과 감지 신호
- 제외:
  - 누가 공을 차는지, 어떤 속도·스핀으로 차는지 (008이 제공)
  - 선수 몸과의 충돌·트래핑 성공 판정 (008·011이 판정하고, 이 스펙은 "Controlled로 전이" 입력만 받는다)
  - 골·아웃 이후 재시작 규칙 (012가 제공)
  - 날씨 생성 (표면 조건은 입력으로 받는다)
  - 3D 공 렌더링·회전 연출 (041)

## 사용자 시나리오
1. 내 선수가 25 m 땅볼 패스를 보내면, 하이라이트에서 공이 잔디 위를 자연스럽게 감속하며 동료 발 앞에서 멈춘다.
2. 감아찬 프리킥이 수비벽 바깥으로 나가서 골문 쪽으로 휘어 들어온다. 리플레이 0.5x에서도 궤적이 매끄럽다.
3. 비 오는 경기에서는 공이 더 높이 튀고, 젖은 짧은 잔디에서는 더 멀리 미끄러진다.

## 요구사항

### 상수와 파라미터 (리서치 01 A-1, A-8 기준값)
- FR-01: 공 파라미터 세트를 데이터로 가진다. 기본값: 질량 0.43 kg, 반지름 0.109 m, 공기밀도 1.2 kg/m³, β = ρA/(2m) ≈ 0.053 m⁻¹ [V], 중력 9.81 m/s².
- FR-02: 항력계수는 속도의 함수: `Cd(v) = CdHigh + (CdLow − CdHigh) / (1 + exp((v − vCrit)/w))`. 32패널: CdLow 0.47, CdHigh 0.20, vCrit 11 m/s, w 1.5 m/s. 현대 공: CdHigh 0.15, vCrit 15~18 m/s [D] (리서치 01 A-2). 공 종류를 파라미터로 선택할 수 있다.
- FR-03: 마그누스: 스핀 파라미터 `Sp = rω/v`, `C_L(Sp) = 0.35·(1 − exp(−Sp/0.15))`, `a_M = β·C_L·v²·(ω̂×v̂)` [D] (A-3). 속도 8 m/s 미만에서는 C_L을 0으로 페이드아웃해 역마그누스 구간을 피한다 (A-3 권고).
- FR-04: 스핀 감쇠 `dω/dt = −k·ω`, k 기본 0.07 s⁻¹ (범위 0.05~0.1) [D] (A-4).
- FR-05: 표면별 반발계수 e_n: 건조 0.62, 젖음 0.74, 인조 0.65, 접선 마찰 μ 0.5 [D/U] (A-5).
- FR-06: 구름 감속: `dv/dt = −(a + b·v) − β·Cd(v)·v²`, a = 0.40 m/s², b = 0.10 s⁻¹ [D] (A-6). 표면 보정 [D]: 젖은 짧은 잔디 a×0.8, 침수 a×2.5·b×2, 긴 잔디 a×1.3.
- FR-07: 모든 파라미터는 코드 상수가 아니라 튜닝 데이터에 둔다 (`.claude/rules/20-match-engine.md`).

### 상태 머신 (아키텍처 5)
- FR-10: 전이 규칙:
  - Controlled → Air: 뜬 킥 입력 / Controlled → Rolling: 땅볼 킥 입력
  - Air → Bounce: 공 하단이 지면(z ≤ 반지름)에 닿을 때
  - Bounce → Air: 반발 후 수직속도 ≥ 0.5 m/s / Bounce → Rolling: 수직속도 < 0.5 m/s
  - Rolling → Rest: 속도 < 0.05 m/s
  - Air·Rolling·Rest → Controlled: 외부(008·011) 컨트롤 판정 입력
- FR-11: 한 서브스텝 안에서 여러 전이가 필요하면(예: 착지와 동시에 구름 전환) 정해진 순서로 한 번씩만 처리하고, 상태와 전이 사유를 기록한다.
- FR-12: Bounce는 순간 상태다. 같은 서브스텝 안에서 Air 또는 Rolling으로 넘어가고, 바운스 이벤트(위치·입사속도·반발속도)를 남긴다.
- FR-13: Controlled 상태의 공은 소유 선수 기준 오프셋 위치를 따른다 (위치 계산은 008/005 입력). 이 상태에서는 물리 적분을 하지 않는다.

### 적분
- FR-20: 고정 dt 0.01 s(100 Hz) 서브스텝, semi-implicit(symplectic) Euler (A-8). 결정 틱(10 Hz)당 정확히 10 서브스텝 (006이 호출 순서를 제공).
- FR-21: 높이 z는 Air 상태에서만 적분한다. Rolling·Rest는 z = 반지름으로 고정.
- FR-22: 매 서브스텝 공의 이동 선분(시작점→끝점)을 제공해, 008·011이 선분-원 접촉 판정을 할 수 있게 한다 (30 m/s에서 서브스텝당 0.3 m 이동).
- FR-23: 바운스 접선 처리 [D] (A-5): 미끄럼 단계 `Δv_t = −μ(1+e)·v_n`, 그립 시 `v_t' = 0.6·v_t + 0.4·rω`, `ω' = v_t'/r`. 미끄럼과 그립 중 작은 변화량을 적용한다.

### 예측과 역산
- FR-30: 궤적 예측기는 실제 적분과 **같은 모델·같은 dt**로 미래 궤적을 계산한다 (A-8 "예측과 실제가 어긋나지 않게"). 출력: 시각별 위치·높이·속도·상태, 최초 착지 지점·시각, 정지 지점·시각, 경계 통과 시각.
- FR-31: 예측 길이 상한 10 s, 시각 간격은 호출자가 0.04~0.1 s 중 지정 (리서치 01 B-9 스캔 간격과 맞춤).
- FR-32: 예측은 공 상태를 바꾸지 않는다 (부작용 없음).
- FR-33: 역산: 땅볼 목표 거리 d에 정지 또는 지정 잔여속도로 도달하는 초속을 구한다. 실제 구름 모델로 한도 속도에서 한 번 굴린 궤적(속도·누적 거리 표)을 파라미터 로딩 시 만들고, 구름 ODE가 자율계라는 성질(초속 v0의 정지거리 = 전체 거리 − x(v0))로 표를 보간해 오차 0.2 m 이내로 맞춘다. 0.2 m 보장은 AC-10 테스트가 실제 적분기로 확인한다. (2026-11-02 수정: 런타임 재검증 시뮬 제거 — 성능 예산, 표 보간 오차 약 0.0004 m. 해석해 `v0/b − (a/b²)·ln(1 + b·v0/a)` (A-8)는 참고)
- FR-34: 역산: 뜬공 목표 착지점(거리·높이 제약)에 도달하는 초속·발사각 조합을 구한다. 해가 없으면(너무 먼 거리) "도달 불가"를 반환한다.

### 경계와 골대
- FR-40: 피치 규격 105×68 m, 골대 폭 7.32 m·높이 2.44 m (기획서 5A.1). 골포스트·크로스바는 반지름 0.06 m 원기둥으로 보고 반발한다 (e 0.6). (2026-11-02 승인)
- FR-41: 공 **전체**가 골라인·터치라인을 넘은 시점(공 중심이 선 바깥쪽 가장자리에서 반지름 이상 넘은 순간)을 경계 통과로 판정하고, 통과 서브스텝 안의 정확한 시각·지점을 보간해 신호로 낸다. 골/아웃 결정은 012.
- FR-42: 골망 안에 들어간 공은 골망 감속 영역에서 빠르게 멈춘다 (연출 일관성용, 정확도 요구 낮음). (2026-11-02 승인)
- FR-43: 디버그 진단 출력 (040 FR-30 레이어 '공 궤적'에 공급): 공 상태(Controlled/Air/Bounce/Rolling/Rest), 100Hz 궤적 점, 예측 착지점, 스핀 축·크기, 바운스 지점. 진단 출력은 시뮬 결과와 RNG 소비를 바꾸지 않고, 꺼져 있으면 추가 비용·할당이 0이다. (UI 검수 정리, 2026-11-02)

## 경계 · 예외 상황
- 속도 0(완전 정지) → Sp, v̂ 계산에서 0으로 나누기 금지. v < 1e-4 m/s면 항력·마그누스 항을 0으로.
- 스핀만 있고 속도가 거의 0인 공 → 마그누스 0, 스핀은 감쇠만.
- 극단 입력 속도(예: 60 m/s, 스핀 300 rad/s) → 입력 한도(속도 40 m/s, 스핀 180 rad/s [A-4 런처 최대])로 자르고 경고 이벤트 기록.
- 지면 아래로 파고든 위치(z < 반지름) → 같은 서브스텝에서 지면으로 보정하고 바운스 처리. 다음 스텝에 지면 아래 상태가 남으면 안 된다.
- 아주 낮은 반복 바운스(미세 떨림) → 수직속도 0.5 m/s 미만 규칙으로 반드시 Rolling에 수렴해야 하고, 바운스 무한 반복 금지.
- 골포스트 맞고 골라인 위에서 튀는 공, 골대 모서리(포스트+크로스바 동시 접촉) → 한 서브스텝 안 두 번 접촉도 결정론적 순서로 처리.
- 같은 서브스텝 안에서 경계 통과와 바운스가 동시 발생 → 시각 순으로 처리하고 둘 다 기록.
- NaN·무한대 발생 → 즉시 실패 이벤트(테스트에서 실패)로 처리, 조용히 넘어가지 않는다.
- 표면 파라미터가 비정상(a < 0, e > 1) → 로딩 시 거부.

## 비기능 요구사항
- 결정론: 같은 초기 상태·같은 파라미터·같은 서브스텝 수 → 위치·속도·스핀 비트 단위 동일. 난수 사용 없음 (오차는 008이 입력 단계에서 넣는다).
- 할당: 서브스텝·예측 경로에서 힙 할당 0 (예측 결과 버퍼는 호출자가 재사용).
- 세이브 호환: 공 상태는 직렬화 가능한 값으로만 구성.

## 수용 기준
- AC-01 [로직]: 구름 모델(드래그 포함)에서 초속 3.2 / 5 / 8 / 10 / 12 / 15 / 20 m/s의 정지거리가 리서치 01 A-6 표(7.2 / 13.2 / 22.6 / 28.5 / 34.5 / 44.4 / 60.3 m)와 각각 ±3% 이내, 정지시간(5.2~11.0 s)이 ±5% 이내다.
- AC-02 [로직]: 초속 3.2 m/s 구름 거리가 UEFA/FIFA 기준 범위(5~10.6 m) 안이다 (A-6).
- AC-03 [로직]: 스핀 0 비행: 18 m/s·15° → 사거리 14.8 m·체공 0.92 s, 25 m/s·30° → 39.8 m·2.32 s, 30 m/s·30° → 51.6 m·2.70 s (A-7)와 사거리 ±3%, 체공 ±3% 이내.
- AC-04 [로직]: Cd를 0으로 두면 진공 사거리(16.5 / 55.2 / 79.5 m)와 ±1% 이내 (적분기 검증).
- AC-05 [로직]: 감아차기 18.5 m/s·64 rad/s(Sp ≈ 0.38) 횡방향 킥이 20 m 비행 동안 휘는 방향이 스핀 축과 오른손 법칙으로 일치하고, 횡이동이 0보다 크다. 36 m/s·63 rad/s·약 27 m 비행은 횡이동이 2~6 m 범위다. (2026-11-02 수정: A-3 공식으로는 약 5.3 m. 베컴 사례 3 m는 참고값이며, 휘는 정도는 017에서 튜닝)
- AC-06 [로직]: 속도 8 m/s 미만 공은 마그누스 가속이 0이다.
- AC-07 [로직]: 2 m 높이 낙하 공의 첫 반발 높이가 건조 표면 e 0.62 기준 √ 관계(≈0.77 m ± 5%)를 따르고, 젖은 표면이 건조보다 높게 튄다.
- AC-08 [로직]: 바운스를 반복하는 공은 유한 횟수(≤ 20회) 안에 Rolling으로 전이하고, 이후 Rest로 끝난다. 상태 전이 순서가 아키텍처 5의 그래프 밖으로 나가지 않는다 (허용되지 않은 전이 0건).
- AC-09 [로직]: 궤적 예측기가 예측한 위치와 실제 적분 결과가 10 s 동안 모든 샘플에서 완전히 같다 (오차 0).
- AC-10 [로직]: 땅볼 역산으로 구한 초속으로 실제 굴렸을 때 목표 거리 5~45 m 전 범위에서 정지 지점 오차 ≤ 0.2 m. 도달 불가 거리는 "도달 불가"를 반환한다.
- AC-11 [로직]: 크로스바 하단을 맞고 아래로 튄 공이 골라인 위/안쪽에 떨어지는 경우 경계 통과 신호가 "공 전체가 넘은 순간"에만 나온다 (선에 걸친 상태에서는 신호 없음).
- AC-12 [로직]: 경계 · 예외 상황 목록의 입력(속도 0, 극단 속도, 지면 아래 위치, 포스트+크로스바 동시 접촉, 잘못된 표면 파라미터) 각각에서 NaN 0건, 예외 0건, 규칙대로 처리된다.
- AC-13 [결정론]: 무작위로 만든(고정 시드) 초기 조건 10,000개를 2회 시뮬레이션해 최종 상태 해시가 전부 같다.
- AC-14 [성능]: 성능 예산 표의 항목이 기준 프로필에서 예산 안이고, 할당 0 B다.
