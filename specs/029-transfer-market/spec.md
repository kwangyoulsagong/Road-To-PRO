## 배경
이적시장은 커리어의 갈림길이다. 내 선수의 시장가치는 능력·나이·계약·출전·폼에 따라 매주 움직이고, AI 클럽들은 필요도와 예산으로 입찰한다. 빅클럽 벤치냐 중소클럽 에이스냐, 임대로 출전을 쌓을지 — 플레이어는 이 선택으로 커리어를 만든다. 월드의 모든 AI 클럽도 같은 시장에서 거래하므로, 시장이 무너지면(한 클럽이 다 사감, 아무도 안 팔림, 가치 폭등) 월드 전체가 이상해진다. 대량 시뮬로 시장 건강성을 검증한다.

## 범위
- 포함:
  - 선수 시장가치 계산 (로그-선형 공식, 포지션별 나이 곡선, 계약 승수, 노이즈)
  - 가치의 신뢰도·갱신 주기, 가치 변화 기록
  - AI 클럽 이적 수요: 필요도(Depth Gap·Quality Gap), 효용, 입찰가
  - 클럽 간 이적료 협상: 판매 클럽 Ask, 최대 3라운드, 라운드마다 차이 30~50% 축소
  - 이적 창구(하계 약 9주·동계 약 4주)와 마감 직전 7일 Urgency
  - 임대: 순수 / 구매 옵션부 / 의무 구매 조건부, 임대료·연봉 분담, 최소 출전 조항, 원소속팀 상대 출전 금지, 1월 리콜
  - 바이아웃 발동 (자동 이적 성사)
  - 자유계약(FA) 영입 (이적료 0, 연대기여금·훈련보상금만)
  - 내 선수 관련 오퍼 흐름: 관심 소식 → 오퍼 도착 → (원소속 클럽 수락 시) 개인 조건 협상(028) → 이적 확정
  - 이적 요청, 이적 요청 거절
  - 에이전트 Network에 따른 비공개 관심 구단 발견
  - 이적 화면: 관심 클럽 목록, 오퍼 카드, 복수 오퍼 비교로 연결 (028)
- 제외:
  - 개인 계약 조건 협상 (028)
  - 이벤트 문구 (031), 미디어 반응 (034)
  - 월드 클럽 재정·명성 생성 (020)
  - 국가대표 여부 판정 (035 — 가치 공식은 값을 읽음)

## 사용자 시나리오
1. 홈 화면 "내 시장가치 4.2M (+0.3M)" 카드. 누르면 지난 시즌 가치 곡선과 변화 이유(평점 상승, 계약 잔여 감소)를 본다.
2. 여름 창구 열림. "빅클럽 2곳이 관심을 보이고 있어요" — 에이전트 Network가 높아서 비공개 관심 1곳이 더 보인다.
3. 오퍼 도착: 이적료 12M, 원소속 클럽이 역제안 15M, 라운드 2에서 13.5M 합의. 개인 조건 협상(028)으로 넘어간다.
4. 출전이 적어서 임대를 요청했다. 구매 옵션부 임대 제안 2개를 비교한다.
5. 마감 D-7, 오퍼가 몰려온다. 마감일이 지나면 창구 닫힘 배지.
6. 라리가형 리그의 내 계약에 바이아웃 30M. 한 클럽이 바이아웃을 발동해 자동으로 협상 단계로 넘어간다.

## 요구사항

### 시장가치
- FR-01: 가치 공식 (리서치 05 § 1.2):
  `ln(V) = β0 + β1·Ability + β2·Ability² + f_age(age, pos) + β3·ln(1 + contractMonthsLeft) + β4·LeagueStrength + β5·ClubFinance + β6·MinutesShare(최근 2시즌) + β7·Intl + β8·FormZ + ε`, ε ~ N(0, 0.15)
  `f_age = −k_pos·(age − peak_pos)²` (age > peak_pos 이면 계수 1.5배)
  β 계수 [미정 — 원문 비공개, 대량 시뮬 캘리브레이션].
- FR-02: 포지션별 정점·곡률 [U]: GK 28 / 0.010, CB 27 / 0.014, FB·CM 26 / 0.018, W·ST 25.5 / 0.020.
- FR-03: 계약 승수 C(m) [U]: m ≥ 36개월 1.0, 24 → 0.9, 12 → 0.65, ≤ 6 → 0.35, 0 → 0 (자유계약). 사이 구간 [제안: 선형 보간]. C(m)은 이적료 협상(Ask·Bid)에 곱하고, 화면의 "시장가치"는 C 적용 전 V로 보여준다 [제안 — 질문 참고].
- FR-04: 노이즈 ε은 선수·시즌 단위로 고정한다 [제안: 주마다 새로 뽑으면 가치가 요동침]. 매주 바뀌는 항은 FormZ·contractMonthsLeft·Ability.
- FR-05: 가치 갱신: 주 마감(024)마다 재계산. 변화 이유는 항별 기여 변화 상위 2개로 기록.
- FR-06: 평판(034)이 가치에 주는 영향: 입력은 034 FR-01의 명성·팬 평판·언론 평판. 반영 방식 [미정: 별도 항 β9·Reputation_norm으로 넣을지 — 기획서 § 4.5 "인터뷰 답변이 이적시장 가치에 영향"]. 이 스펙이 반영 여부를 결정하는 소유자다.
- FR-07: 임대 성공 시 가치 상승 (리서치 05 § 5.2) — 성공 판정은 024, 상승 크기 [미정: MinutesShare·FormZ 경로로 자연 반영할지, 별도 보너스일지].

### AI 클럽 수요와 입찰
- FR-10: 필요도: `DepthGap = 목표 인원 − 해당 능력치 이상 보유 인원`, `QualityGap = 후보 능력 − 해당 포지션 주전 능력` (리서치 05 § 1.3).
- FR-11: 효용: `U = w1·QualityGap + w2·DepthGap + w3·AgeFit(클럽 철학) + w4·ResaleValue − w5·(Fee + 계약기간 총연봉)/Budget` [미정: w1~w5].
- FR-12: 입찰가: `Bid = V × U(0.75, 1.0) × (1 + 0.15·Urgency) × BuyerWealthFactor` (U(a,b) = 균등 분포 샘플).
- FR-13: 판매 클럽 응답: `Ask = V × (1 + 0.1·KeyPlayer + 0.2·ContractYears/5)`.
- FR-14: 협상: 최대 3라운드, 라운드마다 Bid–Ask 차이를 30~50% 좁힘. 3라운드 안에 Bid ≥ Ask 이면 합의, 아니면 결렬.
- FR-15: 클럽은 예산(이적 예산 = 020 FR-27 + 연봉 예산 028) 안에서만 입찰한다. 한 창구에서 한 클럽의 동시 진행 협상 수 상한 [제안: 3].
- FR-16: 판매 결정: 판매 클럽은 합의 이적료와 대체 선수 가능성으로 판매 여부를 정한다 [미정]. 내 선수의 경우 "이적 요청" 상태면 판매 의향 상승.
- FR-17: 이적 확정 = 이적료 합의 + 개인 계약 서명(028) 둘 다 성사. 개인 계약 결렬이면 이적 무산.

### 이적 창구
- FR-20: 창구는 캘린더(021)의 하계(약 9주)·동계(약 4주) 날짜 [U]. 창구 밖에서는 이적 확정 불가 (FA 영입은 [미정: 창구 밖 허용 여부]).
- FR-21: 마감 직전 7일 Urgency 급상승 (리서치 05 § 1.3) [미정: 곡선 — 제안 0 → 1 선형]. 마감일 당일 합의는 그날 끝(024 경계: 경기 처리 후, 마감 처리 전)까지 확정 가능하고, 마감 처리 시점에 진행 중인 협상은 모두 종료.
- FR-22: 창구 상태 변화는 024가 알리고, 이 스펙은 협상 진행·종료만 처리한다.

### 임대
- FR-30: 임대 유형: 순수(임대료 V의 0~10%, 연봉 분담 0~100%) / 구매 옵션부 / 의무 구매 조건부 (리서치 05 § 1.4).
- FR-31: 임대 조항: 최소 출전 조항(미달 시 벌금 또는 리콜), 원소속팀 상대 출전 금지(025 출전 불가 사유), 1월 리콜 조항.
- FR-32: 임대 종료: 시즌 말 복귀 (024 시즌 경계). 구매 옵션 행사 판단(임대 클럽), 의무 구매 조건 충족 판정 [미정: 조건 형식].
- FR-33: 임대 기간 중 원소속 개인 계약은 유지, 연봉 분담 비율대로 양쪽이 지급 (028 지급과 연결).

### 바이아웃 · FA
- FR-40: 바이아웃 금액 이상 제시 시 판매 클럽 협상 없이 이적료 합의 상태 → 개인 계약 협상(028)으로 바로 간다 (리서치 05 § 1.4). 국내/해외 구분 바이아웃은 구매 클럽 국가로 판정.
- FR-41: FA 선수는 이적료 0, 연대기여금·훈련보상금만 [미정: 계산 — 원문은 항목만 언급].

### 내 선수 흐름
- FR-50: 관심 소식: AI 클럽 효용이 임계값 이상이면 "관심" 상태. 공개 관심은 항상 보이고, 비공개 관심은 에이전트 Network 확률로 발견 (리서치 05 § 2.3).
- FR-51: 오퍼 도착 시 024 자동 진행 중단 조건 발생, 이벤트 계기(030).
- FR-52: 이적 요청: 내 선수가 요청하면 판매 의향 상승, 025 선발 Penalty 0.1, 원소속 감독 신뢰 하락 [미정: 크기]. 클럽이 요청을 거절할 수 있다 (거절 확률 [미정]).
- FR-53: 복수 오퍼(이적·임대 섞여도) 비교 화면으로 연결 (028 FR-62).
- FR-54: 이적 결정 화면에 033 FR-31 가족 의견(찬성/반대·이유 한 줄)을 표시한다. 해외 이적 오퍼가 도착하면 033에 의견 계산을 요청한다.
- FR-55: 은퇴 확정(036) 시 그 선수의 관심·오퍼·진행 중 협상은 모두 취소되고 기록에 "은퇴로 취소"가 남는다.

### 화면
- FR-60: 가치 카드: 현재 V 큰 숫자, 주간 변화, 탭하면 시즌 가치 그래프 + 변화 이유.
- FR-61: 이적 화면: 창구 상태·남은 일수, 관심 클럽 목록(공개/비공개 표시), 진행 중 오퍼와 라운드 상태.
- FR-62: 임대 제안 카드: 유형, 임대료, 연봉 분담, 출전 조항, 리콜 조항, 구매 옵션 금액.
- FR-63: 금액 표시는 032 FR-14 통화 규칙·037 숫자 포맷.

## 경계 · 예외 상황
- contractMonthsLeft = 0 → C = 0, ln(1+0) = 0 (로그 정의역 안전). 음수 잔여(만료 처리 지연) 금지.
- Ability², 나이 차 제곱이 큰 극단(16세 GK, 40세 W)에서 ln(V) 범위 — V 하한·상한 클램프 [제안: 하한 1천, 상한 [미정]].
- V 계산의 exp 오버플로 방지 (ln(V) 상한).
- Budget = 0 클럽, 음수 효용, DepthGap 음수(과잉 보유).
- Bid = Ask 정확히 같은 경계, 3라운드 마지막에 Bid가 Ask를 넘는 경우.
- 한 선수에게 같은 날 오퍼 여러 개 → 처리 순서 고정 (클럽 id 순).
- 마감일 당일 합의 → 확정 시각이 마감 처리 전인지 후인지 고정 (024 FR 경계와 맞춤).
- 임대 중인 선수를 원소속팀이 다른 클럽에 판매 → [제안: 1월 리콜 조항이 있을 때만 가능].
- 이적 직후 같은 창구 재이적 [제안: 같은 창구 재이적 금지].
- 월드에서 한 클럽이 너무 많이 사거나(독점) 아무도 거래하지 않음 → AC-10으로 감시.
- 내 선수 국적 = 구매 클럽 국가 → 국내 바이아웃 적용.

## 비기능 요구사항
- 결정론: 같은 입력·시드 → 가치·입찰·협상·확정 결과 동일. 클럽 처리 순서 고정. 창구 하루 단위 처리 순서 고정.
- 세이브 호환: 가치 기록(시즌 곡선), 진행 중 협상, 관심 상태, 임대 조건 저장.

## 수용 기준
- AC-01 [결정론]: 같은 월드·시드로 하계 창구 시뮬 2회 → 모든 이적(선수·클럽·이적료·날짜) 해시 동일.
- AC-02 [로직]: 가치 공식이 FR-01~FR-03과 같다 (고정 β 픽스처 표 12행, 계약 승수 보간 경계 36/24/12/6/0개월 포함).
- AC-03 [로직]: 나이 곡선: 포지션별 V 최대 나이가 peak_pos와 같고, 정점 이후 감소가 이전 증가보다 가파르다 (1.5배).
- AC-04 [로직]: 노이즈 고정: 같은 시즌 안에서 다른 입력이 같으면 주마다 V가 같다.
- AC-05 [로직]: 입찰·Ask·3라운드 협상이 FR-12~FR-14와 같다. 라운드별 차이 축소율 30~50% 범위, 3라운드 초과 협상 0.
- AC-06 [로직]: 예산을 넘는 입찰 0 (월드 3시즌 헤드리스).
- AC-07 [로직]: 창구 밖 이적 확정 0, 마감 후 진행 협상 0, 마감 D-7 구간 Urgency > 0.
- AC-08 [로직]: 바이아웃 이상 제시 → 협상 라운드 없이 개인 조건 단계로 간다. 국내/해외 구분이 구매 클럽 국가로 판정된다.
