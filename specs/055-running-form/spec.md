## 배경
043의 로코모션 클립은 수치상 발이 미끄러지지 않지만, 사람이 보면 "팔을 펴고 뛰는 타조"다. 현재 생성기(`Art/Blender/scripts/player/clips/gait.py`)를 연구 수치와 대조하면 원인이 보인다:
- **보폭이 너무 길고 걸음이 느리다**: sprint 7.6 m/s를 19프레임 주기로 → 걸음 3.2회/초·보폭 2.4 m. 실제 축구 선수 최고속 구간은 걸음 약 4회/초·보폭 약 1.9~2.1 m. 긴 보폭을 느리게 → 껑충껑충 뛰는 "타조 걸음".
- **골반 상하 진동 위상이 반대**: 골반이 접지 순간 가장 높고 공중에서 낮다. 실제(스프링-질량 모델)는 접지 중간에 가장 낮고 공중에서 가장 높다 → 머리가 이상하게 출렁인다.
- **목이 앞으로 튀어나온다**: 몸통을 앞으로 숙인 만큼(최대 17°) 머리를 0.8배 거꾸로 세워 얼굴을 수평으로 맞춘다 → 목만 앞으로 빠진 타조 자세.
- **팔**: 팔꿈치 각도가 고정이고(걷기 15°, 뛰기 70~90°) 어깨 스윙만 있어 팔이 막대처럼 흔들린다. 실제는 팔꿈치가 앞에서 더 굽고 뒤에서 더 펴지며, 어깨 스윙 범위가 속도에 따라 크게 늘어난다.
- **몸통 기울기가 속도 하나에 고정**: 최고속도에서 17°는 과하고, 출발 첫 걸음의 큰 숙임은 없다.
이 스펙은 **달리기·킥 폼의 형태 기준을 공개 생체역학 연구 수치로 정하고**, 선수 개성(역할·성향·버릇)이 달리기·킥 스타일 차이로 보이게 한다. 054(궤적·접촉 동기화)는 "언제·어디"를, 055는 "어떤 모양으로"를 맡는다.

## 범위
- 포함:
  - 전진 보법 4종(walk·jog·run·sprint)과 8방향 변형의 형태 기준: 걸음 빈도·보폭·접지 비율·상하 진동·몸통·머리·팔·골반·다리 관절 각도·위상
  - 축구 특화 보법: 출발 가속(첫 3~4걸음), 감속·정지, 공 몰고 달리기(드리블 런). 054 FR-20·21·37이 요구하는 동작의 형태를 여기서 정한다
  - 달리기 스타일 원형(가상 원형, 실명 없음)과 선수 개성(역할·성향·버릇·체형) → 원형 매핑
  - 킥·패스 스타일 원형: 도움닫기·디딤발·백스윙·접촉 부위·팔로스루의 형태 기준
  - 생성 클립의 형태를 재는 측정 도구(관절 각도·위상·진동 추출)와 측면·정면 필름스트립 증거
- 제외:
  - 루트 궤적·접촉 시각·발 미끄러짐·관통 (054)
  - 모델 메시·얼굴 (056), 골키퍼 전용 동작 (011)
  - 실존 선수 개인의 스타일 재현, 실명 스타일 이름 (01-legal) — 리서치에서 실존 선수를 참고해도 결과물은 이름 없는 원형만
  - 모션 캡처 데이터 사용 (사용자 결정: 절차 생성)

## 사용자 시나리오
1. 윙어가 측면을 전력질주한다. 팔꿈치를 90° 안팎으로 굽힌 팔이 앞뒤로 크게 흔들리고, 몸통은 거의 서 있고, 머리는 몸통과 한 줄이다. 걸음이 빠르고 짧아 "껑충"이 아니라 "타다닥" 달린다.
2. 수비수가 정지 상태에서 출발한다. 첫 걸음은 몸을 크게 숙이고 짧게 밀어내다가, 대여섯 걸음 만에 몸이 선다.
3. 드리블하는 선수는 공 없을 때보다 보폭이 짧고 무게중심이 낮다.
4. 키 작고 민첩한 드리블러와 키 크고 힘 있는 스트라이커의 달리는 모양이 다르다. 같은 팀 미드필더 두 명의 킥 모양도 다르다.

## 요구사항

### 보법 시간 구조 (속도별)
- FR-01: 각 보법 클립은 아래 범위를 지킨다. 값은 정면(dir 0) 기준이며, 걸음 빈도 = 2 / 주기(초), 보폭 = 속도 / 걸음 빈도, 접지 비율 = 한 발 접지 시간 / 주기.

  | 보법 | 속도 (m/s) | 걸음 빈도 (회/초) | 보폭 (m) | 한 발 접지 시간 | 접지 비율 | 골반 상하 진동 (피크-피크) |
  |---|---|---|---|---|---|---|
  | walk | 1.4 | [제안] 1.8~2.0 | 0.70~0.78 | — | [제안] 0.58~0.62 | [제안] 3~5 cm |
  | jog | 3.4 | [제안] 2.6~2.9 | 1.17~1.31 | [제안] 0.22~0.27 s | [제안] 0.30~0.38 | 6~8 cm (Konstanz·Humboldt) |
  | run | 5.4 | 3.0~3.3 (JSSM 표4: 3.26) | 1.64~1.80 | 0.17~0.18 s (JSSM 표4) | [제안] 0.26~0.30 | 6~8 cm |
  | sprint | 7.6 | [제안] 3.8~4.3 | 1.77~2.00 | [제안] 0.11~0.13 s | [제안] 0.22~0.26 | [제안] 5~7 cm |

  현재 값(sprint 3.2회/초·보폭 2.4 m·접지 비율 0.16, run 2.9회/초)은 이 표를 벗어난다.
- FR-02: 공중 구간(두 발 모두 떠 있음)은 jog 이상에서만 있고, sprint의 공중 시간은 걸음당 [제안] 0.10~0.14 s (Weyand 약 0.12 s).
- FR-03: 골반 높이는 접지 중간(접지 구간의 40~60% 지점)에서 가장 낮고, 공중 구간 중간에서 가장 높다(스프링-질량). 현재처럼 접지 순간 최고점인 위상은 금지.

### 다리
- FR-10: 착지: 발은 무게중심 앞 [제안] jog ≤ 0.30 m, run ≤ 0.30 m, sprint ≤ 0.35 m에 딛는다. 착지 순간 무릎 굴곡 [제안] 10~25°(무릎을 편 채 착지 금지). 접지 패턴: walk 뒤꿈치, jog 뒤꿈치~중족부, run·sprint 중족부~앞꿈치.
- FR-11: 접지 중 무릎 최대 굴곡 [제안] jog 35~45°, run 35~45°, sprint 30~40°. 이지 직전 엉덩이·무릎이 다 펴지지 않는다(이지 무릎 굴곡 ≥ [제안] 10°, Salford).
- FR-12: 스윙 중 무릎 최대 굴곡(뒤꿈치 회수) [제안] jog 80~100°, run 95~115°, sprint 110~130° (Novacheck 리뷰 범위). 스윙 엉덩이 최대 굴곡(무릎 들기) [제안] jog 35~50°, run 45~60°, sprint 55~70°. 축구 선수는 스프린터보다 무릎 들기를 [제안] 5~10° 낮게 둔다(Garden 2022, 공·상대 대응 자세).
- FR-13: 스윙 발 궤적은 "뒤꿈치가 엉덩이 쪽으로 접혀 올라간 뒤 무릎이 앞으로 나가며 정강이가 펴지는" 순서다. 발이 몸 아래를 지날 때 발 높이(지면에서 발목까지) ≥ [제안] jog 0.15 m, sprint 0.30 m이고, 무릎이 발보다 먼저 앞으로 나간다(무릎 앞 이동 피크가 발 앞 이동 피크보다 이르다). 발을 직선으로 높이 들어 앞으로 내미는 "행진·타조" 궤적 금지.

### 몸통 · 머리 · 골반
- FR-20: 몸통 전방 경사(골반-목 선 기준): walk [제안] 0~4°, jog 3~8°, run 4~10°, sprint(최고속도) 5~12°. 속도 하나에 경사 하나를 고정하지 않고 가속도로 바꾼다(FR-40).
- FR-21: 머리·목: 머리는 몸통과 거의 한 줄이다. 목의 몸통 대비 신전(얼굴 들기) ≤ [제안] 10°, 머리 중심이 어깨선보다 앞으로 나간 거리 ≤ [제안] 6 cm(정적 서기 자세 대비 증가량). "목만 앞으로 빠진" 자세 금지. 시선은 앞 [제안] 10~20 m 지면.
- FR-22: 골반 수평 회전(요): 다리를 따라 ±[제안] walk 4~6°, jog 6~10°, sprint 8~12°. 흉곽(상체)은 골반과 반대 방향으로 비틀어 팔 스윙과 함께 각운동량을 상쇄한다(Hinrichs). 흉곽-골반 상대 회전 피크 ±[제안] 8~15°.
- FR-23: 골반 기울기(옆, 지지 쪽 반대 골반 내려감) ±[제안] 3~6°. 상체 좌우 흔들림(롤) ±[제안] 3° 이내.

### 팔
- FR-30: 팔은 다리와 반대 위상이다: 오른 다리 엉덩이 굴곡 피크와 왼팔 어깨 굴곡 피크의 시각 차 ≤ 주기의 [제안] 8%.
- FR-31: 팔꿈치 굴곡: walk 평균 [제안] 10~30°(편안히 늘어뜨림), jog·run·sprint 평균 80~100°. 한 주기 안에서 팔꿈치는 변한다 — 앞으로 갈 때 더 굽고(최소 각 [제안] 60~80°) 뒤로 갈 때 더 편다(최대 [제안] 100~120°). 팔꿈치 각도 변동 폭 ≥ [제안] jog 15°, sprint 25°. 팔꿈치 각도가 주기 내내 고정인 클립 금지.
- FR-32: 어깨 앞뒤 스윙 가동 범위: walk [제안] 25~40°, jog 50~70°, run 70~90°, sprint 100~120°(JSSM 13-128: 111~118°). 앞쪽 끝에서 손은 가슴~턱 높이(sprint), 뒤쪽 끝에서 손은 엉덩이 뒤를 지난다.

- AC-03 [로직]: 착지 거리·착지 무릎 굴곡·접지 중 최대 무릎 굴곡·이지 무릎 굴곡·스윙 무릎/엉덩이 최대 굴곡이 FR-10~12 범위 안. 스윙에서 무릎 앞 이동 피크가 발 앞 이동 피크보다 이르다 (FR-13).
- AC-04 [로직]: 몸통 경사·목 신전 ≤ 10°·머리 앞 이동 ≤ 6 cm·골반/흉곽 회전과 반대 위상·골반 기울기가 FR-20~23 범위 안.

- AC-08 [로직]: 달리기 원형 간 지표 차이(걸음 빈도·몸통 경사·팔 가동 범위 등)가 원형 정의대로 측정되고, 선수 200명 샘플의 원형 분포가 매핑 규칙대로 나온다. 같은 id 재생성 시 동일 (FR-50·51).
