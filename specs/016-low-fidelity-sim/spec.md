# 016 — 비관전 경기 저정밀 시뮬

상태: 승인됨
브랜치: feat/016-low-fidelity-sim
기획 출처: docs/index.html § 기획서 5.1("다른 경기(내 선수가 뛰지 않는 경기)는 저정밀 통계 모드로 빠르게 계산"), § 5.5.1 배터리 정책("다른 경기는 저정밀 통계 모드로 계산"), § 6 기술 스택(성능: 비관전 경기 대량 시뮬), research[5] § 6.1(국가·리그 피라미드 규모), § 6.4(시즌 캘린더)

## 배경
내 선수가 뛰는 경기는 22명 전원을 10Hz 결정·100Hz 물리로 풀 시뮬한다. 하지만 같은 주에 월드 전체에서 수십~수백 경기가 열린다. 이걸 전부 풀 시뮬하면 한 주를 넘기는 데 너무 오래 걸리고 배터리도 쓴다. 그래서 내 선수가 없는 경기는 통계 모델로 빠르게 결과를 만든다. 단, 결과 분포(득점, 스코어 분포, 이변 확률, 카드, 부상, 선수 스탯·평점)가 풀 시뮬과 **통계적으로 구분되지 않아야** 한다. 그렇지 않으면 리그 순위·득점왕·이적 가치·부상이 풀 시뮬 경기와 다른 세계처럼 움직인다.

## 범위
- 포함:
  - 경기 입력(두 팀 라인업·능력치·전술 성향·컨디션·홈/원정·대회 종류·시드)에서 결과 생성
  - 결과: 최종 스코어, 득점 시각·득점자·어시스트, 경고·퇴장, 부상 발생(027로 넘김), 교체·출전 시간, 선수별 015 형식 스탯 요약과 평점, 팀 스탯 요약(점유율·슈팅·xG·코너)
  - 연장·승부차기(컵 대회)
  - 풀 시뮬과의 분포 일치 보정 절차와 검증
  - 월드 한 라운드(전 리그 동시 경기) 일괄 처리
- 제외:
  - 풀 시뮬 (006~013)
  - 부상 종류·기간 결정 (027 — 여기서는 "발생 + 상황 정보"만 넘김)
  - 일정 생성 (021), 순위표·승강 (024)
  - 하이라이트·키 모먼트 (저정밀 경기는 하이라이트가 없다. 결과 텍스트만)

## 사용자 시나리오
1. 내 선수 경기가 끝나고 "주 넘기기"를 누르면 리그 다른 경기 결과가 즉시(1초 안) 순위표에 반영된다.
2. 리그 득점왕 경쟁자의 골 수가 풀 시뮬 경기 기준과 비슷한 속도로 오른다. 시즌 끝 득점왕 골 수가 현실적인 범위다.
3. 다른 팀 주전이 다른 경기에서 다쳐 다음 주 라인업에서 빠지고, 그 덕에 내 팀이 이길 확률이 바뀐다.
4. 내 선수가 다른 클럽으로 이적하면, 예전 팀 경기는 저정밀로, 새 팀 경기는 풀 시뮬로 바뀐다. 리그 전체 분위기는 끊김 없이 이어진다.

## 요구사항

### 모드 결정
- FR-01: 경기마다 시뮬 모드를 정한다: 내 선수가 출전 명단(선발 + 벤치)에 있는 경기 → 풀 시뮬, 그 외 → 저정밀. 내 선수가 벤치에서 끝내 못 나와도 풀 시뮬 [제안] (교체 투입 가능성 때문).
- FR-02: 사용자가 옵션으로 "관심 경기"(라이벌, 이적 협상 중인 클럽 등)를 풀 시뮬로 바꿀 수 있다 [제안].
- FR-03: 모드는 결과의 의미를 바꾸지 않는다. 저정밀 결과도 같은 이벤트 스키마(골·카드·부상·교체)와 같은 015 스탯 형식으로 저장한다.

### 결과 생성
- FR-10: 입력: 양 팀 출전 선수와 능력치(002), 역할·성향(003), 팀 전술 성향(009가 정의한 전술 파라미터 요약), 컨디션·피로(027), 홈/원정, 대회·단계, 날씨 상태·피치 상태(064 FR-42, 풀 시뮬 006 FR-10과 같은 칸), 시드. 출력은 FR-11~14·17. 날씨는 득점 기대치에 직접 더하는 보너스가 아니라 풀 시뮬 보정(FR-20)이 날씨 종류별로 맞춘 계수로만 들어간다(064 FR-41). 날씨 입력이 없으면 064 대체 값(기준 날씨·건조).
- FR-11: 팀 득점 기대치(λ)를 두 팀 전력 차·홈 이점·전술 성향으로 계산하고 (같은 λ를 015 FR-40 승률 추정의 경기 전 값으로 쓴다), 득점 수를 확률 분포에서 뽑는다. 분포 형태(독립 포아송, 이변량 포아송, 저득점 보정 등)는 플랜에서 정하되, 아래 FR-30 일치 기준을 만족해야 한다.
- FR-12: 득점 시각 분포는 풀 시뮬의 시간대별 득점 분포를 따른다 (전반·후반, 후반 막판 증가, 추가시간 골 비율 8.4~13.5% [V], research[2] § 6).
- FR-13: 득점자·어시스트는 출전 선수의 포지션·역할·능력치·출전 시간 가중으로 뽑는다. 득점 원천(오픈플레이 0.60 / 세트피스 0.25 / 페널티 0.08 / 역습 0.07)도 함께 뽑아 득점자 가중을 바꾼다 (세트피스 → 공중볼 강한 선수, 페널티 → 지정 키커).
- FR-14: 경고·퇴장, 부상 발생(027로 넘김), 교체(전술 성향·피로·부상, 한도는 006 FR-12), 출전 시간, 선수 평점(015 분포와 일치), 팀 스탯 요약을 생성한다. 빈도 목표는 별도 수치를 두지 않고 풀 시뮬 보정(FR-20)과 017 FR-20 목표를 따른다.
- FR-15: 퇴장·부상이 생기면 그 시각 이후 해당 팀 득점 기대치를 조정한다 (10명이면 λ 감소 [제안]).
- FR-16: 컵 대회 동점 → 연장(30분, 득점 기대치 시간 비례) → 승부차기(키커별 성공률은 017 FR-20 PK 성공률 목표 기반, 능력치 보정).
- FR-17: **골 속성 생성** (063 FR-51, 063 Q2-B): 저정밀 경기의 골마다 거리·슈팅 종류(발리·로빙·프리킥·장거리 등 015 분류)·xG·득점 원천(FR-13)·슈팅 구역·직전 드리블로 제친 수를 함께 뽑아 결과에 저장한다. 분포는 풀 시뮬 골 속성 분포와 일치해야 한다(FR-30에 항목 추가). 063 올해의 골 후보 평가와 시나리오 라이브러리 결정론 재구성 장면(063 FR-52·53)이 이 속성을 읽는다. 같은 경기 시드면 같은 속성이다.

### 보정
- FR-20: 저정밀 모델 파라미터는 풀 시뮬 대량 결과(017)로 보정한다. 보정 데이터: 전력 차 구간별 승/무/패 비율, 팀 득점 분포, 스코어라인 빈도표, 시간대별 득점, 카드·부상·교체 빈도, 포지션별 득점·어시스트 비율, 평점 분포.
- FR-21: 풀 시뮬 엔진이 바뀌면 보정이 낡았는지 감지해 재보정을 요구한다 (017 엔진 버전 기준).
- FR-22: 보정 결과(파라미터)는 데이터 파일로 저장해 코드 수정 없이 갱신한다.

### 일치 기준
- FR-30: 같은 팀 쌍·같은 조건으로 풀 시뮬 N경기와 저정밀 N경기를 돌렸을 때 [제안: N = 2,000 경기 쌍 집합, 전력 차 구간 5개]:
  - 평균 총 득점 차 ≤ 0.1골
  - 스코어라인 분포 (0-0, 1-0, 1-1, 2-1 … 5+) 카이제곱 검정 p ≥ 0.05
  - 전력 차 구간별 홈 승·무·원정 승 비율 차 ≤ 3%p
  - 경기당 경고·퇴장·부상 평균 차 ≤ 10%
  - 포지션별 득점 비율 차 ≤ 3%p
  - 선수 평점 평균 차 ≤ 0.1, 표준편차 차 ≤ 0.1
  - 골 속성 분포(FR-17): 슈팅 종류·득점 원천·슈팅 구역 비율 차 ≤ 3%p [제안], 거리·xG 평균 차 ≤ 5% [제안]
  - 날씨 종류별(064 FR-02 7종): 위 항목을 날씨 종류마다 따로 만족한다 (064 FR-42)
- FR-31: 시즌 단위 지표도 비교한다: 리그 우승 승점, 강등권 승점, 득점왕 골 수, 팀 득점 분산. 풀 시뮬 리그 시즌과 저정밀 리그 시즌을 각각 [제안: 50시즌] 돌려 평균 차 ≤ 5% [제안].
- FR-32: 시즌 단위 결과 모드 (036 FR-52 뉴게임+ 근사 요청): 경기 하나씩이 아니라 시즌 단위로 팀 순위·득실·선수 시즌 스탯 요약을 한 번에 생성하는 모드를 둔다. 분포는 경기 단위 저정밀을 시즌으로 합친 것과 [제안: ±5%] 안에서 맞아야 한다.
- FR-33: 축소 월드 내 경기 저정밀 옵션 (024 FR-55/56 요청): 헤드리스 커리어 검증(축소 월드 픽스처)에서는 **내 선수 경기도** 저정밀로 계산할 수 있는 옵션을 둔다. 출시 게임에서는 쓰지 않는다. 이 옵션으로 만든 결과에는 "저정밀" 표시가 붙는다.

## 경계 · 예외 상황
- 선수가 11명 미만(부상·징계로 경기 전 명단 부족) → 024 규칙대로 몰수 또는 유스 선수 자동 충원 [미정]. 저정밀은 그 결정을 받아 처리한다.
- 같은 선수가 같은 날 두 경기에 배정 (데이터 오류) → 오류로 막는다.
- 득점 0인 경기에 어시스트·득점 시각 생성 금지.
- 득점 수 상한: 한 팀 득점 상한 없음이지만 분포 꼬리 확인 (10골 이상은 풀 시뮬 빈도와 비교).
- 퇴장 2명 이상 → 득점 기대치 조정이 누적되고 음수가 되지 않는다.
- 교체 수 규칙(교체 인원·횟수 상한)은 006 FR-12 값을 그대로 지킨다.
- 시즌 마지막 라운드 동시 경기 → 처리 순서와 무관하게 같은 결과 (경기 단위 독립 시드).
- 내 선수 이적이 라운드 중간에 확정 → 이미 처리된 경기 결과는 바뀌지 않는다.
- 선수 평점 생성 시 출전 10분 미만 → 015 규칙대로 "—".

## 비기능 요구사항
- 결정론: 경기 결과는 `(월드 시드, 경기 id)`에서 유도한 시드로만 정해진다. 같은 라운드 다른 경기를 어떤 순서·병렬도로 처리해도 각 경기 결과가 같다.
- 병렬: 라운드 안 경기들은 서로 독립이라 병렬 처리 가능 (경기 하나는 단일 스레드).
- 세이브 호환: 결과 형식은 풀 시뮬과 같아 022 세이브에 그대로 저장.

## 수용 기준
- AC-01 [로직]: 내 선수가 명단에 있는 경기는 풀 시뮬, 없는 경기는 저정밀로 배정된다. 관심 경기 옵션이 켜진 경기는 풀 시뮬이다.
- AC-02 [로직]: 저정밀 결과가 풀 시뮬과 같은 스키마로 저장·로드되고, 015 스탯 필드가 모두 채워지거나 명시적 "없음"이다.
- AC-03 [로직]: 득점 0 경기에 득점자·어시스트·득점 시각이 없다. 득점 n개면 득점 이벤트가 정확히 n개다. 득점자는 모두 그 시각에 출전 중인 선수다 (교체 아웃 후 득점 0건).
- AC-04 [로직]: 퇴장·부상 발생 시각 이후 해당 팀 득점 기대치가 줄고, 음수가 되는 경우가 없다 (퇴장 3명 인공 케이스 포함).
- AC-05 [로직]: 컵 동점 경기가 연장 → 승부차기로 끝나 승자가 반드시 1팀이다. 리그 경기는 연장이 없다.
- AC-06 [로직]: 교체 수가 006 FR-12 상한을 넘는 경기가 10만 경기 중 0건이다.
- AC-07 [로직]: 일치 기준(FR-30) 전 항목이 2,000 경기 쌍 비교에서 통과한다: 총 득점 평균 차 ≤ 0.1, 스코어라인 카이제곱 p ≥ 0.05, 승무패 비율 차 ≤ 3%p, 카드·부상 차 ≤ 10%, 포지션별 득점 비율 차 ≤ 3%p, 평점 평균·표준편차 차 ≤ 0.1.
- AC-08 [로직]: 시즌 지표(FR-31) 평균 차가 5% 이내다.
- AC-09 [로직]: 추가시간 골 비율이 8.4~13.5% 범위다 (10만 경기).
- AC-10 [로직]: 엔진 버전이 바뀐 상태에서 낡은 보정 파일을 쓰면 "재보정 필요"가 보고된다.
- AC-11 [결정론]: 같은 월드 시드로 한 라운드를 처리 순서 정방향·역방향·무작위, 병렬도 1·8로 돌려도 모든 경기 결과 해시가 같다.
- AC-12 [결정론]: 같은 경기를 2회 생성하면 결과(스코어·이벤트·스탯) 해시가 같다.
- AC-13 [성능]: 성능 예산 표 항목이 기준 프로필에서 예산 안이다.
- AC-14 [로직]: FR-32: 같은 시드로 시즌 단위 모드와 경기 단위 저정밀 모드를 각각 100시즌 돌리면 팀 승점·득점 분포 평균 차이가 ±5% 이내다.
- AC-15 [로직]: FR-33: 축소 월드 옵션을 켜면 내 선수 경기 결과에 "저정밀" 표시가 붙고, 출시 설정에서는 옵션을 켤 수 없다.
