## 배경
플레이 시간 대부분은 경기 밖, 매니지먼트 화면에서 보낸다. 주간 루프(훈련 선택 → 출전 여부 → 평점 → 라이프 → 이벤트 → 다음 주)를 끊김 없이 돌 수 있어야 하고, 각 화면은 **한 가지 목적**을 가지고 결정은 한 번에 하나만 묻는다 (기획서 4.9, 037 FR-08로 완화). 이 스펙은 화면 목록, 각 화면이 보여주는 정보와 할 수 있는 동작, 화면 사이 흐름을 정한다. 모양과 컴포넌트는 037이 제공하고, 데이터와 규칙은 각 도메인 스펙이 제공한다. 화면은 도메인 상태를 읽고 명령만 보낸다 (`.claude/rules/30-presentation-ui.md`).

## 범위
- 포함 (화면):
  1. 홈: 이번 주 요약 (다음 경기, 해야 할 선택, 핵심 수치 4개: 평점 폼·감독 신뢰·시장가치·사기), "다음 주로" 진행 버튼
  2. 일정: 캘린더(월/주), 경기·훈련·이적시장 기간·대표팀 기간 표시, 경기 결과
  3. 훈련: 주간 훈련 포커스 선택 (기술 / 체력 / 전술 / 휴식 / 개인 특훈, 기획서 4.3), 예상 효과·피로 표시
  4. 받은편지함: 이벤트·메시지 목록, 읽음/안 읽음, 선택이 필요한 항목 우선, 항목을 열면 스토리렛 선택 패널(037 FR-23)
  5. 계약: 현재 계약 보기, 제안 비교, 협상(조건 선택 패널), 서명 확인
  6. 내 선수 프로필: 능력치(분류별), 역할 적합도 ★1~5, 역할↔성향 궁합, 버릇, 성향(드러난 것만), 부상·질병 상태, 시즌 기록, 레이더 차트
  7. 라이프 탭: 쇼핑(상품 카드 + 큰 가격), 보유 자산, 주간 시간 예산 슬롯 배정, 자기관리
  8. 관계: 메신저형 대화 목록과 대화 화면 (에이전트, 감독, 동료, 연인·가족)
  9. 경기 전·후: 경기 전 출전 여부 안내 → 경기(039) → 경기 후 결과 요약(평점, 스탯, 신뢰·가치·명성 변화)
  10. 설정: 각 항목의 동작은 원본 스펙이 정하고 이 화면은 배치만 한다 (FR-100 표)
  11. 세이브 슬롯: 새 커리어, 불러오기, 저장, 삭제 확인
  12. 선수 생성: 023이 정한 단계(국적·체형·포지션·아키타입·성격·잠재력 힌트 등)를 한 단계 = 한 화면으로 배치
  13. 은퇴 · 레거시: 은퇴 결정 확인, 커리어 요약(레거시 점수·트로피·기록), 명예의 전당, 뉴게임+(자녀 2세대) 진입 — 데이터와 규칙은 036
- 제외:
  - 선수 생성 단계·선택지·검증 규칙(023이 제공). 이 스펙은 화면 배치·이동·입력 UI를 맡는다
  - 은퇴 판정·레거시 점수 계산·뉴게임+ 승계 규칙(036이 제공)
  - 경기 HUD·하이라이트 재생(039, 041)
  - 에디터·모드 가져오기(049)
  - 컷신·대화 연출(047). 받은편지함·관계 화면은 텍스트·선택지까지만
  - 수치 계산(성장량·신뢰도·가치 등)은 각 도메인 스펙이 제공

## 사용자 시나리오
1. 홈에서 "이번 주 훈련을 골라주세요" 카드를 누르면 훈련 화면으로 가고, 포커스를 고르면 홈 카드가 완료 표시로 바뀐다.
2. 받은편지함에 "에이전트가 새 제안을 가져왔어요"가 맨 위에 있다. 열면 제안 요약과 함께 선택 패널로 "수락 / 역제안 / 거절"을 고른다.
3. 계약 화면에서 두 제안(연봉, 기간, 출전 보장, 바이아웃)을 나란히 보고, 큰 숫자로 연봉 차이를 바로 안다.
4. 내 선수 프로필에서 현재 역할이 ★2라 낮고, "드리블 중독 + 앵커: 궁합 나쁨" 표시를 본다.
5. 라이프 탭에서 차를 사면 잔고가 카운트업으로 줄고, 남은 주간 시간 슬롯이 보인다.
6. 할 일을 다 하고 "다음 주로"를 누르면 경기가 있으면 경기 전 화면, 없으면 다음 주 홈으로 간다.

## 요구사항

### 공통
- FR-01: 화면은 한 가지 **목적**을 가진다 (기획서 4.9, 037 FR-08 정보 밀도 원칙에 맞춰 완화 (2026-11-11 사용자 결정 '베스트 케이스')). 그 목적에 필요한 정보(표·목록·능력치 그리드·비교·보조 패널·탭)는 한 화면에 함께 놓을 수 있다. 다만 서로 다른 두 종류의 **결정**(선택 패널로 묻는 것)을 동시에 요구하지 않고, 다른 목적의 일을 하려면 다른 화면으로 이동한다.
- FR-02: 모든 화면은 037의 토큰·컴포넌트만 쓴다. 화면 제목은 대화체 한 줄.
- FR-03: 각 화면에서 가장 중요한 수치(연봉, 시장가치, 평점, 신뢰도 등)가 가장 큰 글자로 보인다 (기획서 4.9). 화면별 "최상위 수치"를 명시한다: 홈=다음 경기 + 핵심 4수치, 계약=연봉, 프로필=현재 능력(전체 등급 표시 방식 [미정]), 라이프=잔고, 경기 후=평점.
- FR-04: 선택이 필요한 결정(인터뷰 답, 계약 조건, 이벤트 선택지)은 선택 패널로 묻는다 (037 FR-23, 2026-11-11 바텀시트에서 변경).
- FR-05: 수치가 바뀐 직후 화면에 들어오면 이전 값에서 새 값으로 카운트업한다 (037 FR-21).
- FR-06: 탐색: 사이드 내비(037 FR-28)에서 홈·일정·받은편지함·내 선수·라이프로 이동 [제안] (섹션 5개). 계약·관계·설정은 상위 화면에서 진입. 뒤로 가기는 항상 이전 화면으로 간다.
- FR-07: 모든 화면은 빈 상태·로딩 상태·오류 상태를 가진다 (037 FR-26). 데이터가 없을 때 0이나 빈 카드를 보이지 않는다.
- FR-08: 화면은 도메인 상태를 바꾸지 않고 명령만 보낸다. 명령이 거부되면(예: 돈 부족, 시간 슬롯 부족) 이유를 한 줄로 보인다.

### 1. 홈
- FR-10: 이번 주 할 일 목록 (훈련 선택, 받은편지함 필수 선택, 계약 마감 등). 완료한 항목은 완료 표시.
- FR-11: "다음 주로"는 필수 선택이 남아 있으면 비활성이고, 남은 항목 수와 바로가기를 보인다.
- FR-12: 다음 경기 카드: 상대, 대회, 날짜, 홈/원정, 예상 출전 여부(025가 제공).
- FR-13: 핵심 수치 4개: 최근 평점 폼, 감독 신뢰, 시장가치, 사기. 각각 지난주 대비 증감.

### 2. 일정
- FR-20: 월/주 보기 전환. 경기·훈련·이적시장·대표팀 기간·휴식을 구분 표시 (021이 제공하는 캘린더 데이터).
- FR-21: 지난 경기는 결과·내 평점, 다음 경기는 상대·대회. 경기를 누르면 경기 요약(지난 경기) 또는 상대 정보(다음 경기).
- FR-22: 오늘(게임 날짜) 위치가 표시되고, 일정 화면을 열면 오늘이 보이도록 스크롤된다.

### 3. 훈련
- FR-30: 포커스 5종 중 하나 선택 (기획서 4.3). 각 선택지에 예상 효과(어느 능력치 분류가 오르는지)와 피로 변화 방향을 보인다. 수치는 026·027이 제공.
- FR-31: 부상·질병 중이면 선택 가능한 포커스가 제한되고 이유가 보인다 (027이 제공하는 제한).
- FR-32: 버릇 교정 훈련 과제가 진행 중이면 진행 주차(4~12주 중 n주차, 기획서 4.2.1)를 보인다.

### 4. 받은편지함
- FR-40: 정렬: 선택 필요 → 안 읽음 → 날짜 역순. 카테고리 필터(12 카테고리, 기획서 4.6.2).
- FR-41: 항목을 열면 본문(대화체), 선택지가 있으면 선택 패널. 선택 후 결과 요약(어떤 수치가 어떻게 바뀌었는지, 지연 결과는 "나중에 영향이 있을 수 있어요"처럼 숨김 표시)을 보인다. 결과 규칙은 030이 제공.
- FR-42: 선택 마감이 있는 항목은 남은 일수를 보이고, 마감이 지나면 기본 선택 결과가 적용된 상태로 표시된다 (기본 선택 규칙은 030).
- FR-43: 수천 개 메시지가 쌓여도 목록이 끊기지 않는다 (가상화, 037 FR-24). 오래된 메시지 보관 정책은 [미정].

### 5. 계약
- FR-50: 현재 계약: 연봉, 남은 기간, 출전 보장 조항, 바이아웃, 보너스 (기획서 4.5). 연봉이 최상위 수치.
- FR-51: 제안 비교: 제안 2~3개를 나란히(넓은 화면) 또는 넘겨보기(좁은 화면). 현재 계약 대비 차이를 증감으로.
- FR-52: 협상: 조건별로 선택 패널에서 요구값 선택. 에이전트 의견 한 줄 (028이 제공). 서명 전 확인 모달(되돌릴 수 없음 표시, 037 FR-29).
- FR-53: 서명하면 성공 피드백(성공 피드백 지점, 037 FR-42)과 계약 화면 갱신.

### 6. 내 선수 프로필
- FR-60: 능력치 4분류(기술·정신·신체, 숨김은 표시 안 함, 기획서 4.2). 1~20 값, 지난 시즌 대비 증감.
- FR-61: 역할 적합도: 현재 역할과 추천 역할들의 ★1~5 (기획서 4.2.1, 계산은 003이 제공).
- FR-62: 역할↔성향 궁합: 좋음/보통/나쁨 + 이유 한 줄 (예: "드리블 중독 + 메짤라: 좋음"). 궁합이 나쁘면 "평점 기대치가 내려가요" 안내 (기획서 4.2.1).
- FR-63: 버릇 목록과 효과 요약, 교정 중이면 진행 상태.
- FR-64: 플레이 성향: 경기 기록으로 드러난 성향만 표시, 드러나지 않은 축은 "아직 몰라요" (기획서 4.2.1: 숨김 → 경기 기록으로 드러남). 드러나는 규칙은 003이 제공.
- FR-65: 잠재력은 범위 힌트로만 (기획서 4.1). 숫자 노출 금지.
- FR-66: 레이더 차트(분류별 평균 [제안]) (research 07 § 5.2).
- FR-67: 시즌 기록(출전, 골, 도움, 평균 평점)과 커리어 통산.
- FR-68: **트로피 캐비닛 탭** (063 FR-93): 커리어 화면(내 선수 프로필)의 한 탭. 팀 트로피·개인상·마일스톤을 다크 UI 카드 그리드(트로피 렌더 이미지 + 시즌 + 클럽)로 보이고 정렬(시즌·종류)·필터를 제공한다. 트로피 0개면 빈 상태(037). 기록·데이터는 063 FR-90이 소유하고 이 화면은 읽기만 한다. 은퇴 화면(FR-122)의 트로피 목록도 같은 기록을 읽는다.

### 7. 라이프 탭
- FR-70: 쇼핑: 상품 카드 + 큰 가격 (기획서 4.10). 분류(집, 차, 시계·패션, 반려동물, 투자). 살 수 없는 상품은 이유(돈 부족 등) 표시.
- FR-71: 구매 확인 모달 → 잔고 카운트업 감소. 상품 효과(라이프스타일 등급, 회복률 등)는 032가 제공하는 값을 표시.
- FR-72: 주간 시간 예산: 남은 슬롯 수, 활동(데이트, 유흥, 자기관리, 사교 등)을 슬롯에 배정. 슬롯이 부족하면 배정 불가 (기획서 4.10: 다 할 수는 없게).
- FR-73: 보유 자산 목록과 유지비.
- FR-74: 유흥·도박은 가상 화폐 소비로만 표현한다 (기획서 4.10). 실제 결제와 연결되는 UI 요소 금지.

### 8. 관계
- FR-80: 메신저형: 대화 상대 목록(마지막 메시지, 안 읽음 수) → 대화 화면(말풍선) (기획서 4.10).
- FR-81: 답장이 필요한 메시지는 말풍선 아래 선택지 버튼 또는 선택 패널.
- FR-82: 상대별 관계도(호감·신뢰)를 대화 화면 상단에 표시 (033이 제공).
- FR-83: 연애·유흥 관련 대화는 암시적 표현만 (기획서 4.10, 15세 등급). 표현 규칙은 033·031이 제공하고, 화면은 이미지·문구 필터 없이 받은 텍스트를 그대로 보이되 노골적 이미지 슬롯을 두지 않는다.

### 9. 경기 전 · 후
- FR-90: 경기 전: 선발/벤치/제외 통보 (025), 상대 정보, **날씨·피치 상태**(대표 날씨 아이콘·라벨과 보조 표시, 기온 °C, 바람 3단계, 피치 상태 라벨 — 값은 064 경기 레코드, 표시 규칙은 078 FR-50: 경기 당일 날씨만, 예보·경기 중 변화 예고 없음), "경기 시작" → 039로. 064가 경기를 연기하면 경기 전 화면 대신 "연기 — 사유 — 재배치 날짜" 카드를 보이고 다음 주 홈으로 진행한다(078 FR-51, FR-110 막다른 화면 0).
- FR-91: 경기 후: 평점이 최상위 수치, 세부 스탯(xG, 키패스, 압박 성공 등, 015가 제공), 감독 신뢰·시장가치·명성 변화를 카운트업으로.
- FR-92: 출전하지 않은 경기는 결과만 요약하고 사기 변화를 보인다 (기획서 아키텍처 6: 벤치/제외 → 사기 하락).

### 12. 선수 생성 · 13. 은퇴 · 레거시
- FR-120: 선수 생성은 023의 단계를 순서대로 한 화면씩 보인다. 단계마다 뒤로 가기로 이전 선택을 바꿀 수 있고, 마지막 확인 화면에서 전체 요약을 본 뒤 시작한다. 잠재력은 범위 힌트만(FR-65 규칙 같음).
- FR-121: 이름 입력은 길이·문자 규칙(023)을 즉시 검증하고 이유를 한 줄로 보인다.
- FR-122: 은퇴 화면: 은퇴 확인 모달(되돌릴 수 없음), 커리어 요약 카드(레거시 점수가 최상위 수치), 트로피·기록 목록, 명예의 전당 진입, 뉴게임+ 시작 버튼(자녀가 없으면 비활성 + 이유). 질병 은퇴 등 진지한 이유의 은퇴는 축하 연출 없이 표시한다(047 FR-31 톤 규칙).
- FR-123: 명예의 전당은 세이브와 별도로 남는 기록을 목록으로 보인다(저장 위치는 036·022).

### 흐름
- FR-110: 주간 루프 전체(홈 → 훈련 → 받은편지함 선택 → 다음 주로 → 경기 전 → 경기 → 경기 후 → 라이프 → 다음 주 홈)를 화면 흐름으로 정의하고, 각 단계에서 다음 단계로 가는 길이 하나 이상 있다 (막다른 화면 0).
- FR-111: "다음 주로" 처리 중에는 진행 표시를 보이고 입력을 막는다. 처리 시간은 024가 제공하는 진행 단계로 표시.

## 경계 · 예외 상황
- 시즌 경계: 시즌 마지막 주 → 프리시즌 전환 주에 일정·홈·계약 화면이 올바른 시즌을 보인다. 이적시장 열림/닫힘 당일.
- 계약 만료 주, 계약 없음(자유계약) 상태, 은퇴 직전 상태에서 각 화면이 깨지지 않는다.
- 부상·질병으로 장기 결장 중일 때 홈·훈련·경기 전 화면 표시.
- 돈이 0 또는 음수(빚)일 때 라이프 탭과 잔고 표시.
- 받은편지함 0개, 1개, 5,000개. 선택 필요 항목이 20개 이상일 때 "다음 주로" 안내.
- 제안 0개(계약 화면 빈 상태), 4개 이상(넘겨보기).
- 관계 대화 상대 0명, 매우 긴 메시지(긴 en 문장), 연속 메시지 수백 개.
- 능력치 1 또는 20 경계, 역할 적합도 계산 불가(GK가 아닌 선수의 GK 역할 등) 표시.
- 성향이 하나도 드러나지 않은 신인, 버릇 0개.
- 같은 주에 여러 화면에서 같은 자원(돈·시간 슬롯)을 쓰려 할 때 남은 값이 모든 화면에서 같다.
- 세이브 직후 불러오기, 저장 중 앱 종료 후 재실행(022가 무결성 보장, 화면은 손상 슬롯 표시만).
- 저장 공간 부족 상태에서 저장·자동 저장: 오류 모달 + 기존 슬롯 무손상, 앱 계속 사용 가능.
- 선수 생성 중 앱 종료: 생성 중 상태는 저장하지 않고 처음부터 (023 규칙이 다르면 023을 따른다). 이름 0자·최대 길이·이모지.
- 은퇴 화면: 트로피 0개 커리어, 기록 수백 개 커리어, 자녀 없음(뉴게임+ 비활성), 질병 은퇴.

## 비기능 요구사항
- 결정론: 같은 세이브 픽스처 + 같은 입력 순서 → 같은 화면 (000 FR-21). 화면 조작이 도메인 RNG를 소비하지 않는다 (명령만 보낸다).
- 세이브 호환: 화면 상태(열린 탭, 스크롤)는 저장하지 않는다 [제안]. 받은편지함 읽음 여부는 세이브에 포함 (022).

## 수용 기준
E2E는 `mac-m1-1600p` 1프로필 스크린샷 + 사용자 육안 승인이다 (2026-11-11 프로필 매트릭스·기준 이미지 비교 폐지, PC 전용). 해상도 차이는 같은 기기에서 창 크기·UI 배율을 바꿔 확인한다.

- AC-01 [E2E]: `e2e/038-weekly-loop`: 픽스처 세이브에서 홈 → 훈련 선택 → 받은편지함 필수 선택 → 다음 주로 → 경기 전 → (경기 생략 픽스처) → 경기 후 → 다음 주 홈까지 각 단계 캡처. ko/en × 다크(037 FR-10 다크 단독)로 `mac-m1-1600p` 1프로필 스크린샷 + 사용자 육안 승인, 겹침·잘림 0.
- AC-02 [로직]: 화면 흐름 그래프에서 모든 화면이 홈에서 도달 가능하고, 모든 화면에 나가는 길이 있다 (막다른 화면 0).
- AC-03 [E2E]: 필수 선택이 2개 남은 상태에서 "다음 주로"가 비활성이고 "2개 남았어요" 안내와 바로가기가 보인다. 바로가기로 처리하면 활성화된다.
- AC-04 [E2E]: 각 화면의 최상위 수치(FR-03)가 그 화면에서 가장 큰 글자 크기다 (요소 크기 단언).
- AC-05 [로직]: 화면 코드가 도메인 상태를 직접 바꾸지 않는다. 화면 조작 전후의 도메인 RNG 상태가 같다 (명령 전송 제외).
- AC-06 [E2E]: `e2e/038-inbox`: 5,000개 메시지 픽스처에서 정렬 순서가 선택 필요 → 안 읽음 → 날짜 역순이다. 항목을 열고 선택하면 결과 요약이 보이고 목록에서 완료 표시로 바뀐다.
- AC-07 [성능]: 받은편지함 5,000개 열기 ≤ 300 ms, 스크롤 p95 ≤ 33.3 ms, 스크롤 중 GC 0 B/프레임 (low-igpu-1080p).
- AC-08 [E2E]: `e2e/038-contract`: 제안 3개 비교가 `mac-m1-1600p`에서 창 2560×1440일 때 나란히, 1366×768일 때 넘겨보기로 보인다. 연봉 차이가 증감으로 표시된다. 서명 확인 모달을 거쳐야만 서명된다.
- AC-09 [E2E]: `e2e/038-profile`: 신인 픽스처(드러난 성향 0)에서 성향 칸이 모두 "아직 몰라요"이고, 잠재력은 숫자 없이 범위 힌트만 보인다. 역할 적합도 ★와 궁합(좋음/보통/나쁨 + 이유)이 보인다.
- AC-10 [로직]: 프로필 화면에 숨김 능력치(부상 경향, 일관성, 큰 경기 강도, 적응력)와 잠재력 숫자가 어떤 경로로도 노출되지 않는다 (렌더된 텍스트 검사).
- AC-11 [E2E]: `e2e/038-life-shop`: 잔고보다 비싼 상품은 구매 버튼 비활성 + 이유 표시. 살 수 있는 상품을 사면 확인 모달 → 잔고 카운트업 감소 → 보유 자산에 추가.
- AC-12 [로직]: 시간 슬롯이 0일 때 활동 배정 명령이 거부되고 이유가 표시된다. 라이프 탭과 홈에서 보이는 남은 슬롯 수가 같다.
- AC-13 [E2E]: `e2e/038-messenger`: 대화 상대 목록 → 대화 화면 → 선택지 답장 → 말풍선 추가. 긴 en 메시지가 말풍선 안에서 줄바꿈되고 넘치지 않는다. 메시지 300개 대화가 끝까지 스크롤된다.
- AC-14 [E2E]: `e2e/038-season-boundary`: 시즌 마지막 주 → 다음 주로 → 프리시즌 홈. 일정 화면이 새 시즌을 보이고, 계약 남은 기간이 1년 줄어 있다.
- AC-15 [E2E]: `e2e/038-edge-states`: 계약 없음, 장기 부상, 잔고 음수, 받은편지함 0개, 제안 0개 픽스처마다 해당 화면이 빈/제한 상태를 보이고 0·빈 카드가 아니다. 콘솔 에러·경고 0.
- AC-16 [E2E]: `e2e/038-save-slots`: 손상 슬롯 1개 + 정상 슬롯 2개 픽스처에서 손상 슬롯은 오류 이유와 함께, 정상 슬롯은 정보와 함께 보인다. 삭제는 확인 모달 후에만.
- AC-17 [E2E]: 키보드만으로(게임패드는 보조, 037 FR-64) AC-01 주간 루프 전체를 끝낼 수 있다 (`e2e/038-weekly-loop-keyboard`, `mac-m1-1600p`).
- AC-18 [성능]: 사이드 내비 화면 이동 ≤ 150 ms, 일정 월 전환 ≤ 150 ms (low-igpu-1080p). 매니지먼트 화면에서 메모리 ≤ 500 MB (mac-m1-1600p).
- AC-19 [로직]: 라이프·관계 화면의 어떤 요소도 실제 결제 흐름을 호출하지 않는다 (결제 호출 지점 0).
- AC-20 [결정론]: 같은 픽스처에서 `e2e/038-weekly-loop`를 2회 실행하면 다음 주 홈 도달 시 도메인 상태 해시가 같다.
- AC-21 [E2E]: `e2e/038-player-creation`: 023의 모든 단계를 지나 커리어를 시작한다. 단계별 캡처에서 겹침·잘림 0, 뒤로 가기로 바꾼 선택이 최종 요약에 반영된다. 잠재력 숫자가 어느 단계에도 렌더되지 않는다. `mac-m1-1600p` 1프로필 스크린샷 + 사용자 육안 승인.
- AC-22 [E2E]: `e2e/038-retirement`: 은퇴 확인 → 커리어 요약(레거시 점수 최상위 수치) → 명예의 전당 → 뉴게임+ 진입. 트로피 0개·자녀 없음 픽스처에서 빈 상태와 비활성 이유가 보인다. 질병 은퇴 픽스처에서 축하 연출 큐가 0개다. `mac-m1-1600p` 1프로필 스크린샷 + 사용자 육안 승인.
