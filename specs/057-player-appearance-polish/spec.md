## 배경
056으로 선수가 "인형"에서 "사람"이 됐지만(AC-09 승인), 클로즈업에서 네 가지가 눈에 걸린다. ① 목 칼라 경계가 삼각형 계단처럼 지그재그로 보인다. ② 머리카락이 볼륨 셸뿐이라 가장자리와 앞머리가 헬멧처럼 딱 끊긴다(056 T08에서 알파 카드를 생략). ③ 클로즈업 피부가 모공 노이즈 때문에 사포처럼 거칠다. ④ 헤어스타일이 10종뿐이라 22명이 서면 같은 머리가 여러 번 보인다. 이 스펙은 056의 모델·뼈대·성능 예산을 그대로 두고 이 네 가지만 다듬는다.

## 범위
- 포함:
  - 유니폼 경계(목 칼라 우선, 소매 끝·반바지 밑단·양말 윗단 포함)가 매끈한 곡선으로 보이게 하기
  - 머리카락 가장자리·앞머리·뒷목선에 가닥 카드를 더해 실루엣이 부드럽게 끊기게 하기 (LOD0·클로즈업 머리)
  - 클로즈업·방송 시점 피부 질감을 매끈하되 플라스틱이 아니게 조정
  - 헤어스타일 30종 확대와 그 분포
  - 056·043 회귀(관통·예산·유니폼 합성·클립) 유지
- 제외:
  - 가닥 단위 머리카락(Strand) 렌더링 — 기획서 리서치에서도 클로즈업 컷신 한정 시험 항목, 유지보수 리스크 (047 이후)
  - 머리카락 물리(흔들림)·천 시뮬레이션
  - 땀(wetness) 효과, 얼굴 문신·타투, 헤어밴드·액세서리 [미정: 후속 스펙에서 다룰지]
  - 수염 종류 확대 (056 4종 유지 — 외형 품질은 FR-24로 포함, 2026-11-05 사용자 결정)
  - 달리기·킥 폼 (055)
  - 피부색·머리색 분포 변경 (056 FR-23 그대로)

## 사용자 시나리오
1. 골 세리머니 클로즈업에서 목 칼라 테두리가 매끈한 곡선이고 톱니처럼 끊기지 않는다.
2. 머리 옆선·앞머리·뒷목선이 헬멧처럼 딱 잘리지 않고 가닥이 흩어지며 끝난다.
3. 얼굴 피부가 가까이서 봐도 사포·노이즈처럼 보이지 않고, 플라스틱처럼 번들거리지도 않는다.
4. 우리 팀 선발 11명을 나란히 세우면 같은 머리 모양이 거의 겹치지 않고, 짧은 머리 위주라 축구 선수답다.
5. 저사양 노트북에서도 하이라이트가 60fps로 돈다.

## 요구사항

### 유니폼 경계
- FR-01: 목 칼라 경계선은 메시 삼각형 경계를 따라 계단처럼 꺾이지 않는다. 클로즈업 머리 기준 화면에서 칼라 경계의 이웃 정점 간 방향 변화(꺾임 각) ≤ [제안] 20°, 경계선 굴곡이 기준 곡선(타원·V넥 등 칼라 모양)에서 벗어나는 거리 ≤ [제안] 3 mm.
- FR-02: 소매 끝·반바지 밑단·양말 윗단·셔츠 밑단·축구화 목은 방송 시점 기준으로, 계단(이웃 꺾임의 부호가 번갈아 바뀌는 10° 넘는 꺾임 쌍) 0, 꺾임 각 ≤ 40°, 평면 이탈 ≤ 3 mm (2026-11-05 사용자 결정: 20°는 칼라만 — 목·발목의 실제 곡률 때문에 정점을 늘려야 해서 삼각형 예산을 칼라에만 쓴다).
- FR-03: 경계에는 056 FR-50의 턱(두께)이 유지되고, 어떤 클립 포즈에서도 피부가 유니폼을 뚫는 프레임 0 (056 AC-03 회귀).
- FR-04: 043·056 유니폼 합성(팀 색 ΔE 기준, 번호·이름 글자 영역)이 그대로 통과한다. 칼라 영역 색(칼라 색이 몸판과 다른 키트 포함)이 경계를 넘쳐 번지지 않는다.

### 머리카락 가닥 카드
- FR-10: 머리카락이 있는 모든 스타일(삭발 제외)은 볼륨 셸 위에 가장자리(옆머리·구레나룻)·앞머리·뒷목선을 덮는 가닥 카드를 가진다. 카드는 가닥 방향이 있는 알파 텍스처로, 실루엣이 셸 경계에서 딱 끊기지 않는다.
- FR-11: 카드는 LOD0와 클로즈업 머리에만 있다. LOD1·LOD2는 056처럼 셸만(카드 없음). LOD 전환 때 머리 실루엣이 튀지 않는다(043 LOD 히스테리시스 그대로).
- FR-12: 알파 가장자리 처리는 기획서 리서치대로 알파 클립 + 디더링(또는 alpha-to-coverage) 계열로, 반투명 정렬 문제가 없어야 한다(투명 큐 정렬 없이 그린다).
- FR-13: 카드 머리카락이 머리·목·어깨·유니폼을 뚫지 않는다 (056 FR-41 기준, 043 클립 전체).
- FR-14: 헤어 텍스처는 bpy 절차 생성 또는 CC0만 (01-legal, `Art/LICENSES.csv`).

### 피부 질감
- FR-20: 클로즈업에서 피부의 고주파 노이즈(모공·잡티)는 형태 음영을 덮지 않는다. 측정: 클로즈업 머리 렌더에서 피부 영역 밝기의 고주파 성분(작은 반경 블러 차이)의 표준편차가 056 대비 [제안] 50% 이하이면서, 완전 평탄(0)은 아니다(디테일 노멀이 남아 있다).
- FR-21: 피부 디테일은 부위별로 다르다 — 코·볼은 모공이 조금 더 보이고, 이마·눈가·입술은 더 매끈하다. 수염 자리는 056 그대로.
- FR-22: 방송 시점 원거리에서 피부가 반짝이는 노이즈(밉맵·노멀 앨리어싱으로 깜빡임)를 보이지 않는다. 측정: 카메라를 천천히 움직인 연속 프레임에서 얼굴 영역 밝기의 프레임 간 깜빡임이, 노멀맵을 끈 기하 기준선 대비 ≤ 1.10배 (2026-11-05 사용자 승인; E2E에서는 켬 − 끔 평균 차 ≤ 0.2로 판정).
- FR-23: 056 FR-31의 "플라스틱 피부 금지"(정반사 하이라이트 면적·세기 상한)는 그대로 지킨다.
- FR-24: 수염(056의 4종 그대로)이 사람 수염처럼 보인다 (2026-11-05 사용자 지적 "수염이 이상하다"로 추가). ① 점 노이즈(소금·후추)가 아니라 매끈한 밀도에 낮은 대비 결 — 수염 영역 안 밀도 고주파 RMS ≤ [제안] 0.05 (056 0.164). ② 아래 경계는 턱 밑(울대 위)에서 끝나고 목 아래로 내려가지 않는다 — 울대 아래 목 앞 밀도 평균 ≤ [제안] 0.01. ③ 입은 입술만 비우고 콧수염·입꼬리·턱이 이어진다 — 입꼬리 밀도 ≥ [제안] 0.3 (056 0). ④ 볼·목 경계는 흐리고, 짧을수록 피부가 비치는 옅은 색조.

### 헤어스타일 확대
- FR-30: 헤어스타일을 056의 10종에서 **30종**으로 늘린다 (2026-11-05 사용자 결정 "30종 이상"). 기획서 "축구 선수는 대부분 짧은 머리"에 따라 짧은 머리 계열이 과반이다. 추가 20종(일반 명칭, 특정 인물 연상 이름 금지): 크루컷, 사이드 파트, 언더컷, 슬릭백, 쿠이프(앞머리 세움), 가운데 가르마(커튼), 텍스처드 크롭, 버즈 + 라인(옆선 면도 무늬 1종), 하이톱, 콘로(땋아 붙임), 트위스트(꼬은 머리), 톱 노트(묶어 올림), 짧은 포니테일, 미디엄 웨이브, 프렌치 크롭, 아이비리그, 스파이크, 짧은 곱슬 톱(옆 짧게), 박스 브레이드, 하프 업(반묶음).
- FR-31: 스타일별 생성 분포: 짧은 계열(버즈·페이드·크루컷·크롭 등) 합계 [제안] ≥ 55%, 긴 머리·묶음 계열 합계 [제안] ≤ 15%. 세부 가중치는 플랜에서 표로 정하고 이 범위를 지킨다.
- FR-32: 다양성: 같은 팀 22명(무작위 시드 [제안] 1,000팀)에서 같은 헤어스타일이 [제안] 4명 이상 나오는 팀 비율 ≤ [제안] 5%. (머리색과 조합하면 겉보기 중복은 더 적다.)
- FR-33: 모든 새 스타일은 056 기준을 지킨다 — 두피 위 간격, 머리카락×몸 관통 0, 머리색 6종 적용, 클로즈업 머리 버전, LOD0~2.
- FR-34: 결정론: 같은 선수 id·시드 → 같은 헤어스타일. 헤어스타일 개수가 바뀌어 기존 시드의 외형 조합이 달라지는 것은 허용한다 (2026-11-05 사용자 결정: 배포된 세이브 없음, 호환 규칙 두지 않음. 기준 이미지는 승인 후 갱신). 세이브에는 메시를 넣지 않는다(056 그대로).

### 예산 · 호환
- FR-40: 폴리곤: 카드를 더해도 LOD0 6~10k tris(몸 + 가장 무거운 헤어), 클로즈업 머리 ≤ 6k tris (CLAUDE.md 확정·056 FR-61). LOD1 2~3k.
- FR-41: 서브메시·머티리얼 수는 056 대비 늘리지 않는 것을 원칙으로 하고, 늘어도 드로우콜은 056 대비 [제안] +10% 이내.
- FR-42: glb 크기는 헤어 조각 증가를 포함해 056(6 MB) 대비 [제안] 2배 이내, 생성 시간은 [제안] 3분 이내(056 약 70 s).
- FR-43: 뼈대·뼈 이름·Humanoid 매핑·043 클립 82개·발 접지 IK는 바꾸지 않는다.

## 수용 기준
- AC-01 [로직]: LOD0 키트 메시의 칼라 경계 고리에서 이웃 정점 꺾임 각 최대 ≤ 20°·평면 이탈 ≤ 3 mm, 소매 끝·셔츠 밑단·반바지 밑단·양말 윗단·축구화 목 고리에서 계단 0·꺾임 ≤ 40°·이탈 ≤ 3 mm (FR-01·02).
- AC-02 [로직]: 056 관통 검사(클립 82 × 극단 체형 4 × 4프레임)를 헤어 30종 × 카드 포함으로 돌려 피부×유니폼 0, 머리카락(셸·카드)×몸·유니폼 0, 뒤집힌 삼각형 0 (FR-03·13·33).
- AC-03 [로직]: 예산 — 모든 헤어 스타일에서 LOD0 6~10k, LOD1 2~3k, 클로즈업 머리 ≤ 6k, LOD1·LOD2에 카드 없음, 삭발 제외 전 스타일 LOD0에 카드 있음 (FR-10·11·40).
- AC-04 [로직]: 헤어스타일 30종 존재, 분포(짧은 계열 ≥ 55%, 긴·묶음 ≤ 15%), 1,000팀 다양성(같은 스타일 4명 이상 팀 ≤ 5%), 같은 id 재생성 동일 (FR-30~32·34).
- AC-05 [로직]: 클로즈업 피부 고주파 표준편차가 056 대비 ≤ 50%이고 > 0, 부위별(코·볼 > 이마·눈가) 디테일 순서 유지, 정반사 상한 유지, 수염 밀도 고주파 ≤ 0.05·울대 아래 ≤ 0.01·입꼬리 ≥ 0.3 (FR-20·21·23·24).
